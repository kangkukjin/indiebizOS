# HWP/HWPX 회귀 자료

한글 합성 본문과 2×2 표만 담은 시험 문서다. RHWP 0.8.6으로 생성했으며 기본
서식 정의는 MIT RHWP의 `rhwp-studio/public/samples/form-002.hwpx` 헤더를 재사용했다.
개인 사용자 문서나 개인정보가 아니다. 원본 출처: https://github.com/edwardkim/rhwp/tree/v0.8.6

기본 헤더의 글꼴 이름은 참조이며 상용 글꼴 파일을 포함하지 않는다.
생성기 `createEmpty()`만의 HWPX에는 서식 정의가 없어 실제 읽기/쓰기 시험용으로 부적절하여,
유효한 서식 정의를 포함한 이 자료를 사용한다. 새 HWP/HWPX 생성 UI는 제공하지 않는다.

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
