# 가이드 등록 가이드 (Guide Registration Guide)

이 가이드는 IndieBiz OS 시스템에 새로운 작업 지침(가이드)을 등록하고 관리하는 방법을 설명합니다.

## 1. 가이드 파일 생성
새로운 가이드는 마크다운(`.md`) 형식으로 작성하며, 다음 경로에 저장합니다.
- **경로**: `data/guides/`(저장소 루트 기준)
- **파일명**: 영문 소문자와 언더바(`_`)를 사용한 직관적인 이름 (예: `my_new_guide.md`)

## 2. 가이드 DB 등록

파일을 생성한 후, 시스템이 검색할 수 있도록 DB에 등록해야 합니다.

- **DB 파일**: `data/guide_db.json`(저장소 루트 기준)

### 등록 항목

| 필드 | 설명 | 규칙 |
|------|------|------|
| `id` | 고유 식별자 | 파일명에서 `.md` 제거한 것 (예: `my_guide`) |
| `name` | 가이드 공식 명칭 | 한글 10~20자. 사용자가 보는 이름 |
| `description` | 내용 요약 | 한 문장. 이 가이드가 **언제** 필요한지 명시 |
| `keywords` | 검색 키워드 목록 | 아래 작성 규칙 참고 |
| `file` | 실제 파일명 | 확장자 포함 (예: `my_guide.md`) |
| `topic` | 실행기억 가지 | `<execution_map>` 에 있는 가지 이름(예: `보고서/AI 동향`). 가이드가 지도에 실리는 씨앗 — 필수 |

### keywords 작성 규칙

`read_guide` 의 키워드 검색(지도에 마땅한 가지가 없을 때의 폴백)이 씁니다. 가이드의 주 입구는 아래 3절의 가지입니다.

- **한글 + 영문 모두 포함**: `["투자", "주식", "investment", "stock"]`
- **사용자가 실제로 쓸 만한 단어**: 기술 용어보다 일상어 우선 (예: `"길찾기"` > `"navigation"`)
- **동의어/유의어 포함**: `["홈페이지", "웹사이트", "사이트", "homepage"]`
- **동사형도 포함**: `["만들어줘", "제작", "생성"]`
- **8~15개가 적당**: 너무 적으면 매칭 안 되고, 너무 많으면 관련 없는 것까지 매칭됨
- **다른 가이드와 겹치는 범용 키워드는 피하기**: `"검색"`, `"정보"` 같은 건 모든 가이드에 매칭되므로 비효율적

## 3. 가지에 걸기 — 지도가 입구다 (2026-09-03)

가이드는 실행기억(해마)의 **주제 가지**에 속합니다. 씨앗은 `guide_db.json` 의 `topic` 필드(저장소에 추적됨)이고, 정본은 가지 문서 `data/hippocampus_tree/<가지>/memory.md` 의 `guide:` 줄(몸-사적, 여러 개면 쉼표)입니다. 문서가 없거나 줄이 비면 씨앗이 채우고, 문서의 줄이 있으면 그것이 이깁니다. 어느 쪽이든 매 턴 프롬프트의 `<execution_map>` 목차에 실려 의식·실행자가 거기서 고릅니다. 어디에도 걸리지 않은 가이드는 키워드 검색으로만 닿습니다.

- 가지 이름은 `<execution_map>` 에 있는 것을 씁니다. 없는 주제면 증류가 가지를 만들 때까지 가장 가까운 가지에 겁니다.
- 구성요소 생명주기는 이 줄을 참조로 셉니다 — 걸린 가이드는 고아가 아닙니다.

## 4. 등록 확인

등록이 완료되면 의식 에이전트가 `<execution_map>` 의 `guide:` 줄에서 가이드를 고르고(`guide_files`), 실행자가 `read_guide` 에 파일명을 그대로 넣어 엽니다. 별도의 검색 명령은 제공되지 않으며, 다음을 확인하세요.
- `guide_db.json`이 유효한 JSON인지 (쉼표, 따옴표 형식 등)
- `file` 항목의 파일명이 `data/guides/` 안에 실제로 존재하는지
- `keywords`가 사용자가 실제로 쓸 만한 단어를 포함하는지

검증을 위해 시스템을 재시작할 필요는 없습니다. 등록 즉시 반영됩니다.

## 4. 수정 및 업데이트

- **내용만 수정**: `.md` 파일만 편집하면 즉시 반영됩니다.
- **이름/키워드 변경**: `guide_db.json`도 함께 업데이트하십시오.
- **가이드 삭제**: `guide_db.json`에서 항목 제거 + `.md` 파일 삭제.
- **주의**: `guide_db.json`은 JSON이므로 마지막 항목 뒤에 쉼표가 없어야 합니다.
