# 외부 라이브러리 확인·설치

과제에 맞는 방법과 도구는 의식의 ‘세상의 방식’과 실행자의 판단으로 선택한다.
설치 여부는 실제 환경에서 확인한다. 자동 설치는 없다.

```ibl
[self:install_lib]{package: "<공식 pip 이름>", check: true}
[self:install_lib]{package: "<공식 pip 이름>", reason: "<이 작업에 필요한 이유>"}
```

`check: true`는 등록·설치 없이 installed / pending / approved / missing 상태를 확인한다.
미설치 패키지는 조종실 도구 관리의 ‘라이브러리 설치 승인’에서 사용자가 승인한 뒤 설치한다.
AI가 승인하거나 셸로 우회하지 않는다. 승인 대기 중에는 가능한 다른 방법으로 진행하거나 상태를 알린다.
pip 이름은 공식 문서에서 확인한다. 프로그램 바이너리는 설치 여부를 확인하고 없으면 사용자에게 안내한다.
