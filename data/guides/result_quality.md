# 결과 확인

실행 AI가 사용자 요청·유효한 가이드·실제 결과를 대조하고, 필요한 확인과 보완을 수행한 뒤 마친다.
확인의 방법과 깊이는 작업과 관측에 맞게 판단한다. 별도 평가에 통과하기 위한 형식이나 증빙 문서를
만들지 않는다. 사용자 요구, 내부 제안, 과거 기억과 실제 관측을 구분한다.

파일을 만들거나 수정했다면 결과를 읽고 사용 가능한지 확인한다. 조사·계산 결과는 판단에 필요한
원문과 입력에 대조한다. 미확인·부분 실패·한계를 결과에 정확히 반영하고, 아직 남은 일을 완료했다고
보고하지 않는다. 이미 확보한 원문과 실행 결과를 재사용하며 완료된 외부 효과를 반복하지 않는다.

독립 검토는 기본 절차가 아니다. 의식이 이번 작업에 필요하다고 선택한 경우만 별도 검토를 실행한다.
독립 검토를 하지 않은 결과는 NOT_RUN으로 기록하며 승인받았다고 표시하지 않는다.
검토자는 결과의 적합성을 판단하고 실행자는 피드백과 실제 상황을 보고 필요한 부분을 보완한다.

하네스는 권한·취소·실행 영수증·원문 무결성과 전달 상태를 확인한다. 이 확인을 내용의 완성도나
목표 달성 판단으로 대신하지 않는다. 공개·전송은 기존 사용자 권한 안에서 수행하고,
전달 실패나 효과 미확인은 내용 판단과 구분해 남긴다.
