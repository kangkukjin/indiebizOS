# 한국 쇼핑 추천 가이드

제품 추천·구매처 비교는 가격비교 한 곳으로 끝내지 않는다. 아래 소스를 목적에 맞게 골라 뒤지고, 아래 원칙으로 후보를 고른다. 중고는 [used_market.md](used_market.md).

## 어디를 뒤지나

| 목적 | 소스 | 여기서 볼 것 |
|---|---|---|
| 후보·가격대 훑기 | 다나와·에누리(`search_shopping`) | 어떤 브랜드·모델이 있고 가격대가 어떤지. 여기 없는 인기 제품이 많다. |
| 많이 팔리고 후기 많은 제품 | 네이버 쇼핑·스마트스토어, 쿠팡, 11번가, G마켓 | 판매량·후기 수·별점·실구매 후기. **후기 많은 순으로 본 결과를 반드시 포함**한다. 소규모 스마트스토어 제품이 실제 인기 1위인 경우가 흔하다. |
| 정확한 스펙·보증 | 제조사 공식몰·제품 페이지·설명서 | 상품명·광고 문구의 기능 주장이 맞는지, 모델 간 차이, A/S·소모품. |
| 실사용 평가 | 네이버 블로그·카페, 유튜브, 품목별 커뮤니티 | 장기 사용 단점·고장·관리. 협찬 글은 걸러 보고 같은 홍보 글을 여러 근거로 세지 않는다. |
| 할인 구성·유통 전용 모델 | 홈쇼핑(GS·CJ온스타일·Hmall·롯데)·SSG | 같은 이름의 다른 모델인지 확인. 사은품을 가격 이점으로 세지 않는다. |
| 국내에 없거나 훨씬 싼 대안 | 알리익스프레스·아마존(미국·일본) | 배송·관세 포함 총액, 전압·규격·반품. |
| 객관 시험 | 한국소비자원·소비자24 | 그 품목 시험 자료가 있으면 참고. 시험하지 않은 모델로 확장하지 않는다. |

가격만 물으면 가격 소스로 좁히고, "뭘 살까"면 최소한 가격비교 + 오픈마켓(후기순) + 스펙 원문 + 실사용 후기를 본다. 더 넓힐 가치가 작아지면 멈춘다.

## 어떻게 고르나

1. **사용자 조건으로 먼저 거른다.** 용도·사용자(예: 어르신·아이)·크기·예산·필수 기능에 안 맞으면 인기 제품이라도 뺀다. 비슷한 기능(예: 카운트다운 타이머 vs 24시간 예약)을 같은 것으로 취급하지 않는다.
2. **스펙 주장은 원문으로 확인한다.** "올스텐"·"자동전원차단" 같은 상품명 표기를 그대로 믿지 말고 상세페이지·제조사 원문에서 실제 사양(어디가 스텐인지, 과열방지인지 자동꺼짐인지)을 확인한다. 확인 못 했으면 미확인이라고 쓴다.
3. **인기와 단점은 후기로 본다.** 후기 수로 검증된 정도를, 후기 내용으로 반복되는 불만을 본다.
4. **총액으로 비교한다.** 표시가가 아니라 옵션·배송비·쿠폰 조건을 반영한 실제 결제액. 렌탈 월액과 일시불을 섞지 않는다.
5. **후보마다 링크와 근거를 붙인다.** 구매 링크, 가격과 관측 시점, 핵심 근거(후기 수·스펙 출처)를 처음 답에 함께 준다. 사용자가 링크를 따로 요청하게 만들지 않는다.
6. **본 곳과 못 본 곳을 밝힌다.** 접근 실패·미조회 채널을 "상품 없음"으로 해석하지 않는다.

## 대화가 이어지면 조건을 기억한다

같은 아이템에 대한 대화가 여러 턴 이어지면, 사용자가 앞서 말한 조건(용도·누가 쓰는지·크기·예산·필수/제외 기능·선호 구매처)을 모두 유지한 채 답한다. 새 질문에 답할 때 앞 조건을 빠뜨리거나 다른 조건으로 바꿔치지 않는다. 사용자가 조건을 바꾸거나 철회하면 그것을 반영해 후보를 다시 거른다. 이전 추천은 사용자 조건이 아니다.

## 도구 주의

- `search_shopping`은 다나와·에누리만 지원하고 정렬은 기본순뿐이다. 후기순·판매량순은 오픈마켓을 직접(search·crawl·browser) 본다.
- 네이버 쇼핑 **검색 API**는 2026-07-31 종료됐다(`site:naver` 호출 금지). 네이버 쇼핑·스마트스토어 **웹페이지**는 search·browser로 볼 수 있는 별개 소스다.
- `search_shopping`의 `mall`은 가격비교 서비스 이름이지 판매처가 아니고, `price`는 구매 총액이 아니다.
- 다나와는 요청한 검색어·페이지의 상품 상태, 에누리는 검색어가 일치하는 상품 목록을 읽는다.
  `source_changed`는 상품이 없다는 뜻이 아니다. 원천의 목록을 확인하지 못한 경우이며,
  `empty_reason:no_results`로 확인된 정상 빈 결과와 구분한다.

소스 전체 목록은 [web_landmarks.md](web_landmarks.md#한국에서-구매할-제품을-찾을-때).
