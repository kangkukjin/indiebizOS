# 지출내역 ([self:spend]) 가이드

결제 앱(하나카드·청주페이)의 승인 푸시 알림을 폰 USB 연결 때 수거해 쌓는 **지출 원장**.
계기: 💳 지출내역 (내역/통계/검색 3탭).

## 사용 흐름 (사용자 규약이 핵심)

1. 폰에서 결제 알림을 **지우지 않고** 모아둔다 — 활성 알림에만 가맹점·금액 텍스트가 남는다.
2. 폰을 USB 로 연결하고 수거: `[self:spend]{op: "sync"}` (계기 '지금 수거하기' 버튼).
3. 수거가 끝나면 알림을 지워도 된다 (id 해시로 중복 방지 — 여러 번 수거해도 안전).

## op

- **list** (기본): 지출 내역 조회. 기본 이번 달.
  - `month: "YYYY-MM"` / `days: 7`(최근 N일 — month 보다 우선) / `source: "하나카드"|"청주페이"` / `query: "가맹점·문구"` / `limit`
  - items 의 `amount` 는 숫자라 table 파이프 조합 가능:
    `[self:spend]{op: "list"} >> [table:sort]{by: "amount", order: "desc"} >> [table:take]{n: 5}`
- **summary**: 월간 통계 — 순지출(승인−취소)·카드별 합계·상위 가맹점. `month` 지정 가능.
- **sync**: 폰(USB) 결제 알림 수거 → 원장 병합. 폰 미연결이면 정직하게 거부.

## 한계 (정직 신고)

- **지운 알림·재부팅으로 사라진 알림은 수거 불가** (아카이브엔 텍스트가 없다 — 실측).
  놓친 결제는 월간 명세서 이메일 대사로 메꾼다.
- 앱당 활성 알림 상한(~24) — 결제가 잦으면 수거 주기를 짧게.
- 취소·환불은 `type: cancel` 로 잡혀 통계에서 자동 차감. 청주페이 충전은 `type: charge`(지출 아님).
- 파싱 실패 알림은 미분류(parsed=0)로 원문 보존 — 실측 문구가 쌓이면 파서를 다듬는다.

## 폰 쪽 선행 설정 (1회, 완료 2026-08-12)

- 청주페이: 시스템 알림 허용 (importance NONE→DEFAULT 확인).
- 하나카드: 시스템·앱 승인 알림 켜짐 확인.
