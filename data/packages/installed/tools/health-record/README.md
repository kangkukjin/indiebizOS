# Health Record

에이전트가 사용자의 건강 정보를 기록하고 조회할 수 있게 합니다.
혈압, 혈당, 체중, 증상, 투약 기록 등을 체계적으로 관리합니다.

## 주요 기능
- 건강 측정값 저장 (혈압, 혈당, 체중 등)
- 증상 및 투약 기록
- 건강 이력 조회 및 요약
- 다중 사용자 지원

문서 이미지는 건강 데이터의 영속 저장소에 복사하고 실제 파일 경로를 기록합니다.
실행 세대의 연결 경로를 남기지 않아 이전 코드 세대가 정리돼도 원본을 조회할 수 있습니다.
`INDIEBIZ_USERDATA`가 지정된 환경에서는 해당 저장소를 유지합니다.

## 적합한 에이전트
- 건강/의료 관리 에이전트
- 개인 비서 에이전트
