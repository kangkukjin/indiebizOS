# 공동 업무 · Managed Records

`[self:record]`는 선언된 업무 명령을 실행하는 선택 패키지다.
같은 기록을 여러 사람이 처리할 때 권한·버전·조건을 검사하고 변경·이력·승인 대기·영수증을 함께 확정한다.

- 내 어휘에서 이 묶음을 선택한 뒤 앱 모드의 **공동 업무**를 연다.
- 업무 정의를 등록하고 공간의 참여자와 역할을 지정한다.
- 회원에게 제공하려면 기존 외부사용자 관리에서 묶음을 별도로 공개한다.
- 데이터는 운영자 호스트의 업무 공간에 저장되며 회원 개인 파일과 구별한다.

사용 계약과 두 예시 정의: `data/guides/managed_records.md`.
서버 화면: `/records/app`, 회원 화면: `/m/records/app`.
조회 op는 `describe/query/detail/history/inbox/receipt`, 변경은 `apply`다.

이 패키지는 함께 배포되는 관리 기록 backend를 필요로 한다. 패키지 파일만 이전 버전의 서버에 복사하면 실행할 수 없다.
회원 공개는 패키지와 backend 의존 파일의 감사 지문이 일치할 때만 열린다.
현재 상한은 공간당 1,000개 기록, 한 명령 100개 변경이다. 외부 기관 연결은 업무별 어댑터 계약을 맞춰야 한다.
