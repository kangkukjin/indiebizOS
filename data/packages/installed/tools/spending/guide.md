# spending — 지출내역 ([self:spend])

결제 앱(하나카드·청주페이)의 승인 푸시 알림을 폰 USB 연결 때 수거해
지출 원장(`data/spending.db`)으로 쌓는다. 상세 사용법은 `data/guides/spend.md`.

## 구조

- `handler.py` — spend_op (sync/list/summary). 전부 handler.py 한 파일
  (서브모듈 없음 → `/packages/reload` 만으로 라이브 반영).
- 원장: `data/spending.db` (spend 테이블 — 원문 title/body 보존, parsed=0 미분류 표시,
  sync_log 테이블 — 수거 이력).

## 원리와 순서 (사용자 규약)

1. 폰에서 결제 알림을 **지우지 않고** 모아둔다 (활성 알림에만 텍스트가 남는다).
2. 폰을 USB 로 연결하고 `op:sync` (계기 '지금 수거하기' 버튼).
3. 수거 후엔 알림을 지워도 된다 (원장에 이미 병합, id 해시 중복 방지).

## 함정

- **지운 알림은 수거 불가** — dumpsys 아카이브·삼성 히스토리엔 메타데이터만 남고
  제목·본문 텍스트가 없다 (2026-08-12 실측). 재부팅도 활성 알림을 지운다.
- 앱당 활성 알림 상한(~24)이 있어 결제가 아주 잦으면 오래된 알림이 밀려날 수 있다.
- 수거 대상 앱 추가는 `handler.py` `_PAY_PKGS` 에 pkg→이름 한 줄.
- 파서(`_parse_payment`)는 실측 문구가 쌓이면 다듬는다 — 원문이 보존되므로 재파싱 가능.
  파싱 실패는 버리지 않고 미분류(parsed=0)로 남긴다 (침묵 실패 금지).
- 놓친 결제의 백업 경로: 월간 명세서 이메일 대사(하나카드) / [limbs:android] 앱 화면 읽기.
