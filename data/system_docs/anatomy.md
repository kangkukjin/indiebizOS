# indiebizOS 해부도 (Anatomy)

> indiebizOS는 자동차처럼 복잡한 물건이 됐다. 그래서 이 문서는 *부품 목록*이 아니라, **하나의 생각에서 각 기관이 어떻게 자라났는지**를 보여준다.
> 처음 오는 사람은 이 문서만 위→아래로 읽으면 전체가 잡힌다. 각 절 끝의 **→ 링크**가 상세로 데려간다.
> 자동차를 처음 보는 사람에게 "이건 엔진, 이건 변속기"는 도움이 안 된다. 필요한 건 "이건 네가 *모는* 기계다, 여기가 운전대다, 그리고 *왜 이렇게 생겼는지*"이다.

---

## 0. 한 문장 — 무엇인가

**indiebizOS는 데려다주는 *자율주행차*가 아니라, 입는 *인지 외골격*이다.** 사용자의 PC에서 도는 개인 소유 프로그램(하네스)이 웨어러블 로봇의 *몸*이고, AI 모델은 그 *두뇌*(빌리는 것·교체됨)다. 진짜 자산은 **핏(fit)** — 한 사람의 의지가 응고된 것.

두 패러다임으로 가른다:
- **정답 패러다임** (업계 주류·AI 브라우저): 인간 명령 → 정답 하나 도출. 가능성을 *줄여* 시야를 좁힌다.
- **시야 패러다임** (indiebizOS): 인간 판단에 기반해 가능성을 *늘린다*. 힘은 AI가 대되, 어디로 뻗을지는 매 순간 사람이 정한다. 웨어러블 로봇처럼.

깊은 일(연구·집필·창업·"뭘 원하는지 알아내기")은 목적지가 루프 *안*에서 생성된다 — 그래서 한 방에 정답을 뽑는 게 아니라 사람과 함께 좁혀 간다.
→ 정본 telos: [vision.md](vision.md) · 코드 독립 원리(자기 하네스를 지으려는 사람용): [harness_haerye.md](harness_haerye.md)

## 1. 어떻게 만지는가 — 런처의 3표면 (운전대·페달)

같은 IBL 신경계 위에, 사용자가 직접 모는 세 표면이 있다. 각각 {속도·표현력·주권} 중 둘을 갖고 하나를 내준다 (트릴레마).

| 표면 | 무엇 | 비용 | 큐레이션 |
|------|------|------|----------|
| **자율주행** | 의도 → 플래그십 AI가 다단계 처리 (아래 3장 인지 파이프라인) | 비쌈 | AI |
| **조종실** (구 수동/계기판) | 경량 모델이 자연어→IBL 번역 → dry-run 검수 → 실행. 시스템 상태·모델 기어·프레즌스·주행기록·손발 스위치가 모인 **감독·개입의 주권 기관** | 거의 0 | 인간+언어 |
| **앱** | 결정화된 IBL 호출을 아이콘/GUI로 직접 조작 (부동산·도서검색 등) | 0 (코드 실행) | 결정화된 워크플로 |

**생애주기**: 새 일은 자율주행이 탐색 → IBL 흔적이 조종실 초안으로 → 검증된 고빈도 워크플로가 앱으로 결정화. *굳히는 건 증명된 것만.* 이 빈도-결정화가 "언제 시야를, 언제 한 번의 실행을"의 자동 규율이다.
→ 상세: [architecture.md](architecture.md) "사용자 표면 — 런처의 세 모드"

## 2. 표면 아래의 언어 — IBL (신경계)

세 표면이 무엇을 하든, 밑바닥에서는 전부 **하나의 문법**으로 번역된다:

```
[node:action]{params}      예) [sense:search]{query: "AI 뉴스"}
```

<!-- IBL_STATS:START -->
- **6개 노드 155 액션** = 에이전트가 세계와 맺는 관계: `sense`(지각, 43) · `self`(내 자원, 50) · `limbs`(장치·신체, 14) · `others`(소통, 17) · `engines`(생성, 9) · `table`(통화 변환 문법, 22)
<!-- IBL_STATS:END -->
  (위 수치는 빌드가 레지스트리에서 재생성 — 손 수정 금지)
- API든 크롤링이든 안드로이드든 DB든 같은 문법으로 요청 — 프로토콜 차이는 드라이버가 감춘다.
- **왜 도구 더미가 아니라 *언어*인가**: 표현력은 어휘 크기가 아니라 *조합*에서 나온다. 적게 고른 프리미티브 + 풍부한 조합 = 사실상 무한. 업계의 "자연어 SKILL.md" 대신 정합적 언어로 도구 폭증을 다스린다.
  - **조합 문법**: `>>` 순차(파이프 단축 `|`) · `&` 병렬 · `??` 폴백 · 조건/분기 **블록**(`if`/`else`/`case`) · 고차 문장 **`[table:each]{do, as}`**(찾은 것 *각각*에 IBL 문장 적용 — "각각에 대해 ~해라"를 처음으로 표현 가능하게 한 유일한 고차 변환자) · 변수 · `goal`. 중첩 실행 깊이 상한 3(더 긴 절차는 `[self:workflow]` 에 저장해 id 로 부른다 — 그쪽은 순환 금지·깊이 5).
  - **한 문장 = 한 프로그램 (2026-08-22)**: 문장이 프로그램급으로 올라갔다 — 술어 언어(`count()`/`empty()`/`matches`/`and`·`or`·`not`, AI 술어) · 오류 처리(`[try][catch][finally]`, `[on_error: skip|null]`) · 반복(`[repeat: N|until|while]`) · 상태(`$n = $n + 1` 한 줄 식) · 블록을 파이프 한 칸으로 · `$return` 반환. **어휘 증가는 `[table:reduce]` 하나뿐, 나머지는 전부 문법**이다. 범용 자료구조·재귀는 언어로 끌어들이지 않고 `[self:script]` 로 얼린다.
  - **워크플로우 = 함수**: 저장한 문장을 이름·인자(미할당 `$이름`)·반환값(`$return`)·닫힌 스코프로 부른다.
  - **어휘는 작아지면서 세졌다**: 2026-08-05~17 압축으로 163→**144**. 복합어를 지우고 보편어를 세우는 것(`pew_research`→`[sense:feed]`)·같은 개념의 낱말을 `op`/`source` 축으로 접는 것(사업 4형제→`[self:ledger]{store, op}`)이 표준 수술이다. 반대 방향의 압력은 `[self:script]`(등록 스크립트)가 받는다 — "새 낱말 만들까?"의 기본 답은 "스크립트로 얼려라".
  - **언어의 한계는 진짜 프로그램이 적발한다 (2026-08-27~28)**: 매일 손으로 돌리던 세 일간 보고서를 *한 문장 프로그램*으로 다시 쓰는 실험이 표현 공백 여덟 자리를 드러냈고(확장 경로 `${x.items.*.f}`·옵셔널 `?`·`[table:each]{on_error:"keep"}`·파이프 속 `if` 불일치=직전 통화 통과 등) 일괄 개정으로 닫혔다 — 팁 23문장·동향 24문장·부동산 21문장이 전부 품질 기준을 충족했다. 같은 시기 **실패가 위치를 갖게** 됐다: 모든 실패 봉투의 `traceback`, AI step 품질 미달을 `error_type:"quality"` 로 만드는 `criteria` 계약.
→ 명세·설계 철학: [ibl.md](ibl.md)

## 3. 어떻게 생각하는가 — 인지 파이프라인 (뇌)

자율주행 표면의 내부. 인간의 인지 과정을 모델링한다: **분류(반사) → 의식(계획) → 실행 → 평가(성찰)**.

```
사용자 메시지
  ↓ [0] 연상   해마(과거 IBL 사례) + 심층메모리(사용자 사실) 1회 검색
  ↓ [1] 반사   해마 점수 ≥ 0.85 → 곧장 실행(무의식 스킵) / 미만 → 경량 AI가 EXECUTE·THINK 분류
  ↓ [2] 의식   (THINK만) 본격 AI가 "지금 무슨 문제를 풀어야 하나" 규정 + 달성 기준
  ↓ [3] 실행   IBL 엔진 → 도구 실행
  ↓ [4a] THINK 평가   경량 AI가 달성 기준 대비 검증, NOT_ACHIEVED면 재시도(최대 3라운드)
  ↓ [4b] EXECUTE 반성 달성 기준은 없고, 실패·복잡 궤적·세계 변경이면 실행기 SelfReflect 1회
  ↓ [5] 증류   성공 경험을 해마·심층메모리에 저장 (다음엔 더 빠르게)
```

**평가값의 뜻**: GoalEval은 의식이 달성 기준을 만든 `THINK` 턴에만 돈다. `EXECUTE`/Reflex의 `evaluation_result=NULL`은 “실패”가 아니라 “GoalEval 미실행”이며, 그 갈래의 바닥은 조건부 SelfReflect다. 에피소드 판정을 읽을 때 분류와 평가값을 반드시 함께 봐야 한다.

**모델 기어**(절약/균형/최대 레버, 조종실에 노출)가 4축(분류·평가·실행·의식)을 티어(경량/중급/본격)로 매핑 — 비용/속도를 한 손잡이로 변속. 의식 토글을 끄면 THINK 경로를 차단해 빠르고 싸게 돈다.
→ 상세: [architecture.md](architecture.md) "인지 파이프라인" · 뇌 구조 대응표는 [memory.md](memory.md) 부록

## 4. 어떻게 *너의 것*이 되는가 — 메모리 (기억·직관)

메모리는 곧 **속도·비용 최적화 장치이자 개인화의 엔진**이다. 인간 기억 분류에 대응하는 **7종**:

| 인간 기억 | indiebizOS |
|---|---|
| 의미(정적 지식) | 시스템 문서 (지금 읽는 이 문서들) |
| 작업(단기) | 대화 이력 |
| 일화(경험) | 에피소드 로그 |
| 절차(방법) | IBL 액션 + **해마**(자연어→IBL 코드 자기학습) |
| 관계(사용자 사실) | 심층메모리 (선호·결정·중요날짜 자동 흡수) |
| 자기상태(항상성) | World Pulse + Self-Check |
| 공간(포식) | **포식 기억**(냄새지도 — 어디에 무엇이 사는가) |

핵심은 세세한 사실이 아니라 **직관(감)** — 요리사의 손이 소금에서 알아서 멈추듯. **해마 점수**(과거에 해본 일인가)가 인지 라우팅(반사냐 의식이냐)을 가른다. 두 자기학습 루프(해마 증류 / 심층메모리 증류)가 *쓸수록* 시스템을 빠르고 개인적으로 만든다 — 이게 핏이 쌓이는 방식이다.
→ 상세: [memory.md](memory.md) (7종 지도 + 연상기억 심층)

## 5. 철학이 만져지는 곳 — 검색/포식 브라우저 (손끝)

시야 패러다임이 기능 하나로 응축된 곳. 구글 검색창처럼 보이지만 작동이 다르다:

1. 사용자가 **판(board)의 크기 N**을 정한다 (예: 10).
2. 키워드에 대해 AI가 정답 하나가 아니라 **후보 N개**를 판에 올린다 (아주 좋을 필요 없어 경량 모델로 충분).
3. 사용자가 마음에 안 드는 것을 **지운다**. 들어가 보기도 한다.
4. AI는 지운 수만큼 **새 후보로 채운다** — 남은 것에서 취향을 읽어. (옷가게 점원이 5벌 치우면 다른 5벌을 가져오듯.)
5. 반복하는 가운데 판의 분위기가 바뀌고, 사용자는 *새로운 것을 발견*한다. 판은 통째로 **판 도서관**에 저장돼 나중에 돌아올 수 있다.

정답 AI가 가능성을 줄인다면, 이 브라우저는 *빈칸을 채워야 하므로* 계속 가능성을 늘린다. 뒤에서는 AI 에이전트가 개인적 사실(사는 곳·직업·취미·보유 자산 등, 사용자가 스스로 준 것)을 참고해 후보를 개인화한다 — 구글과 달리 **내 PC의 파일**을 읽기에 가능한 일.
→ 개념 뿌리: [memory.md](memory.md) §7 공간 기억(포식) · [vision.md](vision.md) (융합 vs 자율)

## 6. 어떤 몸에 사는가 (체현)

- **소유**: 네 PC에서 도는 개인 소유 프로그램. 하드웨어도 정보도 네 통제 아래. (중앙 SaaS 아님.)
- **능력**: IBL 노드의 실제 구현체 = **도구 패키지**(폴더 기반 동적 로딩). 설치/철거가 코드+어휘를 원자적으로 넣고 뺀다. → [packages.md](packages.md)
- **여러 몸**: PC(허브)와 폰이 각각 독립 자아(폰=온디바이스 두뇌)이고, 낯선 PC 도 USB 손발로 잠깐 몸이 된다. 사용자 세계-데이터(연락처·일정·비즈니스)는 CRDT로 공유·동기화, 각 자아의 주관적 기억(대화·해마)은 사적. **사전도 몸마다 다르다** — 설치된 몸은 자기 어휘만 갖는다. → [architecture.md](architecture.md) · [communication.md](communication.md)
- **몸끼리**: 특권 배관 대신 **명함**(`/nodes/card`)과 **자연어 부탁**(`[others:ask]`) — 받는 몸이 자기 사전으로 컴파일해 실행한다. 특별함은 배관이 아니라 **이웃 등급**이다.
- **소통**: Gmail·Nostr(NIP-17 DM) + 탈중앙 망 **IndieNet**. AI와, 이웃과, 에이전트끼리 소통. → [communication.md](communication.md)
- **자기 몸의 변화를 기억한다**(몸 원장, 2026-08-21): git(추적 파일의 사건) + 쓰기 관문 원장(런타임 쓰기)을 `[self:body]{op}` 어휘로 회상한다. 몸이 바뀌면 몸에 대한 가정이 깨지므로, 변화 자체가 연상 가능한 기억이어야 한다 — 실제로 층 구조 개편이 회상 불가능해 낡은 가정이 6주 잠복한 사건이 계기였다. 행위자(누가·무슨 과제로·어디서)가 실려 "이 파일 왜 바뀌었나"가 한 호출에 닫힌다. → [architecture.md](architecture.md) '몸 원장'

## 7. 어떻게 세상에 열리는가 — 공유창고 (얼굴)

기억과 능력이 안쪽이라면, 창고는 **바깥쪽 얼굴**이다. 발행 행위는 하나뿐: **폴더에 파일을 놓는다.**

- `공유창고/0..4/` 가 노드의 맨 주소에서 그대로 서빙된다 — 색인도 변환도 없이 바이트 그대로(해석은 읽는 쪽 AI 몫).
- 폴더에 적힌 숫자가 곧 문이다. 방문자 등급 0~4 는 이웃 CRM 등급과 **같은 자**이고, 등급 위 파일은 403 이 아니라 **404**(존재 자체가 정보).
- 사람은 브라우저로, **남의 AI 는 `/manifest`(JSON)로** 읽는다. 계약은 `/manifest` + `/f?path=` + 쿠키 로그인 셋뿐 — indiebizOS 자체가 계약이 아니다.
- 읽는 쪽엔 **이웃 창고 피드**(30분 폴러, 모델 호출 0)가 있고, 방언 어댑터가 nginx 색인·RSS·Nextcloud·일반 웹페이지를 같은 통화로 정규화한다 — 이웃이 아무것도 설치하지 않아도 편입된다.
- **묻는 쪽이 낸다**: 주인은 파일만 놓고, 검색·거르기·렌더는 방문자 쪽 AI 가 자기 하드웨어로 한다. 그래서 서빙 비용이 ~0 이고, 문은 "사람이냐 봇이냐"가 아니라 **"너는 누구냐(등급)"**만 묻는다.
→ 상세: [communication.md](communication.md) "공유창고"

## 닫으며 — 다시 한 문장으로

도구는 인간의 시야를 **가리기보다 넓혀야** 한다. 세상엔 정답이 있는 문제도 있지만, 중요한 문제일수록 사람의 질문 자체가 애매하고 자신도 뭘 원하는지·뭐가 가능한지 모른다. 그럴 때 필요한 건 정답을 뽑아 주는 자율주행이 아니라, 열린 마음으로 함께 좁혀 가되 결정에서 인간을 빼놓지 않는 외골격이다. 위의 모든 기관 — 3표면·IBL·인지·메모리·검색 브라우저·창고 — 은 결국 **이 한 신념의 파생**이다. 나중에 지어낸 철학이 아니라, 이미 만들어진 몸을 서술한 것이다.
