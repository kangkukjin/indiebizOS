## 괄호 병렬 분기의 변수

`($기술 >> [table:take]{n:-6}) & $사례`를 파이프 머리·맨몸 병렬 변수와
같은 방출기로 파싱하고 실행한다. 괄호 안 변수의 바인딩을 바깥 병렬 step이
모아 전달하며, 실행 때 사본에 값을 싣는다. 괄호형 참조·경로 참조·함수 슬롯도
같은 규칙을 따른다. 출력 포맷터도 변수 표기를 보존한다. 미할당 변수는 실행
전 오류이며, 폴백의 시도 전용 규약과 중첩 분기·블록 제한은 유지한다.

## each의 산문 결과

`collect:true`는 이미 존재했다. 따라서 결과의 기본 의미를 바꾸거나 새 어휘를
추가하지 않았다. do의 산문 결과를 모을 때 collect를 켜도록 어휘 설명과
기본 프롬프트·보고서 가이드에 명시했다. 문자열 산문은 value 열, 객체 결과는
그 키로 보존한다. 충돌 키의 접미사·신고 규약은 종전과 같다.

정적 검사기는 do가 확정적으로 산문을 내고 collect가 꺼져 있으면 실행 전
경고한다. 런타임의 passthrough 안내도 collect 처방을 포함한다. 효과만 실행하고
원 행을 넘기는 기존 each는 계속 사용할 수 있다. 실제 산문 수집 회귀는 순차와
병렬 각각 4행을 넣어 요약 4개가 남는지 확인한다(외부 API는 대체).
