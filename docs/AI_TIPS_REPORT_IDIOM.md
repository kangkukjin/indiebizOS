# AI팁보고서쓰기

영상 선정 → 자막에서 팁 추출 → 보고서 작성과 로컬 저장을 수행한다.
정본은 `data/idioms/ai_tips_report.ibl`, 연결 코드는 `data/scripts/ai_tips_report.py`다.
일상 사용법은 `data/guides/youtube_ai_tips_report.md`를 따른다.

## 호출

입력은 `설정` 객체 하나다. `topic`, `date(YYYY-MM-DD)`, `root(절대경로)`는 필수다.
`mode`는 draft(기본) 또는 commit, `reader_context`와 `run_id`는 선택이다.
이름·서명은 유지하며 기본 회차는 날짜·주제·v4로 정한다. 이전 상태는 자동 변환하지 않는다.

결과 items 한 행에 status(`draft` 또는 `committed`), report, evidence(실행 상태),
report_hash, new_tips, tips, videos, candidates, checked를 반환한다. published는 false다.
HTML·공유창고·알림은 호출자의 후속 작업이다.

## 흐름

1. 짧은 AI 호출로 검색어 2~3개를 만든다. 검색 결과에서 기존 영상 ID를 제외한다.
2. 메타데이터로 180일 이내 날짜를 확인하고 AI가 관련 영상 몇 편을 고른다.
3. 자막을 읽고 AI가 팁의 제목·구체 방법·주의점을 함께 추출한다.
4. AI가 추출 결과를 골라 보고서로 작성한다. 코드는 출처 연결·건수·파일을 조립해 저장한다.

별도 제목 추출, 원문 색인, 상세 재추출, 내용 검토, 최종 심사, 자동 재작성은 없다.
인용문·타임스탬프는 생성하거나 검증하지 않는다. 모델은 읽은 자막에 근거해 쓰고,
확인되지 않은 방법은 제외하거나 불확실하다고 설명한다. 출처 ID와 저장 형식만 코드로 확인한다.
누적 팁은 모델에게 보내지 않으며 과거와 같은 팁도 허용한다.

짧은 영상 N편의 정상 경로는 모델 호출 N+3회(검색어·선정·영상별 추출·작성)다.
긴 자막만 32,000자 단위로 나누고 경계 문맥을 겹쳐 읽는다. 전체 핵심 범위는 보존하며
그 결과를 바로 작성에 사용한다. 별도 위치 색인이나 추가 심사는 없다.

일부 검색·메타데이터·자막·추출 구간이 실패하면 나머지 자료를 쓰고 한계를 표시한다.
자료나 팁을 하나도 얻지 못하면 실패로 종료한다. 실패 자료를 성공으로 바꾸지 않는다.
보고서에는 자막을 읽은 영상만 표시한다. 보고서에 팁을 쓴 영상, 끝까지 추출했으나
소개할 팁이 없던 영상만 처리 원장에 넣는다. 선택하지 않거나 실패로 팁을 얻지 못한
영상은 다음에 다시 다룰 수 있다. 기존 원장의 ID는 계속 제외한다.

## 재개와 저장

스크립트 op는 start → queries → search → metadata → videos → transcripts →
compose → finish다. 추출 중 extracted_part가 구간 결과를 즉시 저장한다.
완료한 단계는 같은 설정의 재진입에서 외부 호출을 반복하지 않는다.
운영 파일을 쓰는 동안 중단되면 준비된 본문·원장과 저널로 이어 저장한다.
원장이 달라졌거나 같은 이름의 보고서가 있으면 덮어쓰지 않는다.

draft는 로컬 실행 폴더의 draft.md만 만든다. commit은 파일 잠금과 전후 저널로
영상 원장·팁 DB를 먼저 반영하고 md를 마지막에 저장한다. 원자적인 다중 파일 DB가
아니므로 중단 시 저널을 사용한다. ‘committed’만 로컬 반영 완료다.

이전 실행 방식과 중단 증거는 Git 이력과 실행 폴더에 보존한다. 폐기한 검수 단계나
그 판정을 새 성공 조건으로 가져오지 않는다.

## 등록과 검증

스크립트 ID `AI팁보고서`, 관용구 이름 `AI팁보고서쓰기`를 유지한다.
`python3 scripts/register_idiom.py --update AI팁보고서쓰기 --body data/idioms/ai_tips_report.ibl --reason "변경과 검증"`
으로 개정하며 상시 소개로 승격하지 않는다.

테스트: `.venv/bin/python3 -m pytest data/scripts/test_ai_tips_report.py`.
실제 IBL 이름 호출·each·스크립트·저장을 사용하고 외부 검색과 AI는 고정한다.
실제 모델의 품질·전체 소요 시간·토큰 절감은 고정 응답 테스트만으로 확정하지 않는다.
