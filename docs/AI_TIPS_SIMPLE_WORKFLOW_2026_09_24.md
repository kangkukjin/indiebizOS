# AI 팁 가이드와 관용구 단순화 — 2026-09-24

사용자가 요구한 일은 최근 영상 몇 편을 골라 팁을 추출하고 보고서로 보여주는 것이다.
기존 가이드는 이를 다섯 갈래 검색·제목 추출·원문 색인·후보 선발·상세 재추출·영상별
내용 검토·편집·최종 심사·자동 재검토로 확대했다. 정상 인용도 자막 경계 대조에서
실패했고, 그 대조를 고치는 것만으로는 불필요한 절차가 줄지 않았다.

## 새 계약

- 최근 영상 2~4편 선정 → 자막에서 팁과 구체 방법을 함께 추출 → 보고서 작성.
- 2~3개 검색어를 권장하되 정해진 검색 갈래를 채우지 않는다. 후보가 적으면 한 편도 사용한다.
- 별도 인용문·시간 대조, 원문 위치 색인, 제목/상세 이중 추출, 내용 심사와 최종 심사,
  자동 재작성·재검토를 제거한다. 자막에 없는 방법·효과는 만들지 않는다.
- 출처 링크, 180일 이내 업로드 날짜, 같은 영상 ID 중복 방지, 보고서 안의 반복 정리는 유지한다.
  과거 팁과의 의미 비교는 하지 않는다.
- 일부 자료가 실패하면 읽은 자료에서 얻은 팁을 쓰고 실패 범위를 표시한다.
  추출 실패로 팁을 얻지 못한 영상은 완료 원장에 추가하지 않아 다음 조사 기회를 남긴다.
  일부 구간의 팁이라도 보고서에 썼으면 영상 ID를 기록해 같은 영상을 다시 쓰지 않는다.
  자료나 팁이 전혀 없으면 생성 실패로 반환한다.
- 긴 자막만 32,000자 단위로 순서대로 읽는다. 경계 문맥을 겹치며 본문을 버리지 않는다.
- 파일 잠금·완료 단계 재사용·구간 결과 저장·중단된 저장 복구를 유지한다.
  완료 보고서나 다른 작업의 원장을 덮어쓰지 않는다.

가이드는 17,098자/199줄에서 3,305자/86줄로 줄였다. 등록 설명과 구현 문서도 같은
계약으로 갱신했다. 과거 사고·수리 기록은 역사로 보존하며 현재 실행 지시로 쓰지 않는다.
스크립트의 검색 재시도·원문 색인 보조 모듈은 삭제하고 저장 부품만 분리했다.

## 등록과 적용

관용구 이름 `AI팁보고서쓰기`, 입력 `설정`, 결과 items 한 행을 유지한다.
상태는 v4이며 기본 회차 ID에 v4를 붙인다. 기존 v3 실행은 보존하고 자동 변환하지 않는다.
초안 상태는 `draft`, 로컬 반영 완료는 `committed`다. 공개·알림은 관용구 밖의 후속 작업이다.
해마 예제 ID 4845, 개정 20의 본문·items 반환형과 저장소 정본의 일치를 확인했다.
등록 스크립트는 파일을 매번 실행하고 관용구는 이름 호출에서 DB를 읽으므로 백엔드 재기동이 필요 없다.

사용자 요청으로 중단한 운영 보고서를 재개하거나 공유·알림을 시작하지 않았다.

## 검증 범위

`data/scripts/test_ai_tips_report.py`는 외부 검색·YouTube·AI만 고정 응답으로 대체하고
실제 IBL 이름 해소·each·스크립트 입력·파일 저장을 실행한다. 26개 통과.

- 두 영상의 정상 경로에서 모델 호출 5회(검색어 1, 선정 1, 추출 2, 작성 1).
- 검색 일부 실패, 오래되거나 날짜가 불명확한 영상, 기존 영상, 자막 부재와 부분 자막,
  긴 자막 끝부분, 파일·스필로 외부화된 자막, 일부 추출 실패와 팁 0개.
- 초안/저장 구분, 출처 ID 위조 거부, 완료 재호출, 작성 실패 후 완료 단계 재사용,
  저장 중단 복구, 원장 충돌·기존 보고서 보존, 이전 상태 보존, items 반환 계약.

실제 모델의 보고서 품질이나 운영 완료 시간·토큰 절감률을 측정한 것은 아니다.
호출 수 감소와 문서 분량 감소만으로 그 성과를 확정하지 않는다.

은퇴 계약 검사와 `build_ibl_nodes.py --check`가 통과했다. 배포 매니페스트는 삭제한
검색·색인 부품을 은퇴 목록으로 옮기고 새 저장 부품을 포함하도록 생성기로 갱신했다.

정본 맥의 전체 백엔드 회귀: **5,775 통과, 1 건너뜀**(509.46초).
로그 `/tmp/ai-tips-simple-backend-native.log`, JUnit `/tmp/ai-tips-simple-backend-native.xml`.
