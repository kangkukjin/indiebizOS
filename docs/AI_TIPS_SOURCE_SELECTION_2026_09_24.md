# AI 팁 선정에서 출처·인기·가치 판단의 인계

## 문제와 원인

검색된 모든 영상에서 팁을 먼저 추출하고 있지는 않았다. 기존 관용구도 후보 메타데이터를
조회하고 2~4편을 고른 다음 그 영상만 자막을 추출했다. 문제는 영상 정보 도구가 얻은
조회수를 보고서의 metadata 단계가 버렸고, 영상과 팁의 선정 계약에 출처·인기의 구체적인
판단 근거가 없었다는 점이다. 뒤의 검토가 엄격해도 앞 단계에서 사라진 증거는 복원되지 않는다.

중단된 episode 4011의 선택 영상 네 편 모두 state에는 조회수가 없었다. 선택 영상 중
K05xgAhhpqc를 새 도구로 한 번 조회한 결과는 조회 3회, 채널 구독자 2,870명이고 좋아요·댓글은
미확인이었다(2026-09-23T22:40:20Z 관측). 이는 옛 실행 시점의 수치를 재구성한 것이 아니다.
작은 영상이라는 이유만으로 팁이 무가치하다고 결론낼 수도 없다. 하지만 그 정보를 전달받고
선정 이유를 설명하는 것과 아예 보지 못하는 것은 다르다.

## 구현된 흐름

1. 검색 후보의 기존 info 호출에서 발행 채널·업로더·ID·URL·설명·조회수·좋아요·댓글·구독자·
   인증·조회 시점을 보존한다. 제공되지 않은 수치는 null이며 실제 0과 구분한다.
2. AI가 날짜·길이·검색 층 제약 안에서 출처와 반응을 판단해 영상을 먼저 고른다. 설명은
   발행자의 자기주장이고 발췌임을 알리며, 전문성·경력·평판을 추측으로 만들지 않는다.
   경과일·주제·언어·채널 규모를 고려한다. 고정 인기 점수나 조회수 커트라인은 추가하지 않는다.
3. 선택 영상에만 자막·1차 팁 추출을 요청한다. 후보 팁의 중복 비교 뒤, video_id로 연결한
   출처·인기 자료와 구체 행동·근거·조건·독자 효용을 종합해 AI가 팁을 선발한다.
4. 선정 영상은 출처·인기 판단, 채택 팁은 출처·인기·가치 판단을 각각 짧은 문장으로 남긴다.
   탈락 항목은 결정적인 이유만 남겨 불필요한 출력 확장을 줄인다. 필수 판단이 빠지면
   다음 단계와 원장 반영을 막는다. 독립 내용 검토·편집·최종 검수에도 같은 자료를 전달한다.
5. 보고서에 영상별 수치·관측 시점·출처/인기 판단 및 팁별 선정 가치 판단을 표시한다.
   실제 팁의 발언자가 발행 채널과 같다고 단정하지 않는다. 인기·인증으로 빈약한 실행법을
   통과시키거나 정확성을 보증하지 않는다.

## 비용과 재사용 경계

도구의 결과 보존은 일반적인 sense:video 계약이고, 업무 판단은 ai_tips_selection.py의
관용구 부품이다. 새 어휘나 실행기의 AI 팁 전용 분기를 만들지 않았다. 외부 메타데이터 조회나
AI 단계를 추가하지 않고 기존 호출에서 받은 정보와 기존 판단 단계를 사용한다.

설명문 원본은 input-metadata.json에 보존한다. AI용 설명은 1,200자 이내이고 영상 선정 요청은
600→300→150→0자로 공평하게 발췌 길이를 조절해 입력 상한을 지킨다. 발췌 여부와 원 길이를
명시한다. 후보나 수치·신원을 조용히 제외하지 않으며 기본 정보만으로 상한을 넘으면 실패한다.
조회와 모델 호출 횟수를 늘리지 않았다는 뜻이지 추가 토큰이 0이라는 뜻은 아니다.

새 metadata 단계는 selection_policy=2를 기록한다. 이미 끝난 옛 단계의 영수증을 무효화하거나
새 판단이 수행됐다고 소급하지 않는다. 중단된 보고서는 재시작하지 않았다. 향후 옛 실행을
재개할 때 새 선정 기준까지 적용하려면 메타데이터 수집·선정부터 새 실행으로 수행해야 한다.

## 검증과 한계

- 관련 회귀 155개 통과: 도구 결과→IBL items→영상 선정→팁 선정→검수→본문의 전달,
  0/미확인 구별, 누락 판단 차단, 많은 후보의 설명 발췌 및 후보 보존을 검사했다.
- 정본 맥 전체 backend 회귀 5,775개 통과·1개 건너뜀(495.12초). 추가 가이드/탈락 항목
  계약 검사 15개 통과, 어휘·배포 매니페스트·Android 번들 검사 및 문서 드리프트 검사 통과.
  관리 재시작 결과 restarted, 중단한 작업 없음. 이후 /health 정상·활성 작업 0건 확인.
- 백만 조회 영상보다 실용 근거가 좋은 작은 영상을 고르는 AI 판정을 코드가 허용하는지,
  그 결과의 선택 영상만 추출 대상으로 전달되는지 확인했다. 이는 모형 응답을 사용한
  흐름 검증이며 실제 모델이 항상 좋은 선택을 한다는 증명은 아니다.
- 실제 유튜브 한 편의 공개 정보를 받아 IBL items 행까지 수치와 출처가 보존됨을 확인했다.
  채널 경력·평판의 외부 검증, 실제 모델의 선택 품질 개선, 전체 실행 시간·토큰 절감률은
  이번 작업에서 실측하지 않았다.
- sense:video 용례 58건을 검토했다. 반환 필드 추가와 unknown 보존으로 입력 문법은 바뀌지
  않는다. 기존 원시 용례의 구판 문법·날짜 비교 문제는 코퍼스 판본 격리의 기존 범위다.
