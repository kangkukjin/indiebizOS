# AI 팁 보고서: 영상 단위 중복 방지로 요구 범위 복원

사용자 요구는 같은 영상을 두 번 다루지 않는 것이다. 다른 영상이 과거 보고서와 같은 팁을
말하는 것은 허용한다. 이를 누적 팁 전체와 의미 비교해야 한다는 요건으로 확대해 해석했다.
그 뒤 비교 상한·분할·불확실 판정·복구·최종 검수 인계를 개선하면서 불필요한 작업을
더 복잡하게 유지했다. 부분 구현의 정확성보다 먼저 필요한 단계인지 확인했어야 한다.

## 변경

- 검색 결과에서 다룬 영상 ID를 코드로 제외하는 기존 관문을 유지한다.
- 출처·인기·최신성으로 영상 2~4편을 먼저 고르고 그 영상만 자막·팁을 추출한다.
- 누적 팁 제목의 1차 추출 주입, 직전 보고서 본문의 질의 생성 주입, 누적 팁 전건 비교,
  비교 재시도 및 비교 기록의 후속 검수 전달을 제거한다. 옛 비교 함수도 삭제한다.
- 원문 구간 색인 다음 곧바로 이번 후보를 선발한다. 선발과 최종 검수는 이번 보고서
  내부의 불필요한 반복만 검토한다. 출처·인기·실용 가치, 상세 추출, 원문 근거·시점,
  적용 조건, 독립 내용 검토·최종 검수·추가 공식 근거·내용 보완 1회는 유지한다.
- 누적 DB는 보존·덧붙이기·건수 계산·저장 충돌 검증을 위해 로컬 코드만 읽는다.
  과거 팁의 제목·본문·판정은 모델에 보내지 않는다. 원장 파일을 지우거나 초기화하지 않는다.
- 상태는 v3다. 옛 v1/v2 영수증은 보존하며 새 판정으로 인정하지 않는다. 기본 run_id에
  -v3를 붙이고 옛 run을 명시 재개하면 새 run_id를 요구한다. 같은 v3 실행의 성공한
  외부 호출과 원문 구간 영수증은 재진입에서 재사용한다.
- 호출 이름·입력 슬롯은 유지하여 등록 관용구의 본문을 개정한다. 가이드·스크립트 설명·
  최종 검수 이름도 같은 요구 범위로 바꾼다. 과거 비교 구현의 테스트는 Git 이력에 남기고,
  현재 테스트는 과거 내용이 AI 입력에 들어오지 않는 것을 검사한다.

## 공통 교훈과 범위

이번 문제는 실행기가 비교를 못한 문제에 앞서 업무 요건을 확대 해석한 문제였다.
정확한 식별자로 끝나는 중복 방지를 의미 비교로 강화하는 것은 자동으로 품질 향상이 아니다.
파이프라인의 실패를 고칠 때 해당 단계가 사용자 목표에 필요한지 먼저 확인한다.
목표와 무관한 작업은 분할·재시도·검색 최적화보다 제거가 우선이다.
이번 수정은 업무 관용구·교재의 정책 수정이며, 새 언어 기능이나 범용 중복 알고리즘을
추가하지 않는다. 다른 업무에도 같은 정책을 일괄 강제하지 않는다.

## 검증

- 실제 IBL 이름 호출과 고정 외부 응답을 쓰는 회귀 92개 통과. 누적 팁 0/655/2,000개에서
  동일한 두 영상의 실행은 table:ai 7회·struct 4회로 같다. 과거 팁과 같은 제목·방법도
  채택 가능하며 이전 원장을 보존한 채 이번 팁이 덧붙는다. 완료 재진입은 새 호출 0회다.
- 정본 맥 backend 전체 회귀 5,775개 통과·1개 건너뜀(492.84초), 문서·계약 회귀 39개
  통과. 기존 팁과 제목·방법이 정확히 같은 사례를 보강한 3개 검사도 통과했다.
  어휘·배포 매니페스트 검사, 은퇴 계약 검사, 문서 드리프트 검사가 통과했다.
- 과거 팁·직전 보고서에 식별 문자열을 넣어 모든 AI 요청에서 부재를 확인했다. 기존
  영상 ID는 메타데이터와 자막 요청 모두에서 제외된다. 최종 검수는 이번 호 중복 실패를
  계속 차단한다. 옛 상태·은퇴한 비교 op로 우회할 수 없고 옛 파일은 변경되지 않는다.
- episode 4010의 저장된 실제 28개 후보·655개 누적 팁으로 요청 준비를 재현했다.
  과거 팁 비교 요청은 0개이고 이번 후보 선발 요청 한 개만 준비된다. 원 실행 상태와
  운영 원장은 수정하지 않았다. 재현 출력: outputs/tips_video_only/selection_probe.json.
  해당 선발 요청은 실제 직렬화 기준 8,272자다. 이를 토큰 수로 환산하지 않는다.
- 등록 DB의 관용구 id 4845·서명 설정·always_on=0을 유지하며 본문 일치를 확인했다.
  이전 본문·실적은 개정 이력에 남고, SQLite 백업은 data/_backups/2026-09-24_ai_tips_video_only/에 있다.
  스크립트와 등록 정의는 다음 호출에서 새로 읽는다. 보고서 재실행이나 백엔드 재시작은 하지 않았다.
- 실제 모델의 총 토큰·완료 시간은 재측정하지 않았다. 제거한 비교·보완 호출의 부재와
  누적 팁 규모가 AI 입력·호출 수를 키우지 않는 것은 확인했으나 전체 절감률로 환산하지 않는다.

대체한다. 과거 수리 기록과 원 보고서의 증거는 변경하지 않는다.
