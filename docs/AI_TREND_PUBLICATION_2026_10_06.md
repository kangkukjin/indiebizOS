# AI 동향 보고서의 작성 후 발행과 읽기 화면

## 원인

10월 6일 원격 정기보고 앱 요청은 `task_sysai_7b4fe366`에서 Markdown을 저장했지만
공유창고를 갱신하지 않았다. 가이드가 HTML을 선택 사항으로 안내했고 의식의 완료 기준도
로컬 저장에 한정됐다. 기존 `warehouse_publish_report` 일정은 05:30에만 돌았으므로
그 뒤 수동 작성한 보고서가 반영되지 않았다.

기존 일정은 공유판을 먼저 삭제한 뒤 `table:document`로 변환·복사했다. 실제 공유 파일은
10월 5일판이었고 viewport가 없으며 원문의 강조와 출처 링크가 소실돼 있었다.

## 변경

- 앱 요청·가이드·기존 04:00 작성 일정에 Markdown 저장과 공유창고 HTML 발행을 함께 명시한다.
  사용자가 비공개 초안만 요청하거나 NEW가 0건인 경우에는 기존 공유판을 보존한다.
- 등록 스크립트 `AI동향발행`은 명시한 저장 원문 또는 파일명 날짜가 최신인 보고서를 골라
  `공유창고/0/오늘의 AI 보고서.html`을 만든다. 조사나 모델 호출·알림은 추가하지 않는다.
- 기존 05:30 보완 일정도 같은 스크립트를 호출한다. 파일을 먼저 삭제하지 않으며 렌더 성공 후
  같은 폴더의 임시 파일을 원자적으로 교체한다. 감독 턴의 검수 대기·승인 공개 규약은 유지한다.
- 공통 `보고서HTML`의 `briefing` 테마는 원문 본문을 보존하며 목차·요약·기사 구획과
  모바일 17px 본문, 밝은 화면·다크 모드, 끊기지 않는 날짜 표기를 제공한다.
  기존 AI 팁 등의 `plain`·`card` 테마는 계속 사용할 수 있다.
