# Android 하드웨어 컨트롤

2026-10-18. 사용자가 앱으로 기기를 제어하고 AI도 같은 실행 코드를 재사용한다. 콘텐츠·음악·앱별 제어는 이 기본 기능 위에 별도로 조합한다.

## 구현

- 데스크톱 `PhoneControlInstrument` + `PhoneControlExtras`, 원격 표면 `data/instruments/phone_control.yaml`.
- 공유 실행 파일은 `phone_control.py`(음량 종류·진동)와 `phone_device.py`(하드웨어 기본 기능). 기존 guestpc Python 계약으로 전송하며 새 IBL 어휘는 없다.
- 음량은 Android AudioManager를 호출하고 종류별 복원 기록을 분리한다. 화면·설정·손전등·센서는 `RemoteDeviceCalls.hardware` → `HardwareControl`을 사용한다. 리소스를 소유해야 하는 손전등은 상주 프로세스에 유지한다.
- 화면 켜기는 독립 Activity로 요청하며 잠금을 해제하지 않는다. 화면 끄기는 접근성 잠금 동작이다. 밝기·회전·자동 꺼짐은 WRITE_SETTINGS 특별 접근을 확인한다. 권한 화면을 여는 버튼이 있지만 허용은 사용자 조작이다.
- 한 변경의 적용과 관측은 원격 요청 한 번으로 끝낸다. 응답을 잃으면 자동 재시도하지 않는다. `success`와 `verified`를 구분한다. 센서 리스너는 제한 시간 후 반드시 해제한다.
- 원격 장치 소개에는 Android용 `control_guide="android_control.md"` 포인터만 넣는다. 가이드는 `data/guide_db.json`에도 등록한다. 현재 문맥에 있는 계약을 다시 읽거나 코드를 재생성하지 않도록 안내한다.
- Wi-Fi·블루투스 전환과 기기 종료·재부팅은 제공하지 않는다. 전원·네트워크는 관측한다. 구형 APK는 기본 상태만 반환하고 새 명령은 업데이트 필요 오류를 낸다.

## 검증

- 변경 영향 선택기: 230개 기존 시험 파일(32%) + 신규 `test_phone_device.py`. 비system 연관 회귀 3,433개 통과. 저장소 전수·모든 system 검사를 실행한 결과는 아니다.
- 직접 검사 28개 통과: 음량 복원과 종류별 격리, 진동 범위, 기존 APK의 읽기 전용 호환, 권한·통신 실패의 비재시도, UI 결과 봉투, 원격 앱의 모든 버튼 IBL 컴파일, 가이드 포인터.
- TypeScript 검사와 Vite 빌드 통과. 브라우저 모의 기기로 대상 선택, 음량 종류 변경, 밝기 변경 1회당 요청 1회, 센서 결과 표시, 390px 화면 넘침 없음 확인.
- Android arm64/arm32 debug APK 0.14 빌드와 기존 JVM 단위 검사 24개 통과. 신규 하드웨어의 물리 동작을 JVM 검사만으로 확인했다고 보지 않는다.
- 실제 예나폰 구형 APK에서 같은 `phone_device.py`로 상태 조회 성공: 5.72초, hardware_control=0. 모델을 거치지 않은 원격 왕복 시간이며 과거 AI 작업과 통제된 속도 비교는 아니다.

## 배포

0.14 APK를 기존 서명으로 검증하고 중앙 arm64/arm32 채널에 발행했다. 데스크톱 빌드와 불변 화면 판본을 갱신했다. 설치 요청 접수와 새 APK 인증 재접속을 구분한다. 최종 실폰 배포 결과는 변경 이력에 기록하며, OS 승인·설치가 완료되지 않은 폰의 신규 하드웨어 동작은 미검증이다.

배포 확인: 삼성0은 `INSTALL_FAILED_ABORTED: Self update is blocked by unknown source package`, 예나폰은 진행 중인 화면 공유로 `phone_update_busy`. 삼성1은 앱 설치 허용이 없는 상태다. 새 하드웨어 기능은 세 폰 모두 설치 후 실기 확인이 남는다. 업데이트 실패를 우회해 OS 권한을 바꾸거나 진행 중인 화면 공유를 종료하지 않았다.

추가 실기 확인: 삼성1에서 미디어·알람·벨소리·알림 네 음량을 한 원격 작업으로 조회하여 3.94초에 응답했다(변경 없음). 삼성0에는 전송된 APK의 SHA-256을 검증한 뒤 `Download/IndieBiz-0.14.apk`(82,816,656바이트)를 준비했다. 파일 준비는 설치 완료가 아니다.
