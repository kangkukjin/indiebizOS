# 외부 웹앱 전환 감사 — 4단계

앱 선언과 외부 지원 매니페스트를 대조했다. 기준은 동작의 입력·실행 자원·출력 수신자다. 주인 앱을 숨긴 것을 전환 완료로 세지 않는다.
외부에서 지원되는 기능은 기본으로 사용할 수 있고, 사람별 기능 목록을 따로 만들지 않는다.

## 이번에 연결한 앱

모든 조회·제작·행 클릭·행 버튼·선택 목록은 서버가 현재 선언을 찾아 해소하는 동작 ID로 요청한다.
주인용 IBL 렌더러의 보기 문법을 유지하고 실행 어댑터만 바꿨다. 별도 도구 엔진을 만들지 않았다.

| 앱 | 요청 동작 | 허브가 사용하는 자원 | 사용자 기기 작업·결과 위치 | 관리 기능·전환 판정 |
|---|---|---|---|---|
| 정기보고 | 공개 자료 조사·작성, 내 보고서 목록·본문 | 공개 검색·원문 HTTP·회원 모델, 요청별 임시 공간 | 브라우저 reports에 지문 확인 후 보관·내려받기 | 주인 스케줄·시스템 AI 제작은 호출하지 않음. 공개 주제 보고서 흐름 전환, 주인 전용 제작 레시피까지 이식한 것은 아님 |
| 라디오 | 한국 방송 목록·세계 방송 검색·행 재생·정지 | 기존 공개 방송국 조회·스트림 URL 해소 | 요청한 브라우저 audio로 재생·정지 | 주인 즐겨찾기는 미전환. 회원용 목록/검색/재생 경로 연결 |

| 문서 | 파일 선택·읽기·양식 항목 조회·선택 항목 채우기 | 선택한 PDF/Word/Excel/텍스트만 임시 처리 | 선택 파일과 완성 문서를 브라우저에 보관·내려받기 | 주인 파일 경로·문서 폴더·오피스 계정 없음. PDF/Word 양식은 한 항목씩 입력 가능; 복수 항목 작업은 채팅에서도 가능 |
| 공개 웹 검색 | 검색·검색 결과의 원문 읽기 | 감사된 공개 검색·공개 HTTP 텍스트 | 검색 결과와 본문은 해당 작업 화면 | 주인 로그인 브라우저·신문 발행·검색 기억 없음 |
| 내 위치 | 현재 위치 확인 | 인증된 요청과 측정 결과 전달 | 요청 기기의 브라우저 위치 API; OS 권한은 측정 시점에 요청 | 주인 PC 위치를 대신 사용하지 않음 |

## 기존 주인 앱 전체 대조

다음은 **미전환 또는 주인 관리용**이다. 웹 카탈로그에서 빠진 사실을 구현 완료로 표시하지 않는다.
아래 앱을 여는 데 필요한 개인 DB·인증·캐시·파일 자원의 회원별 어댑터가 없으므로, 이번 외부 웹앱의 지원 기능으로 내보내지 않는다.
이 목록의 확장은 별도 앱 전환 작업이며, 채팅/앱 공통 요청과 기기 전달을 다시 설계할 필요는 없다.

## 공통 표면 계약

- 자율주행은 클라이언트 담당 에이전트와의 채팅, 앱은 같은 담당 경로의 선언된 동작 호출이다.
- 앱 조회·버튼·행 클릭은 그 앱의 같은 작업에 이어 붙인다. 선택 목록을 순서대로 처리하여 동시 기기 작업과 충돌하지 않는다.
- 질문은 앱 화면 위에서도 보이고 그 자리에서 답한다. 이전 요청 ID로 연결해 원래 산출물 계약을 유지한다.
- 접수·처리·답변 대기·완료·중단·연결 끊김과 결과 파일은 두 표면의 공통 영역에 표시한다.
- 중단 시 대기 중이던 앱 실행도 취소하며, 이미 저장된 파일은 유지한다. 새로고침 뒤 자동 재실행하지 않는다.
- 브라우저 위치/재생에는 별도 기능별 승인 대화상자를 얹지 않는다. OS 위치 권한과 브라우저 재생 정책은 기기 동작 시점에 따른다.
- 파일은 선택 시 이 기기의 작업 공간으로 가져온다. 서버의 절대경로를 입력받거나 허브의 업로드 폴더에 영구 보관하지 않는다.
- 주인 초대창의 이름 입력/기존 사람 선택 → URL·키 발급은 이전 구현을 유지한다.
