# 의식·실행·중간감사의 책임 축소 — 2026-11-07

연구 에피소드 5892는 작은 고정 과제에서 추가 의식·감사의 품질 우위를 확인하지 못했고,
의식이 덧붙인 조건이 감사·계승을 통해 보존되는 현상을 관측했다. 사용자는 새로운 규칙이나
평가자를 추가하지 않고 중복 책임과 옛 계약을 제거하도록 요청했다.

## 현재 책임

- 의식: 사용자 원래 목적·정정과 관련 맥락을 복원하고 실행할 요청을 정리한다.
- 실행자: 방법·도구·계획 선택, 조사·제작·검산·보완, 결과와 한계 제출.
- 중간감사: 새 관측에 따라 필요한 방향 수정. 교정은 findings 한 곳에 기록한다.
- 선택적 최종 평가: 원래 사용자 목표·정정과 최종 응답·제출물 비교. 이전 수리의 범위를 유지한다.

의식 출력의 achievement_criteria와 criteria 중복을 criteria 한 표현으로 통합했다.
과거 기록은 수정하지 않고 읽는 경계에서 투영한다. 부분 인용 일치로 생성된 기준 전체에
source=user 권위를 부여하지 않는다. expert_choice·imagined_ibl의 별도 작성·전달을 제거했다.
주의점은 필요한 hint에 통합하고 상세 작업은 실행자가 맡는다. 재규정·후속 계승에서 두 기준을
동시에 다시 쓰게 하거나 모든 후속 요청에 비어 있지 않은 기준을 요구하던 관문을 제거했다.

심층연구는 기존 작업 문서를 회수하거나 요청을 출발 메모로 저장한다. 출발 메모를 의식이
완성한 사전 계획으로 표시하지 않는다. 실행자가 기존 경로에서 계획·방법·진행을 작성한다.
별도의 계획 완성 모델 호출·정정 반복, 의식만 가이드를 읽는 제한, 계획 작성자에게 되돌리는
왕복을 제거했다. 기존 연구 프로젝트·주제·실행 소유권과 파일 판본·경로 경계는 유지한다.
의식의 계획 patch/revise 프로토콜은 제거하고 실행자가 기존 파일 도구로 갱신한다.

중간감사 출력에서 repair_scope·repair_block_ids·응답 버전/해시를 요구하던 계약과 검증을
제거했다. 전체 산술 재검산·모든 결함의 완료 증거/대안/중단 조건 작성도 제거했다.
findings의 교정·근거는 유지하되 ID는 하네스가 만들 수 있고 resolved_when은 필수가 아니다.
trigger/goal 수명 구분, 취소·현재 판본 대조, 해소된 촉발 지시 폐기는 계속 적용한다.
