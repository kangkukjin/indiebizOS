# 현재 의도와 과제 기억 — 2026-09-14 수리

에피소드 3762는 직전 제주 정책 조사의 후속 질문이었다. 경량 선택기가 9월 10일의
블루칼라 과제(ep3377)를 선택했고, 검토기가 "그 과제 범위 밖이므로 답하지 않기"를
달성 기준으로 만들었다. 하네스는 새 의식 호출을 생략한 채 이 기준을 현재 프레임으로
전달했다. 실행은 질문을 거부했고 평가는 ACHIEVED로 승인했으며 과제 요약에도 거부가 남았다.

현재 요청과 최근 대화는 문제를 이해하는 기준이다. 영속 과제는 이를 보충하는 기억이며,
오래 저장됐거나 active라는 이유로 현재 요청의 범위를 정하거나 거부할 권한이 없다.
사용자가 실제로 이어가는 장기 지시·전체 완료 기준은 유지한다. 같은 일의 정정과 무관한
과제의 오연결 회수는 별개다. IBL 어휘·문법과 실행/반사 경로는 변경하지 않았다.

## 구현

- `pursuit_bind.prepare`: 선택 후보를 최근 대화와 함께 재검토한다. keep/amend/rewrite에
  detach를 더하고, 검토 후에만 요약 따라잡기와 begin_turn을 한다. 무관한 후보에는
  현재 턴·요약을 쓰지 않는다. 연결 판단의 형식 실패는 연결을 보류하고 새 의식으로 넘긴다.
- `run_consciousness`: THINK/REPAIR는 현재 의식을 새로 호출한다. 경량 검토의 criteria나
  amended_framing을 문제 규정으로 소비하지 않는다. 이전 프레임·가이드·가정이 새 판단을 대신하지 않는다.
- 의식의 `detach_pursuit:true`와 실행 도구 `pursuit{op:"detach", why}`는 연결만 회수한다.
  실행자는 잘못된 프레임을 기존 reframe(kind=wrong_problem) 통로로 정정할 수 있다.
  분리 후 재규정이 옛 목표를 자동으로 되살리지 않으며, 같은 턴에 새 과제를 열어도 별개 객체다.
- `pursuit_ledger`: detached 턴의 원문·도구·사건을 보존하고 pending 목록에서 제외한다.
  분리 전에 출발한 요약도 apply에서 거부한다. 오연결 때문에 갱신됐던 마지막 참여 시각을 복원한다.
- 선택·검토는 `pursuit.judgment`, 판단 실패 폴백은 `pursuit.connection_unresolved`,
  규정은 `framing_source=fresh_consciousness|fresh_consciousness_revision`으로 출처를 남긴다.
  관측되지 않은 외부/기존 규정은 unobserved이며 새 판단으로 추정하지 않는다.
- 평가자는 기존 기준의 충족 여부만 판정한다. 다만 기준 자체가 현재 사용자 요청과 명백히
  충돌하면 UNKNOWN과 기준 ID·원문 근거를 남기고 성공/학습 승인을 하지 않는다.
  평가자가 새 기준을 만들거나 일반 품질 심사로 일을 늘리는 권한은 추가하지 않았다.
- 요약 프롬프트는 응답·모델 성공 판정을 관찰로 다루며 사용자 만족·유용성의 증거로 승격하지 않는다.
