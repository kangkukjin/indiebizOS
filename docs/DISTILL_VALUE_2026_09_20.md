# 경험 증류의 효용·비용 보강

실행 성공만으로 일회성 주소 읽기와 탐색 이력을 새 용례로 저장하면 다음 실행의
검색·입력 비용이 늘어난다. 기존 증류 호출 안에서 배움을 선별하고, 결정 가능한
중복은 모델을 부르기 전에 제외한다. 별도 평가 모델이나 반복 반성 루프는 추가하지 않는다.

## 변경

- 기존 DB의 전체 코드와 같은 절차, URL 인자만 다른 기존 원시 호출은 0회 호출로 생략한다.
  서로 아는 문장들의 새 조합, 옵션·질의·instruction 차이는 이 관문에서 지우지 않는다.
- 원문과 같은 액션을 쓰는 기존 용례 최대 4개, 목표 검수와 호출당 결과 발췌 최대 400자를
  반성기에게 제공한다. 발췌 누락·절단을 명시한다. 전체 입력이 24,000자를 넘으면 보류한다.
- 기존 한 번의 응답에 `decision`, `benefit`, `applicability`, `source_ids`를 받는다.
  새 효용이 없으면 저장 0건이다. 의미상 새로움·설명 적합성 판단은 이 모델의 몫이며,
  필드가 존재한다는 이유만으로 그 판단의 정확성이 입증되는 것은 아니다.
- 자동 경로는 코드 재작성 응답을 받지 않는다. 원문 번호 선택이 잘못되면 종료하며,
  예전 구문 복구용 추가 모델 호출을 하지 않는다. 수동 복구 헬퍼는 유지한다.
- 성공 여부 없는 도구 호출, 불완전한 목표 판정, 인자 검증기 오류는 성공 근거가 아니다.
- 선택 결과를 다시 중복 확인하고 모든 기존 접지·구문·인자·개인정보 관문을 통과시킨다.
  저장에 성공한 선택 절차만 가지의 주행 절에 남긴다. 부분 절차임을 표시하고,
  선택하지 않은 탐색·실패 원문은 기존 실행 원장에만 둔다.
- DB의 추가 `provenance` 열과 학습 JSON에 과제·에피소드 식별자, 사건 원장 위치,
  원 호출/문장 번호, 원문 해시, 검수 상태, 개선점과 적용 조건을 함께 저장한다.
  식별자를 얻지 못한 호출은 null로 남긴다. 큐 재개 때도 기존 과제 ID 복원 경로를 쓴다.
  회상에는 사적 식별자 대신 적용 조건 최대 240자와 부분 절차 표식을 전달한다.
- 해마 공개 배포 사본에서는 사적인 `provenance`를 제거한다. 로컬 원장은 변경하지 않는다.
- 기존 정리 패스가 빠뜨렸던 `distilled_component`도 실패·중복·개수 상한 대상에 포함한다.
  수동/합성 씨앗은 이 정리 대상이 아니다. 과거 기록을 이번 작업에서 일괄 삭제하지 않는다.

## 검증

임시 DB·모델 대역으로 호출 0/1회, 저장 거절 후 재호출 없음, 원문 의존성·출처,
새 조합 보존, 입력 예산, 검증 실패, 기존 DB 마이그레이션, 부분 절차 정리를 검사한다.
기존 증류 회귀는 원문 번호 선택 계약으로 갱신하고 수동 복구 관문 시험은 유지한다.
실제 유료 모델 호출과 과거 용례 일괄 재증류는 수행하지 않는다.

전체 백엔드 회귀를 한 차례 실행했고, 이전의 무선별 주행 기록을 기대한 시험 1건이
실패했다. 새 계약에서 선택된 절차의 비용 전달을 검증하도록 갱신한 뒤, 마지막 회상
표시 변경까지 포함해 증류·회상·검색 관련 284개 시험이 통과했다. 전체를 다시 돌리지는
않았다. 기존 용례 4822·4823의 읽기 전용 재현에서는 각각 이전 용례만으로 URL 교체
중복을 찾아 모델 호출 전에 제외했다.
