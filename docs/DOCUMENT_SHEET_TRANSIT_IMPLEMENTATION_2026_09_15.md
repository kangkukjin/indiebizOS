# 문서 편집·엑셀 계산·대중교통 구현 계획

## 범위

1. `self:document` — DOCX inspect/edit. 본문·표·머리말·꼬리말의 문단 id와 파일 해시를
   조회하고, 확인한 해시/문구를 기준으로 일괄 편집한다. Word 변경 추적과 주석을 남긴다.
   수정본을 별도 파일로 쓰고 원본 ZIP의 비대상 파트는 바이트 그대로 보존한다.
2. `self:sheet` — range, range_write, calculate 확장. 범위 값/수식 조회·쓰기·
   숫자 서식/굵기 지정은 OOXML을 직접 수정한다. 재계산은 LibreOffice의 별도 프로필·
   임시 사본에서 수행하고 계산 캐시만 원본 구조에 반영한 별도 결과 파일을 반환한다.
3. `sense:navigate_route` — mode=transit 추가. ODsay 인증은 API 레지스트리를 사용한다.
   기본 자동차 경로와 기존 반환은 보존하고 transit만 items 통화를 반환한다.
   도시내 구간을 우선 지원하며 도시간 응답은 연결 구간이 없는 부분 경로로 명시한다.

## 검증

- 문서: 여러 run에 나뉜 문자열, 표·머리말, 변경 추적의 전/후 텍스트, 주석 배선,
  스타일·그림·기타 ZIP 파트 보존, 오래된 해시/중복 일치/지원 밖 요소의 무변경 실패.
- 엑셀: 범위 크기와 타입 검증, 기존 서식·수식·다른 시트·ZIP 파트 보존, 실제 계산값,
  계산 엔진 없음/계산 오류/지원 밖 수식에 대한 정직한 결과.
- 교통: 공식 스키마의 도시내/도시간·부분 실패·API 오류·키 없음·모드 오류 대역 검증,
  기본 자동차 경로 회귀. 실제 API 검증 가능 여부는 결과에 따로 기록한다.
- IBL 소스에서 파생물 재빌드, 가이드·검색 등록·수동 용례 추가, 관련 회귀와 필수 빌드 검사.

## 설계 근거

- [OOXML 삽입 변경](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.insertedrun?view=openxml-3.0.1)
- [ODsay 대중교통 v1.8](https://lab.odsay.com/guide/releaseReference)
- 계획은 사용자 요청 1·2·8의 구현 범위를 기록한다. API 인증키 값은 기록하지 않는다.

## 구현·검증 기록

- 등록 계약: `self:document` inspect/edit, `self:sheet` range/range_write/calculate,
  `sense:navigate_route` mode=transit. 코어 문법 변경 없이 패키지 선언으로 추가했다.
- 관련 회귀 51건 통과. 실제 파서→엔진→핸들러의 문서/범위 읽기·쓰기도 포함한다.
  Word 수락/거절 시 텍스트, 주석 연결·변경 id, 다중 run 서식, 표/머리말과 비대상 파트 보존을 검사했다.
- LibreOffice 실제 계산: 곱셈·SUM 합계 1100 및 #DIV/0! 오류 반환 확인.
  수식·차트·다른 ZIP 파트가 그대로인지 계산 결과와 별도로 대조했다.
- 원본/추적본/확정본 DOCX 각 1쪽 렌더 검수. 한글 폰트가 없는 기본 QA 환경은
  시험 프로세스의 fontconfig에 맥 한글 폰트를 지정해 해결했다(제품/전역 설정 불변).
  머리말·표·꼬리말·문구 교체와 추적 표시를 확인했다. 주석은 OOXML 관계/앵커 검사로 검증했다.
- 수동 용례 30건을 DB·벡터 색인·재학습 JSON에 등록했다. 주제 기억에 가이드를 연결하고
  인자/이웃 스윕을 실행했다. 구체적인 문서 추적·엑셀 계산·대중교통 요구로 상위 검색을 확인했다.
  기존 넓은 검색어에서 옛 용례가 먼저 나오는 경우는 남아 있다.
- IBL 빌드/--check 및 Android 몸 번들 생성 완료. 새 어휘 수는 166개.
- ODSAY_API_KEY 미설정: 공식 응답 스키마 대역으로 검사했으며 외부 서비스 실조회는 미검증이다.
  도시내 경로만 완결 성공, 도시간 연결 누락은 incomplete_route로 명시한다.
- 로컬 HTTP 백엔드는 실행 중이지 않아 HTTP 배포 확인은 못 했다. 직접 IBL 엔진 회귀는 통과했다.
- 엑셀 재계산은 LibreOffice 설치 또는 SOFFICE_PATH 설정이 필요하다. 현재 QA는 번들 엔진으로
  검증했으며 제품에는 특정 Codex 설치 경로를 넣지 않았다.
- 런처 API 키 설정의 포털·지도에 ODsay 등록란을 추가했다.
- 실제 IBL 변수 연결도 실행했다: inspect→edit, range→range_write→calculate→range.
  단가/수량 변경 후 합계 1350을 새 파일에서 확인했다. transit 키 누락은 파이프 실패로 전파됐다.
- 전체 backend 회귀: 4,719 통과·1 건너뜀·규약 실패 2건(446초).
  실패는 새 테스트의 직접 실행 진입점 누락과 파일 확장자 비교의 vj-ok 설명 누락이었다.
  두 건 수정 후 새 기능·기존 회원 문서·단일 러너·값 판정 관문 63건을 재실행해 전부 통과했다.
  마지막 수정은 테스트 진입점과 감사 주석이므로 전체 7분 회귀를 반복하지 않았다.
- 완료 검증: IBL 빌드 및 --check, backend 층 검사, Android 몸 번들, diff 공백 검사 통과.
  모델 호출·시간 절감의 실사용 개선 폭은 이번 구현 검사에서 측정하지 않았다.
