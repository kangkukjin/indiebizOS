# ep3286: 원천 절단 증거의 실행·평가·학습 경계 수리

2026-09-09 최신 두 에피소드(ep3285·ep3286)의 IBL/관용구 사용 감사에서 발견했다.
ep3285 날씨 조회는 2회 호출·3액션으로 경고와 실패가 없었다.
ep3286 조사는 11회 호출·44액션, 크롤 문서 6개 중 5개가 기본 10,000자에서
잘렸는데 재수집 없이 완료 판정과 경험 증류까지 진행했다. 실행 실패는 아니지만
원문 전량 확인의 증거가 부족했다. `verbose`, `take`, `select`는 이미 잘린 본문을
복원하지 못한다.

두 턴 모두 명명 관용구를 호출하지 않았다. ep3286의 의식은 `주소마다읽기`를
제안했으나 실행은 수동 검색·크롤·투영으로 풀렸다. 미사용 계수 0은 적용 기회가
없었다는 증거가 아니다. 이번 수정은 선택기를 추가하거나 관용구 사용을 강제하지 않는다.

## 실행 결과의 진단 계약

- 웹 크롤은 기존 `truncated`에 `truncations`를 동반한다. 각 항목은
  `scope: source`, 원문 URL(`source`), 단위(`unit`), 보존 상한(`retained`),
  원래 길이(`total`), 같은 URL을 더 긴 `max_length`로 읽는 `retry` 파라미터다.
  반환 경고는 원천 누락과 복구 방법을 설명한다. 추가 네트워크 호출은 자동 실행하지 않는다.
- `table:each`는 입력과 자식 실행의 진단을 `row_honesty`로 보존한다.
  입력은 `scope: input`, 자식은 1부터 시작하는 `row`와 원행 `label`을 갖고,
  실제 표지는 `markers`에 둔다. 중첩 실패 수는 이곳에 보존하여 직접 처리한 행의
  `ok_count`·`error_count` 단위를 바꾸지 않는다. `error_count: 0`은 원문 완전성 보증이 아니다.
- 순차·병렬 each, 명명 관용구, 투영, 중간 step 요약을 지나도 절단 증거가 남는다.
  each에서 이 증거가 사라지던 결함은 실제 ep3286에 사용된 경로는 아니며,
  같은 자료를 권장 관용구로 읽는 오프라인 재현에서 확인한 잠재 결함이다.
- 전량 입력에서 의도적으로 행을 줄인 경우는 `scope: selection`, 기존 출처 불명의
  `truncated`는 `scope: unknown`이다. 표시용 `_preview`는 원천 절단으로 취급하지 않는다.
  범용 판정기는 봉투·실행 결과 경계만 탐색하며 사용자 `items` 속 동명 필드는 읽지 않는다.

## 평가와 증류

평가자 trace는 본문 예산에 접히지 않는 호출 헤더에 절단 건수와 범위를 적는다.
스트림 수집기는 동일한 증거를 도구 호출 로그에 붙인다. 증류는 원천 절단이 확인된
호출을 후보에서 제외한다. 후속 호출에서 전체 원문을 재수집했으면 그 호출은 학습할 수
있다. 한 호출 내부에 절단과 복구가 모두 있으면 보수적으로 그 호출 전체를 제외한다.
selection·unknown은 범위를 설명하도록 지시하고, preview만으로는 학습을 막지 않는다.
런타임 성공 판정과 목표 평가의 AI 판단은 유지한다.

잘못 증류된 대표 용례 #4598은 SQLite 백업 후 DB·벡터 인덱스·트리의 용례와
학습 JSON에서 제외했다. ep3286 실행 이력은 보존하고 해당 주제 메모리에 사후 검수
주석을 남겼다. 백업은 `data/_backups/2026-09-09_episode3286_repair/`에 있다.

## 검증

`backend/test_episode3286_repairs.py`는 실제 IBL 실행기에 결정론 크롤 응답을 넣어
정상/절단 × each/관용구 × 순차/병렬, 입력 0행, 중첩 실패, 투영과 요약,
재수집 파라미터, 평가 헤더 예산, 잘못된 증류 배제와 복구 후 학습을 검증한다.
기존 관용구·봉투·증류·평가 회귀와 backend 전체 검사를 수행한다.

최종 결과: backend **3,346 통과·1 skip·실패 0**(120초). 새 재현과 러너 규약
검사는 별도로 24개 통과했다. 기존 경로의 경고 116건(Pydantic 설정의 미해결 타입,
PDF 라이브러리 SWIG 타입, `hippo_tree`의 `re.split` 위치 인자 사용)은 남아 있으며
이번 에피소드의 원천 절단 경고와는 별개다. 어휘 빌드/`--check`, Android 몸 번들,
층 구조·은퇴 계약 검사도 통과했고 라이브 `/world-pulse/health`는 `healthy`다.
