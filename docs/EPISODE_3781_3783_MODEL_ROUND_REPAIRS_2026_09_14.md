# 에피소드 3781–3783: 품질을 보존하며 불필요한 모델 왕복 줄이기

2026-09-14. 정본 로컬 저장소에서 수리. 대상은 건축 프로젝트 설계 에이전트의
영상 MCP 식별, 모델링 도구 비교, Sweet Home 3D·Blender 역할 설명 주행이다.

## 판단 기준

사용자가 지적한 체감 성능의 중심은 AI 모델 호출 지연이다. 빠른 IBL 호출 수나
원문 회수 문자 수를 줄였다는 사실만으로 시간을 절감했다고 판단하지 않는다.
IBL 호출 여러 개가 한 모델 라운드에 묶일 수 있으며, 모델 실행 구간에는 도구
대기가 포함될 수 있다. 시간 합계를 무조건 더하지 않는다.

3781의 이미지 Base64는 코드 안에서 조립해 이미지로 전달됐다. 23개의 이미지
페이지 조회를 23개의 모델 라운드나 130만 자의 모델 텍스트 입력으로 해석하면
틀린다. 다만 전송 계약 불일치와 JSON 파싱 실패가 추가 복구 라운드를 만들었다.
영상 화면에서 서버를 확인한 조사 자체는 답변 근거를 확보하는 데 필요했다.
3783의 실제 Sweet Home 3D MCP 발견도 품질을 개선한 필요한 추가 조사였다.

## 확정한 원인과 수정

- `browser_vision`은 기존 공개 계약인 `image_base64/mime_type`을 반환하지만,
  이미지 수확기는 `image_data` 또는 `images`만 이해했다. 그보다 앞선 모델
  미리보기에서도 이미지가 원문 참조로 접힐 수 있었다.
  `base/image_envelopes.py`로 세 계약을 함께 처리하고, 미리보기 전에 이미지
  바이트를 표시 사본에서 분리해 네이티브와 MCP 모두 이미지 블록으로 전달한다.
  IBL 원본·턴 변수·저장 증거는 유지한다. 기존 4장 상한의 초과는 명시한다.
  표시 계측에서도 이미지 바이트를 모델 텍스트 문자 수에 합산하지 않는다.
- MCP 반복 가드는 `code=""`인 원문 조회들을 같은 실행으로 셌고, JSON 뒤에
  조언 산문을 붙였다. 실제 이미지 조립 코드의 `JSON.parse`가 실패했다.
  조회·계약 확인·정적 검사·회수는 실행 반복 가드 대상에서 제외한다.
  실행 반복 조언과 네이티브의 부록은 JSON 객체 안의 `_model_advisory`로 실어
  객체 응답의 파싱 가능성을 유지한다.
- 브라우저 AX slider의 숫자 `value`에 문자열 슬라이스를 적용해 snapshot이
  실패했다. 표시 문자열로 변환하며 0도 보존한다.
- 연속 실패/반복의 감독 사유가 실행 진전 뒤 남을 수 있었다. 조건이 끝나면
  트리거를 내리고, tick에서 가져온 사유도 모델 호출 직전에 재검증한다.
  원문 페이지 조회는 실패 복구나 실행 반복으로 세지 않는다. 미해결 실패의
  기록과 장시간 작업·작업 실패·정체에 대한 감독은 유지한다.
- 실행 프롬프트와 검색 가이드에 인용 문자열, `$it`, 실제 열과 오류 봉투,
  즉시 할당과 실행 병렬화의 차이를 명시했다. 파서가 잘못된 문장을 임의로
  보정하거나 없는 열을 조용히 버리게 만들지는 않았다.
- 의식·검색 가이드의 비용 기준을 추가 모델 호출의 정보 가치로 정리했다.
  연속 질문의 관련 근거를 재사용하되 최신성·모순·출처 부족은 다시 확인한다.
  추천에서 실제 사용자 작업 흐름과 OS·배포판·연동 제약을 반영하도록 했다.

빌드 관문에서 별도로 드러난 `table:compute`의 기존 `columns` 입력 별칭은
핸들러·flow가 이미 지원하지만 도구 입력 스키마의 타입 선언만 빠져 있었다.
해당 타입 선언을 보충하고 파생 `tool.json`은 빌더로 재생성했다. 새 어휘나
새 실행 별칭은 추가하지 않았다.

## 검증과 한계

회귀 시험 `backend/test_episode3781_3783_repairs.py`는 모델·외부망 없이 다음을 확인한다.

- 큰 이미지가 단독/파이프 및 세 이미지 계약에서 실제 MCP 이미지로 도착한다.
- 네이티브 이미지 전달도 동일 바이트이고 원본 증거는 변경되지 않는다.
- 이미지 상한 초과가 표시되며 저장된 전체 증거는 회수할 수 있다.
- 실제 반복 가드를 켠 여러 페이지 조회가 계속 JSON으로 파싱된다.
- 실행 반복의 조언은 유지된다.
- 연속 오류 뒤 성공한 실행에는 감독 모델을 부르지 않고, 원문 조회만 한
  미해결 오류에는 감독이 유지된다.
- AX 숫자 0·정수·소수와 인용 검색어를 처리한다.

백엔드 전체 회귀 검사에서 실패한 두 항목은 감독 테스트의 실제 실패 조건 누락과
신규 테스트의 직접 실행 진입점 누락이었다. 둘을 수정한 뒤 영향받는 테스트와
이미지·MCP·감독 관련 테스트를 함께 다시 실행해 **177건이 통과**했다.
전체 검사를 수정 후 재실행한 결과는 아니다. 층 구조·의식 스키마·폐기 계약 검사와
IBL 파생물 검증도 통과했다. 정식 재기동 후 백엔드 정상 상태를 확인했다.

실제 모델로 세 질문을 재실행한 성능 실험은 아니다. 새 답변의 품질이나 절감
초·토큰을 수치로 보장하지 않는다. 계획 호출을 없애거나 모델 등급을 낮추거나
검증을 강제로 중단하는 변경은 하지 않았다.
