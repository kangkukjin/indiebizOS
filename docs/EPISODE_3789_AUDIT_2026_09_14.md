## 확인한 오류와 수정

Codex exec의 완결된 `agent_message`들을 모두 합쳐 최종 응답으로 내보내던 연결 오류를 수정했다. 원본 롤아웃에는 `phase=commentary`와 `phase=final_answer`가 구분되어 있었다. 이 구분을 잃어 사용자에게는 진행 설명 세 문단이 답변 앞에 붙었고, 감독에는 진행 설명 뒤 JSON이 전달되어 엄격한 JSON 판독이 UNKNOWN으로 끝났다.
