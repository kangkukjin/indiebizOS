# 에피소드 4016 — 연속 자막 인용의 위치 검증

## 사건과 원인

2026-09-24 08:13에 시작한 ‘유튜브 AI 팁 보고서 써줘’ 작업은
`AI팁보고서쓰기`를 ‘평가’ 주제로 호출했다. 08:17:44 첫 호출이
`인용문과 시간 위치 불일치`로 실패했고, 08:18:10 같은 회차를 다시 호출했다.
재호출은 성공한 아홉 구간의 추출 영수증을 재사용하고 실패한 한 구간만 다시 추출했다.

실패 원인은 추출 모델의 잘못된 시간이 아니라 보고서 검증기의 오판이었다.
영상 `CgAcMP7LbbM`의 29:17 인용은 1757.279초 자막의 중간에서 시작해
1759.679초 자막의 중간에서 끝난다. 전체 자막에는 연속된 원문 그대로 존재한다.
기존 검사는 ±15초 안의 한 세그먼트가 인용에 통째로 포함되거나 그 반대인 경우만
허용해서, 양쪽 경계에 다른 단어가 붙어 있는 올바른 인용을 거절했다.
반대로 근처 세그먼트가 짧은 공통 단어이면 멀리 있는 인용을 잘못 승인할 수도 있었다.

## 중단

사용자의 명시적 중단·수정 요청에 따라 해당 task에 중단 조향을 보냈다.
접수 후에도 중첩 IBL 호출이 진행돼, `/health`의 유일한 실행 에피소드가 4016이고
`/nodes/active-work`에도 해당 시스템 AI만 있음을 확인한 뒤 재기동 제어기의
강제 재기동으로 중지했다. 제어기는 `restarted`와 빈 live_episode_ids를 반환했고,
에피소드 종료 시각은 08:27:10이다. 재기동 결과의 effect_unknown은 보존한다.

운영 회차 `_runs/2026-09-24-9e4ea4a94ab0-v3`의 수집·추출·부분 색인 결과는
그대로 두었다. completed는 false이며 이번 ‘평가’ 보고서는 생성되지 않았다.
수리 과정에서 보고서 작성·발행을 재개하지 않는다.

## 변경

- `ai_tips_report.grounded`: 공백·NFKC 정규화 후 연속 자막에서 **전체 인용**의
  일치 위치를 찾고, 시작 문자가 속한 원본 세그먼트 시각과 대조한다.
  기존 ±15초 허용폭은 넓히지 않는다. 원문 변조·없는 인용·잘못된 시점·추출기가
  신고한 시간 오류는 계속 거절한다. 반복 구절의 뒤쪽 일치 위치도 검사한다.
- 관용구에서 `source_requests`는 추출 확정 결과에, `sources_indexed`는
  구간 색인 결과에 의존하도록 연결한다. 선행 단계 실패 시 뒤의 스크립트를
  독립 작업처럼 호출하지 않는다. 실행기의 일반적인 오류 수집 동작은 바꾸지 않아
  반환 봉투에 의존 변수의 연쇄 오류가 표시될 수는 있다.
- 이름·설정 서명·원문/내용 검수·원장 반영 계약은 유지한다.

업무 이름이나 영상 ID를 실행기에 넣지 않았다. 이번 변경 범위는 보고서 스크립트의
인용 검증과 해당 관용구의 단계 연결이며, 전체 IBL의 중단 전달을 수리했다는 뜻은 아니다.

## 검증

당시 로컬 모델 출력 14행을 원래 자막과 함께 다시 읽어, 실제 `self:struct`의
근거 필터·시각 복원·인용 확장을 재현했다. 수정 전 9번째 행이 같은 오류로
실패했으며, 수정 후 **같은 14행을 내용·시점 수정 없이 전부 통과**했다.
재현 자료: `outputs/episode4016_grounding_replay.json`.
메모리 안의 상태 사본에서 해당 14행의 구간 영수증 수용도 통과했으며,
그 전후 운영 state.json의 SHA-256이 같음을 확인했다.

보고서 회귀 95개가 통과했다. 실제 IBL 이름 호출·병렬 추출·부분 재개·검수·저장
경로를 쓰고 외부 AI·YouTube 응답만 고정한다. 새 검사는 두 부분 세그먼트에 걸친
실제 오류, 짧은 공통 단어의 오승인, 반복 구절·정규화, 잘못된 시점·없는 인용,
추출 실패 후 색인 호출 차단과 성공 구간 재사용을 포함한다.
문서 드리프트 검사 17개와 파일 크기 검사도 통과했다. 등록 개정 18은 기존
관용구 ID 4845·이름·서명·소개 층을 유지하며, 등록 본문과 파일은 끝 개행을
제외하고 일치한다. 스크립트는 호출별 새 프로세스에서 읽으므로 다음 호출에 적용된다.

전체 backend 회귀는 샌드박스에서 포트 바인딩·브라우저·LibreOffice 제한으로

(499.33초). 결과는 `/tmp/episode4016-backend-native.xml`과

실제 보고서의 끝까지 완료, 전체 모델 비용·시간·품질 개선은 이 회귀만으로
