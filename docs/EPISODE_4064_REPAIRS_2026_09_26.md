# 4064 — 선택 파일 읽기와 실행·계약 조회 경계

2026-09-26 AI 동향 보고서는 저장까지 완료했지만 도구 호출 두 건이 실패했다.
수리 범위는 이 두 실패와 그 공통 경계다. 4051의 CLI 사용량 한도·완료 처리,
4015의 보고서 저장 누락은 이번 변경에 포함하지 않는다.

## 원인과 변경

1. `_scan_log.json`은 첫 빈 날까지 없어도 정상인데 필수 읽기처럼 병렬 호출했다.
   가이드는 구형 예외 구문을 가르치고 있었다. 기존 `self:list`의 빈 목록으로
   부재를 확인한 뒤 읽는 현재 조합으로 고쳤다. 공통 교재의 실행 가능한 예제는
   `found`로 부재와 빈 파일을 구별한다. 필수 파일 실패·권한 실패를 빈값으로 만들지 않는다.
2. `read_op`의 텍스트 읽기가 던진 예외를 패키지가 평문 `Error: …`로 반환했다.
   JSON 문서 봉투를 기대하는 어댑터가 이를 `ADAPTER_SHAPE`로 오진했다.
   읽기 예외는 JSON 실패 봉투로 반환하고, 어댑터는 `TOOL` 진단에 `error_type`과
   `errno`를 보존한다. 권한 실패는 permission으로 남아 폴백으로 삼킬 수 없다.
   문서 본문의 `Error:`는 정상 텍스트이며 진짜 봉투 파손은 여전히 형식 오류다.
3. 실행 코드와 부가 `describe`를 함께 제공하면 전체를 거절해 재호출을 요구했다.
   이제 계약을 먼저 조회하고 성공하면 기존 실행 경로를 한 번 호출한다.
   결과의 값·실패·영수증을 보존하고 `descriptions`를 덧붙인다. 조회 불가·잘못된
   조회는 효과 전에 거절하며 `check:true`는 검사만 한다. `read_result`는 여전히
   독립 조회다. 기존 저장 코드의 평문 반환도 원형으로 보존한다.

## 실행과 권한

`describe`가 있다는 이유로 실제 실행이 관측 전용이 되면 안 된다.
공유 요청 판정으로 런타임 추적·재기동 중 HTTP 접수·반복 가드를 연결하고,
상태 통보 턴의 도구 제한도 코드 본문을 검사한다. 회원은 공개 액션만 조회하며
조회 성공 뒤 기존 회원 라이브러리·권한·취소 경로에서 실행한다.

system_essentials의 패키지 지문을 갱신하기 전에 read/fill/script 회원 변환을
재검토했다. 수정된 owner handler 예외 분기는 회원 변환 진입점이 아니다.
`member_documents`는 회원 장치에서 받은 바이트만 임시 작업대에서 변환하고,
`member_script`는 회원 장치로 인자를 전달한다. 경로 제한·허브 경로 비노출·
실행 위임의 기존 동작은 유지된다. 관련 회귀와 빌드가 이 경계를 확인한다.

## 검증

`backend/test_episode4064_repairs.py`는 실제 임시 파일로 부재/빈 파일/본문을
구별하고 병렬 부분 결과·권한 실패·단일 실행·검사 전용·잘못된 조회의 쓰기 차단·
재기동 접수 차단·회원 조회 거절·기존 평문 반환을 확인한다.
검증 명령은 전체 backend pytest, IBL 빌드 및 `--check`, Android 몸 번들
재생성 및 `--check`다. 실제 뉴스 재수집이나 보고서 재발행은 하지 않는다.

재현 19건과 문서 형식·회원 파일·클라이언트 경계의 기존 회귀를 통과했다.
전체 backend 회귀 실행에서 용례 검토 장부·교재 예제 목록·새 테스트의 직접 실행
규약 검사 3건이 실패했다. 이를 갱신한 뒤 해당 파일들과 재현 테스트 63건을
다시 실행해 모두 통과했다. 전체 회귀를 수정 후 다시 전부 실행한 것은 아니다.
`self:read` 교재 변경의 영향 용례 131건도 검토했다. 입력·성공 반환은 동일하고
실패 원인만 구조화하므로 용례 본문의 변경은 필요하지 않다.
라이브 `/ibl/execute`에서도 `return 4064 + describe`의 값·계약 반환과
없는 파일의 `TOOL / not_found / errno=2`를 확인했다. 실행 중 백엔드의
코드 지문과 디스크 지문이 같아 수정 코드가 로드된 것도 확인했다.

개선 범위는 파일 읽기·도구 진입 계약이다. 오늘의 실패를 줄이는 근거는 재현 시험이며,
전체 보고서의 시간·토큰 절감은 다음 실제 실행을 측정하기 전에는 확정하지 않는다.
