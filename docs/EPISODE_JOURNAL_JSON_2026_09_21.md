# 조종실 주행기록 빈 목록 수리

2026-09-21 13:19 에피소드 3947의 `supervision.decision`이 직렬화 후
4096자에서 잘려 유효하지 않은 JSON으로 저장됐다. 주행기록의 IBL 횟수 집계는
다른 종류의 사건에도 `json_extract`를 평가했고, `malformed JSON` 오류를
빈 목록으로 바꿨다. 확인 당시 원본 주행 1,304건은 보존돼 있었다.

- 사건 저장은 마스킹을 먼저 적용하고, 긴 내용은 절단 여부·원래 길이·미리보기를
  갖는 유효한 JSON 봉투로 저장한다. 기존 4096자 제한을 유지한다.
- IBL 집계는 관련 종류의 유효한 JSON만 읽는다. 라운드 집계도 파손되거나
  객체가 아닌 사건을 건너뛴다. 기존 사건 원문은 변경하지 않는다.
- DB 조회 실패는 API 오류로 전달한다. 데스크탑은 첫 조회 실패 시 재연결 문구를
  표시한다. 조회 실패를 기록 부재로 보고하지 않는다.
