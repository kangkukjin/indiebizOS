# 상시 관용구의 수집·선별 경계 수리

## 실제로 재현한 문제

상시 노출 7개 중 네 관용구의 결함을 현재 판본 호출로 확인했다.
`주소마다읽기`·`관련자료골라읽기`는 일반 문자열 dedup을 URL에 적용해
`/A`와 `/a`, 쿼리 값의 대소문자가 다른 주소를 합쳤다. 같은 URL의 뒤쪽 실패 행도
없어져, 자료가 빠진 결과를 `source_complete=true`로 보고했다.

`관련자료골라읽기`·`의미로본문찾기`는 정상 후보 2개 중 1개를 선택하거나 0개를
요청해도 `PARTIAL_SOURCE`로 실패했다. 의도한 선택을 범위 없는 `truncated=true`로
신고했기 때문이다. `좁혀서읽기`도 검색 8곳에서 앞 3곳을 읽는 정상 표본 작업이
검색 상한 6의 절단 표지 때문에 같은 경계에서 실패했다.

## 변경

- 등록 스크립트 `판정관용구`의 `urls` 단계에서 URL 문자열이 정확히 같은 정상 행만
  중복 제거한다. 주소를 임의로 소문자화하거나 재작성하지 않는다. 동일한 자원의 표기
  변형을 더 합치는 최적화보다 서로 다른 주소를 보존하는 쪽을 택한다.
- 원천 실패 행은 URL 중복 제거와 선택 개수 밖에서 보존한다. 크롤은 정상 후보에만
  실행하고, 종료 시 실패 행과 원천 진단을 합친다. 실패를 다시 크롤해서 성공으로
  덮거나, `개수:0`으로 실패 증거까지 지우지 않는다.
- 선별 표지는 `truncations.scope=selection`, 생략 수·선택 수로 명시한다.
  기존 원천의 범위 불명 절단은 `unknown`으로 유지한다. 수집 단계에는 선택된
  `items`만 전달하고 원천 진단은 별도 변수로 보존해 마지막에 합친다.
- grep content 결과에서 요청한 행 상한만 도달했으면 `selection`으로 신고한다.
  시간·크기 상한과 일치 줄 본문 절단은 `source`다. 빈 결과라도 시간 제한으로
  중단했다면 전수 0건으로 위장하지 않는다. `total_complete`가 거짓이면 `total`은
  관측치이며 전수 합계로 사용할 수 없다.
- 기존 관용구 이름·인자·반환 Record 계약을 유지한다. 새 액션과 모델 호출은 없다.
  정확 비교는 수집 부품에 한정하며 일반 table:dedup의 텍스트 비교 계약은 유지한다.

관용구 본문 정본은 `data/idioms/curated.json`, 현재 호출 교재는
`data/idioms/current_call_lessons.json`, 공통 처리는 `data/scripts/judgment_idioms.py`다.
grep 표지는 `data/packages/installed/tools/system_essentials/fs_grep.py`에서 생성한다.

## 검증과 반영

`backend/test_exposed_idiom_boundaries.py`는 관용구를 대역으로 바꾸지 않는다.
격리된 원장에 실제 본문을 넣고 공개 판본 2 입구로 호출하며 웹·Jev만 고정 응답으로
대체한다. URL 경로·쿼리 대소문자, 정확한 중복, 같은 주소의 실패, 상한 밖 실패,
0개 선택의 외부 호출 0회, 실제 수집 실패, 상류 절단 보존, ASCII/한글 grep의
앞 3곳 읽기, 긴 줄·시간·크기 절단을 검사한다. 성공값을 다음 식에서 `.items`로
사용하는 경우도 검증한다.

기존 관용구·원문 보존·진단 전달·수집·grep·대상별좁혀읽기·문서 정합성을 포함해
관련 170개 검사를 통과했다. 기존 격리 실행 도구도 등록된 값 처리 스크립트를 실행하도록
갱신했으며 임의 스크립트·외부 모델 호출은 계속 차단한다.
외부 판정 모델의 의미 정확도나 전체 에이전트 시간·토큰 절감률을 측정한 것은 아니다.

전체 `pytest backend/`는 기존 `logging_utils.py:149`의 비밀값 마스킹에서 정체되어
180초 후 중단했다. 그 실행의 1,148개는 통과했고, 발견한 7개 실패는 수집 스크립트를
모르던 기존 시험 대역과 진단 전달 경계를 수정한 뒤 위 170개 회귀에서 모두 통과했다.
전체 회귀 통과를 주장하지 않는다.

실제 백엔드 HTTP 입구에서도 `좁혀서읽기`가 여러 일치 중 세 곳을 반환하고,
주소마다읽기·관련자료골라읽기·의미로본문찾기의 `개수:0`이 성공과 빈 목록을 반환함을
확인했다. 외부 서비스에 자료를 보내지 않는 호출로 라이브 반영을 확인했다.

라이브 원장 개정은 SQLite backup 후 `scripts/register_idiom.py`의
`update_idiom`을 사용한다. 기존 본문·통계는 `ibl_idiom_revisions`에 보존하고,
같은 이름·상시 노출 상태를 유지하면서 새 본문의 실적을 새로 센다.
본문과 달라지는 호출 교재의 SHA-256도 함께 갱신한다.

패키지 경로 감사: 변경된 실행 소스는 grep의 반환 표지 부분뿐이며 경로 해석·읽기·쓰기·
회원 변환 코드는 바꾸지 않았다. 패키지 전체 지문에 묶인 read/fill/script의
`path_audited`를 이 차이 검토 후 갱신하고 어휘·회원 매니페스트를 빌드로 재생성한다.
