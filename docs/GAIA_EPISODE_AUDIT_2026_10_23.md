## 실제 모델 비교

같은 DeepSeek `deepseek-flash` 분류 모델에 본시험 첫 세 요청을 그대로 전달했다.
실행 도구는 제공하지 않고 분류 호출만 비교했다. 정답이나 기존 실행 결과를 넣지 않았다.

| 유효한 분류 토큰 | 1/3 | 3/3 |
| 출력 토큰 합계 | 6,644 | 6 |

수정 전 두 응답은 문제 풀이·가상 도구 호출까지 생성했다. 수정 후 세 응답은 모두 `THINK`였다.
분류 입력의 추가 안내는 이 표본에서 요청당 약 186 입력 토큰을 늘린다. 표본은 세 건이며
모델 응답의 확률성과 캐시 상태 차이가 있다. 전체 실행 시간·최종 정확도·감독 비용까지
개선됐다고 일반화하지 않는다. 일반 인사·사실 통보·복합 조사도 별도 대조해 각각 `EXECUTE`·`CONTEXT_UPDATE`·`THINK`를 확인했다.

## 코드 결함과 구별한 나머지 항목

- **원천·시점 8건:** 역사적 통계에 현재 개정값을 쓰거나 전체 표를 확인하지 않고 추정한 사례다.
  기존 실행·검수 지침에도 근거와 미확인 보존이 규정되어 있다. 분류 실패로 복합 조사가
  기본 실행 경로로 떨어진 결함을 먼저 고쳤다. 새 정답 목록이나 GAIA 전용 분기를 코어에 넣지 않는다.
- **파일·시각 3건:** 배경 글자·기호 판독과 PDF 본문/도표의 계수 판단이다. 잘못된 답안에
  맞춘 OCR·영상 규칙을 추가할 근거는 부족하다. 실제 판독 능력 향상은 별도 재검증 대상이다.
- **추론 4건:** 공식·단위·계수 대상 해석 오류다. 실제 문제별 근거 재검증이 필요하며,
  자막·원장 수리로 해결됐다고 계산하지 않는다.
- **형식 2건:** 기존 분석의 정답지 오타 의심 및 반올림 조건 충돌이다. 원출처 검증 없이
  정답지나 채점 정규화를 바꾸지 않았다.
- **브라우저·외부 원천:** 403/인증 제한·삭제된 영상은 관측된 원천 실패다. 지원하지 않는
  브라우저 옵션, 파이프 충돌, 예약 변수 `$i`, 실패 대체값의 필드 불일치도 기록에서 확인했다.
  현재 오류는 그 계약 위반을 설명하며, 제한을 없애거나 거짓 성공으로 바꿀 수리 대상으로 삼지 않았다.
- **시험 운영:** pilot 결과의 완료 순서 결합은 기존 스크립트가 이미 문항 ID 결합으로 고쳤다.
  이번에는 봉인 경로·권한·과거 원자료·채점 결과를 변경하지 않았다.
