# 부동산 보고서 관용구 등록 완료

에피소드 4052의 요청은 관용구를 등록하고 부동산 보고서 가이드에서 소개하는 일이었다.
조사·문법 확인 중 모델 연결이 끊겨 등록·가이드 수정은 수행되지 않았다.
이번 작업은 정본의 기존 보고서 정책을 유지하며 반복되는 중간 절차를 등록한다.

## 등록한 계약

| 이름 | 원문 | 역할 |
|---|---|---|
| 부동산준비읽기 | `data/idioms/housing_prepare.ibl` | 설정·순회 원장·연구 노트·최신 보고서·선택 지역 DB 읽기 |
| 부동산기본수집 | `data/idioms/housing_collect.ibl` | 호가 3갈래·실거래 2갈래를 병렬 수집하고 실패·원문 보존 |
| 전세예산추리기 | `data/idioms/housing_filter.ibl` | 원/만원 단위 구분, 전세·예산 양끝 확인, 누락·모순 보류 |
| 매물재방문비교 | `data/idioms/housing_compare.ibl` | URL별 가격 변동·재확인·거절·충돌 분류 |

IBL 현재 판본의 명시 인자·값 반환을 사용한다. 각 정의와 실제 호출 예제를
`data/idioms/housing_seeds.json`에 보존하고 `add_examples_batch`로 등록했다.
등록 ID는 4870~4873, 호출 예제까지 총 8행이며 의미 검색 색인을 확인했다.
가지 `보고서/부동산 발굴`에서 회상하고 이름으로 호출한다. 상시 소개는 꺼 둔다.

등록 재현·검사:

```bash
.venv/bin/python3 scripts/register_webapp_idioms.py --seed-file housing_seeds.json
.venv/bin/python3 scripts/register_webapp_idioms.py --seed-file housing_seeds.json --apply --local-encoder
```

기존 등록기의 검증·SQLite backup·색인·멱등 삽입 경로를 공유한다. 다른 본문의 같은
이름은 덮어쓰지 않고 명시 개정을 요구한다. 백업은 `data/_backups/`에 둔다.
실행 DB는 로컬 상태이며 커밋에는 정의·시드·가이드·검증 코드를 보존한다.

## 가이드 정리

`data/guides/housing_report.md` §3-0에 이름·입력·반환·사용 시점·조합 예제를 연결했다.
중단 직전 실패했던 옛 `matches` 식과 문자열 필터 목록을 현재 콜백 안내로 교체하고,
리터럴 표 계산 예제도 현재 문법으로 정리했다. 가이드 크기는 기존 35KB 상한 안이다.

오늘 지역 선정·주거 철학·안전 평가·지역 분석은 보고서 작성자가 기존 규칙대로 수행한다.
기본 수집은 전국 전건 조사가 아니며 호가 표본 상한이 있다. 개별 소스 실패를 0건으로
바꾸지 않는다. 예산 후보는 평가 통과 매물이 아니고, 검색 누락도 소멸 증거가 아니다.
현재·기존 가격 비교에는 같은 단위·거래 형식의 URL별 행을 제공해야 한다.
새 관용구는 지역 DB·순회 커서를 갱신하거나 보고서를 발행하지 않는다.

## 검증과 범위

```bash
.venv/bin/python3 -m pytest scripts/test_housing_idioms.py backend/test_webapp_idioms.py backend/test_homepage_idioms.py -q
```

32개 검사 통과. 네이버 예산 양끝·월세 혼입·가격/URL 누락, 직방 만원과 월세액 모순,
빈 입력·역전 예산, 수집 5갈래의 빈값·부분 실패, 최신 파일 선택·필수 설정 부재,
재방문 가격 변경·중복·거절·검색 누락, 가이드의 조합 예제와 기존 관용구 회귀를 확인했다.
순수 변환은 실제 IBL 실행기에서 실행했고 외부 조회는 고정 응답으로 대체했다.

등록 후 함수 본문을 붙이지 않은 `[fn:]` 호출로 준비 읽기·선별·재방문 비교를 실행했다.
실제 보고서 폴더의 설정·순회 원장·연구 노트·최신 보고서·전주 지역 DB를 정상 조회했다.
회상 가지에서 네 이름이 노출되는지도 확인했다.
실시간 부동산 API 재조사·보고서 발행과 시간/토큰 절감 비교는 이번 검증 범위가 아니다.
