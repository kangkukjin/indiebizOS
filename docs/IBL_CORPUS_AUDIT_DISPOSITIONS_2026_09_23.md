# 새 문법 코퍼스 — 전수 판정·적용·소비 경계

정본의 학습·회상 **6,255행과 과거 실행 원문 9,382건에 조치 판정을 남겼다.**
추가 1,382행을 적용하여 누적 전환은 2,051행이다. 현재 판본 2,066행을 학습 입력으로
내보내고, 구형 4,189행은 현재 작성 정답·반사 실행·학습 입력에서 제외한다.
원문과 명시 호환 호출은 보존한다.

**이 보고서는 전 행의 의미 검증 또는 전량 문법 이관 완료 보고가 아니다.**
확정 정적 오류가 있는 1,144행은 그 근거로 제외 판정했고 의미 동등성을 검사하지 않았다.
나머지 조합·함수 563행도 이관 계약이 확정되지 않았다. 이를 검증 통과나 전환 완료로
집계하지 않는다. 계획의 ‘모든 행에 근거 있는 조치 판정’과 ‘모든 대상의 현재형 정비’를 구별한다.

통과했다는 이유로 다른 반환형까지 입증한 것으로 취급하지 않는다.

## 실제 적용과 증거

- 누적 2,051행의 ID·의도·주제·출처를 보존했다. 이전 코드·통계는 provenance에 보관하고
  새 판본 실적은 미검증으로 초기화했다. 운영 DB 적용 1,188행의 벡터를 쓸 때 바이트 대조했다.
- 새 묶음은 408개 원문/후보 조합에 2,856개 고정 응답 검사를 통과했다.
  앞선 두 묶음까지 합한 반환·실패 fixture는 4,501개다. 외부 도구 실행은 대역으로 차단했다.
- 기존 현재형 함수 및 저장 조합 예제의 순수 실행 프로브 17개가 통과했다.
  collect의 성공/실패 구분, 병렬 순서, flat_map, 문자열 ID, 콜백·reduce·보간을 확인했다.
- 과거 실행 원문 9,382건의 코드·판본은 보존했다. 조사 중 한 원문의 실제 관측 통계가
  증가한 것은 증분으로 기록하고 되돌리지 않았다.
- 벡터 키 3,684개와 실제 DB ID 집합이 일치한다. FTS·DB 무결성, 후보 코드·이전 통계
  보존, 재적용 pending 0을 확인했다. 서로 다른 대표 회상 12건 모두 대상 코드가 Top-5에 들었다.

현재형 2,066행의 전수 정적 판정은 valid 6 / incomplete 2,060 / invalid 0 / failed 0이다.
대부분은 기존 도구의 Record 호환 경계라 incomplete다. 고정 응답 검증은 실제 서비스의
현재 결과·권한·업무 품질을 검증한 것이 아니며 성공 이력도 만들지 않았다.

## 재유입 경계

공통 `corpus_policy`가 저장 판본 충돌, 구형 원문, 명시 보류/격리 및 정적 거절을 구분한다.
이 정책은 판본/자격 필터이며 컴파일러나 의미 검증의 대체물이 아니다.
신규 현재형 저장·시딩·증류의 컴파일 검사 경로는 기존 `ibl_v2_learning`을 유지한다.

자동 회상은 구형 본문 대신 원문 ID와 명시 펼침 경로를 준다. 구형 용례를 반사 실행 코드로
선택하지 않는다. 함수 이름의 회상·가지 열람은 같은 이름의 현재형 정의를 우선하며,
정의별 실적과 반환 계약을 사용한다. 구형 함수의 현재 호출 반환은 전체 Record다.
ID로 펼치는 과거 정의와 원문은 계속 조회할 수 있다.

로컬·클라우드 학습기와 모델 비교 입력, 학습 export, 폰 정적 색인이 같은 자격 정책을 쓴다.
감사한 의도를 ‘보여줘→가져와’ 같은 동의어 치환으로 자동 증식하는 경로도 학습 진입점에서
중단했다. 이미 학습된 가중치를 바꾼 것은 아니다.

- 학습 export/클라우드 ZIP: DB 1,203 + balanced 819 + distilled 44 = **2,066행**.
- 폰 색인: **1,203행**, 각 ID의 768차원 벡터 바이트가 운영 색인과 일치한다. 누락 0.
- ZIP을 새로 만들고 내부 파일 해시·자격·동봉 정책 모듈을 재검사했다. 외부 업로드는 하지 않았다.
- 모델 재학습·교체는 하지 않았다. 기존 가중치의 구형 학습 영향을 제거했다고 주장하지 않는다.

주간 감사는 판본 1 파서와 판본 2 컴파일러를 구분한다. 지역 함수 참조를 죽은 어휘로
오판하지 않으며 valid/incomplete/invalid/failed를 따로 보고한다. 운영 DB 검사 결과는
죽은 어휘 0, 구형 파싱 오류 0, 현재 invalid/failed 0이다.
빌드 감사는 한 검사 안에서 사전·정의를 공유하고 **각 행의 컴파일 검사는 유지**한다.
새 검사 회차에는 사전을 다시 읽는다. 사전 로드 실패도 모든 대상 행에 실패로 남긴다.

행의 입력·생산자 필드·반환/실패 계약을 복원하고 fixture를 추가한 후에만 채택한다.

## 회귀 시험의 운영 문서 오염 수리

임시 DB를 쓰는 시험 세 곳이 운영 `hippocampus_tree` 경로를 그대로 사용했다.
구문 관문·비용 기록 시험은 뿌리 문서를 시험 행으로 바꿨고, 증류 정리 시험은
삭제 후 전체 갱신을 호출해 다른 가지의 용례 절도 비웠다. 각 시험의 문서 경로를
임시 디렉터리로 격리했다.

영향받은 문서와 갱신 표식을 먼저 백업하고 실제 DB에서 57개 가지·3,684행을 재생성했다.
문서를 DB에 역수입하지 않았고 원본 DB의 코드·의도·출처는 그대로다. 각 가지의 ID·본문을
DB의 렌더 결과와 대조하고, 용례/관용구 절 밖의 산문이 그대로임을 확인했다.
복구 증거는 `data/_backups/2026-09-23_234500_ibl_corpus_audit/all_tree_repair/`에 있다.
마감 스냅샷과 연결 표면 검사는 복구 뒤에 다시 만들었다.
