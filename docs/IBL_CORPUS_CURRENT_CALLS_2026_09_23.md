# 코퍼스 전수조사 두 번째 묶음 — 현재 호출 교재와 문맥 결함 격리

정본에 적용한 범위는 **상시 함수 소개 7개, 새 호출 용례 7행, 학습 파일 격리 40행**이다.
전체 전수조사의 의미 검토 완료를 뜻하지 않는다.
이 묶음은 잘못된 반환형·파이프 설명과 문맥 없는 정답 연결을 고친다.
작업 시간·토큰 절감이나 전체 모델 품질 개선은 아직 측정하지 않았다.

## 호출 계약과 교재

상시 소개의 이름 선정은 기존 `always_on`을 따르되, 소개할 정의는 현재 호출이 선택하는 판본을 따른다.
같은 이름의 현재형 정의가 있으면 그 정의의 서명·반환형·통계를 사용한다.
최신 구형 정의만 있으면 호환 호출이 돌려주는 전체 `Record`를 가르친다.
구형 정의에 현재 파이프 입력 자리가 있는 것처럼 소개하지 않는다.

| 이름 | 현재 호출 경로 | 반환 | 이번에 검증한 범위 |
| --- | --- | --- | --- |
| 열추려보기·정렬해추리기 | 기존 현재형 정의 | List<Record> | 실제 순수 표 연산, 문자열 ID·순서·목록 형태 |
| 본문에서찾기 | 기존 구형 함수 호환 어댑터 | Record | 실제 구형 본문을 현재형 호출로 실행, 문맥·출처·일치 진단 보존 |
| 좁혀서읽기·주소마다읽기·관련자료골라읽기·의미로본문찾기 | 기존 구형 함수 호환 어댑터 | Record | 명시 인자 정합, 호출 컴파일, 테스트 대역의 전체 반환 보존 |

5개 호환 함수의 몸을 새 문법으로 전환한 것은 아니다. 호환 경계의 정적 판정은 여전히 incomplete다.
외부 크롤·AI 판정·실파일 읽기의 성공을 이번 등록의 근거로 주장하지 않는다.
기존 호환 어댑터의 실제 실행·실패 경계는 별도 `test_ibl_v2_assets.py` 회귀로 검사했다.

교재 `data/idioms/current_call_lessons.json`에는 실제 정의 판본과 SHA-256을 적었다.
몸이 바뀌면 오래된 교재 예시는 숨긴다. 같은 이름의 옛 함수 통계를 새 정의에 이월하지 않는다.
현재 함수의 첫 인자는 파이프로 받을 수 있지만 같은 인자를 동시에 쓰면 충돌한다.
예시를 한 줄로 소개할 때 판본 헤더 주석이 전체 예시를 주석 처리하던 가능성도 막았다.
호환 함수의 최상위로 승격되는 것은 items/count다. 본문에서찾기의 일치 진단은 final_result에
남으므로 최상위 match_info 접근을 가르치지 않으며, 실제 호출 회귀로 이 구조를 확인했다.

학습 용례의 의도에는 예시의 **모든 구체적 입력**을 적었다. 예를 들어 문자열 ID가 있는 목록을
질문에 명시하고 그 목록의 열을 고르는 정답으로 연결한다. URL 예시는 example.com을 명시한
합성 입력이며 실제 페이지 수집 성공 사례가 아니다. 새 7행은 성공·실패 횟수 모두 0이다.

## 40행의 문맥 결함

`data/training/_proposed_verify_intents_20260525.json`의 40행을 전부 읽었다.
“방금 고친 거”, “그 변수”, “함수 본문”처럼 대상을 알 수 없는 요청을 특정 파일·줄번호·패턴에
고정한 학습 쌍이다. 파일명만 현재 경로로 바꿔도 이 결함은 남는다.

원문 바이트를 보존하여 `data/training/_archive/2026-09-23_ambiguous_verification.json`으로 옮겼다.
로컬 및 클라우드 학습기의 `training/*.json` 소비 범위에서 빠지며, 삭제하지 않는다.
운영 DB에는 같은 의도·코드 쌍이 0건이었다. 검토 지문이 다르거나 DB에 같은 쌍이 생기면 적용기가
중단하도록 했다. 모델 가중치의 과거 학습 영향을 제거한 것은 아니며 재학습도 하지 않았다.

## 적용·대사

적용기: `scripts/apply_corpus_current_calls.py`. 기본 실행은 검토, `--apply`는 백업 후 등록·격리다.
등록은 기존 `add_examples_batch` 입구를 쓰므로 구문·소유·서명·FTS·벡터·트리 갱신을 재사용한다.
등록과 격리는 별도 단계다. prepared/seeded/applied 기록을 남기고 재실행 시 같은 용례를 중복 등록하지 않는다.
벡터 색인이 빠지면 격리 전에 중단하며 재실행으로 색인을 복구한다.

적용 직전 백업: `data/_backups/2026-09-23_214048_ibl_corpus_audit/`.
`current_calls/`에 행별 격리 결정·시딩 입력·적용 보고서·대사 결과·실제 소개문을 보존했다.
개인 DB·감사 행 원문·백업은 Git에 넣지 않는다.

- 운영 용례: 3,677 → 3,684행. 기존 3,677행의 **모든 필드 변경 0**.
- 새 ID: 4854–4860. FTS 실제 검색 7/7, 벡터 존재 7/7, 성공·실패 통계 0, quick_check 정상.
- 활성 학습 모집단: 6,325 → 6,292행(새 7, 격리 40). 격리 원문 해시는 백업과 동일.
- 원문 대사: 추가 7, 활성 범위에서 제외 40, 기존 의도·코드·판본·alias 변경 0. 과거 실행 원문 변경 0.
- 트리 기억은 표준 등록 경로로 갱신됐다. world_pulse 안내 파일의 동시 변경은 감사 증분에 별도 기록했다.

## 검증과 남은 범위

현재 호출 교재·격리 적용기·현재/구형 함수 경계의 집중 회귀 33개 통과.
소개·함수 확장·파이프·어휘 프롬프트 관련 선행 회귀 49개 통과(서로 겹치는 검사가 있어 합산하지 않는다).
전체 backend 회귀: **5,699 passed, 1 skipped**, 513.09초.
첫 샌드박스 실행에서 로컬 서버·브라우저·문서 렌더가 차단되어 권한을 받아 재실행한 결과다.
옛 교재를 기대하던 소개 테스트는 판본 검토를 거친 교재만 가르치는 계약으로 갱신했고,
새 backend 시험의 직접 실행도 pytest에 위임했다. 해당 수정의 집중 회귀 40개 통과.
전체 회귀 수집 이후 추가한 실제 반환 봉투 검사까지 포함한 현재 호출 교재 회귀 14개 통과
(위 회귀들과 중복 포함). 외부 도구를 호출하지 않는 실제 구형 본문 검증이다.
어휘 빌드 `build_ibl_nodes.py --check`도 통과했다.
Android 몸 번들 매니페스트 재생성 완료, 추적 산출물 차이 없음.

다음 우선순위는 일반 용례의 **행별 의도 검토**다. 같은 단일 도구 호출이라도 실제 대상이 명시된 질문과
“이 영상/이 책”을 가짜 또는 고정 ID에 연결한 질문을 같은 판정으로 처리할 수 없다.
소스 판본·입력·반환 계약이 검증된 것부터 별도 현재형 용례로 등록하고 과거 통계를 이월하지 않는다.
5개 구형 함수의 본문 전환, 호출자 전수 대조, 연결 자료 4,612개 후보의 문맥 검토,
시딩·학습의 재유입 관문과 모델 재학습 판단도 후속 범위다.
