# 최근 유튜브 보고서 ep3148 실행 마찰 수리

2026-09-08. 실제 실행에서 재발한 값 전달·자막 시각 누락을 수리하고, 지원하지 않는 compute 식의 처방과 보고서 가이드를 맞췄다. 새 관용구나 어휘는 추가하지 않았다.

## 관찰과 수리 범위

ep3148의 궤적에는 IBL 28회, 실패 5회가 기록됐다. 실제 `[fn:]` 호출은 0회였고, `팁행source중첩`·`보고서HTML`은 `self:script`로 재사용했다. source 중첩 스크립트는 compute Dict 실패 후에야 찾아 썼다. 따라서 이번 실행으로 관용구 사용이 늘었다고 말할 근거는 없다.

| 실제 실패 | 원인 | 수리 |
|---|---|---|
| 15:19:36 기존 팁을 `known`에 넣은 each 4행 모두 파싱 실패 | 바깥 파이프 슬롯을 지연 코드에 먼저 치환할 때 작은따옴표를 보호하지 않음 | 슬롯 치환도 공유 `bind_scoped_code`를 사용. 중첩 do·목록형 do·달러 데이터 보호, 통짜 경로 참조의 목록/객체 타입 보존 |
| 15:19:50·15:23:08 추출 결과의 timestamp 누락으로 후속 select 실패 | struct가 자막 시간표시를 제거하고, 모델의 필드 생성에 의존 | 자막 세그먼트 시각을 별도 보존하고 근거 `_quote` 시작 위치에서 timestamp 복원 |
| 15:27:39 compute Dict 생성 실패 | 지원하지 않는 식을 반복 작성 | 오류에 평탄 열 계산 후 등록된 self:script 사용을 안내. 가이드에 기존 스크립트의 정확한 호출과 입출력 계약 명시 |
| 15:28:27 compute의 Python `in` 실패 | 지원되는 contains 대신 Python 문법 사용 | 오류와 카탈로그에 contains/not contains 및 목록 소속 검사의 table:filter 처방 제공 |

이전 경계 시험이 각 행·함수 인자 치환을 고쳤어도, 그보다 앞선 바깥 파이프 슬롯 치환 경로는 놓쳤다. 이번 회귀는 실제 실패와 같은 바깥 변수→each→도구 입력 경로를 포함한다. 컴파일된 슬롯 번호는 각 행의 별칭 이름과 다른 타입으로 취급하여 숫자 별칭에 가려지지 않게 했다.

## 자막 시각의 계약

`grounded:true`이고 스키마에 timestamp를 요청한 자막 입력에 적용한다. 시각이 없는 입력은 `timestamp(MM:SS)`를 명시한 경우에만 이 계약을 적용하며, 일반 날짜 timestamp 필드를 임의로 자막 시각으로 바꾸지 않는다.

- 인라인 segments, 시간표시 텍스트 파일, 외부화 봉투, 봉투 JSON 파일, spill 입력을 처리한다. 짧더라도 시간 세그먼트가 있는 자막은 struct에 들어간다.
- 근거 앵커를 문장으로 확장하기 **전**에 원문 위치를 찾는다. 모델이 적은 시각도 원문 시각으로 검증·교체한다. 추가 모델 호출은 없다.
- 서로 다른 시각에 같은 근거가 반복되면 `timestamp:null`, `_timestamp_error:"ambiguous_quote"`를 반환한다. 원 시각이 없거나 대응하지 않으면 각각 `no_source_time`·`unmatched_quote`로 신고한다. 행을 버리거나 임의의 00:00을 채우지 않는다.
- struct 봉투에 `timestamp_grounded`와 필요시 `missing_timestamp`를 기록한다. each로 합친 뒤에도 행별 timestamp와 오류 표지는 남는다.

## 검증

- 신규 회귀 57건: 바깥 값 10종×지연 코드 형태 4종, 문자열 내 보간·숫자 별칭, 자막 입력 경로 5종, 시각 중복·결측·교차 세그먼트·1시간 초과, compute 처방을 포함한다.
- 최종 전체 backend 회귀 **2700 passed / 2 skipped**(107.86초). 어휘 빌드 검사·backend 층 검사·Android 번들 재생성·diff 공백 검사도 통과했다.
- 실행 중 앱의 `/ibl/execute`에서 따옴표가 포함된 기존 팁 목록→each 값 전달을 확인했다.
- 같은 앱에서 작은 실제 자막 파일→each→실제 모델 struct를 실행했다. 기존 팁에 작은따옴표가 있어도 성공했고, 추출된 팁은 원문의 **00:12**를 반환했다. 모델 추출 실행을 포함한 each는 약 5초였다. 이는 작은 통합 확인이며 보고서 전체 속도 비교가 아니다.
- 최종 슬롯 번호 수정 후 앱에서 숫자 별칭을 쓴 중첩 each도 실행해 바깥 값 `outer`가 보존됨을 확인했다. 자동 리로더로 적용됐으며 수동 재시작은 하지 않았다.

회귀 코드는 `backend/test_youtube_episode3148_repairs.py`에 있다. 로컬 원시 기록은 `outputs/episode3148_live_binding.json`, `outputs/episode3148_live_struct.json`, `outputs/episode_idiom_usage_comparison.json`에 보존했다. outputs는 커밋 대상이 아니다.

## 남은 판정

실제 다음 보고서의 실패·수리 횟수, 관용구 선택률, 전체 비용·품질은 아직 측정하지 않았다. 이번 수리는 안정된 중간 단위를 부를 때 안쪽에서 다시 수리해야 하는 마찰을 줄이는 조치다. `[fn:]` 호출을 강제하거나 호출 수 자체를 성과로 삼지 않는다.

ep3148의 에피소드 기록은 기존 자동 리로더의 600초 대기 상한에서 CUT됐고, 같은 실행의 도구 궤적은 이후에도 이어졌다. 완전한 시간·토큰 비교에는 이 기록 절단을 고려해야 한다. 리로더와 에피소드 기록기는 이번 변경에 포함하지 않았다.
