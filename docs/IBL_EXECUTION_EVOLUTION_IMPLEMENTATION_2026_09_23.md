# IBL 실행 개선 구현 — 2026-09-23

설계: [IBL_EXECUTION_EVOLUTION_DESIGN_2026_09_23.md](IBL_EXECUTION_EVOLUTION_DESIGN_2026_09_23.md).
AI 팁 보고서의 실패에서 드러난 일반 경계는 기존 어휘 옵션으로 고쳤고, 보고서의 업무 판정과
실행 영수증은 등록 스크립트에 남겼다. 문법·전역 변수 해석·새 실행기·상태 DB는 추가하지 않았다.

## 구현

- `table:ai.input_fields`: 모델에 보낼 최상위 열만 투영한다. 원 행은 코드에 보존한다.
  숨긴 원본 필드 변경·모든 행에 없는 열·잘못된 투영을 거절한다. 투영 후 직렬화의 chars/bytes와
  상한을 구별해 오류에 남긴다. 기존 `fields`의 출력 투영 의미는 유지한다.
- `table:ai.preserve_rows`: 명시 true일 때 모든 `_i`의 정확히 한 번 반환을 요구한다.
  누락·중복·추가·전체 행 폴백을 거절하고 입력 순서로 병합한다. 기본 false의 기존 선별은 유지한다.
  투영을 선택했을 때는 preserve_rows와 무관하게 유효한 색인으로 원본에 병합해야 한다.
- `self:script.input_as`: 실제 실행용 앞 봉투를 stdin args의 한 키에 주입한다.
  키 충돌·args_file 병용·파이프 부재·만료된 스필은 실행 전 거절한다. 사용자 키와 값, 오류·잘림·
  출처를 보존하며 주입 봉투 내부에는 경로 확장을 적용하지 않는다. 회원 기기 전달도 같은 준비기를
  사용하되 허브 경로 확장·허브 스크립트 실행 없이 args를 기기로 전송한다.
- 보고서 v2: 검증한 결과를 버전·범위·입력·출력 지문의 영수증과 함께 원자 저장한 **후** 다음 요청을
  준비한다. 준비 실패에는 blocked·accepted·evidence·resume가 남는다. 재개는 완료된 모델/API 호출을
  건너뛰고 최초 미완료 요청을 준비한다. v1 상태는 자동 전환하지 않고 새 run_id를 요구한다.
- 기존 팁 전부에 ID를 붙여 요청 크기 안에서 분할한다. 각 배치는 모든 후보를 판정하고, compared 단계가
  모든 배치·후보 ID와 중복 근거 ID를 대조한다. unknown은 통과시키지 않는다. 이후 후보끼리의 중복과
  최종 선정을 별도 판단한다. 편집·검수에는 원장 지문·전건 비교 범위·판정 이유·연결된 근거를 전달한다.
- 보고서 구조 criteria를 명시적인 행 보존·grounded·answer/keyed 검사로 옮겼다.
  원문 전체를 받는 영상별 내용 검토와 마지막 편집 검수는 유지한다. 엔진의 일반 criteria 동작은 그대로다.
  each 안의 4개 봉투 구성은 보존했다. 바깥 연결은 추가 subprocess 없이 input_as로 줄였다.

함수/each·표 변환·문서 원본 열 보존·로컬 subprocess stdin·스필·회원 기기 전송을 시험한다.
보고서 밖의 여러 소비자가 공유하는 영수증 모듈은 아직 만들지 않았다. 두 번째 실제 소비자가
확인되기 전에 보고서 상태 기계를 언어 코어로 올리지 않는다.

## 검증 및 운영 반영

- 계약·조합·기존 args·criteria·보고서 관련 회귀와 실제 하위 프로세스/회원 전송 시험.
- 표준 어휘 빌드·삼각 검증·파생 문서 신선도, 용례 계약 재검토, Android 본문 번들 재생성.
- self:read/fill의 회원 문서 어댑터는 변경 없음. 패키지 전체 지문이 바뀌므로 경로 감사와
  실제 회원 문서 읽기·채우기 시험을 다시 확인하고 감사 지문을 갱신했다. 새 script 회원 어댑터는
  인자 준비와 전송만 수행하며 스크립트를 허브에서 실행하지 않는다.
- `scripts/register_idiom.py --update`로 같은 이름·서명을 유지해 라이브 관용구를 개정했다.
  이전 본문·실적은 도구의 개정 원장에 보존하며 새 본문에 옛 성공 통계를 붙이지 않는다.
- 보고서 등록 설명에 compared와 revise의 from/reason 계약을 반영했다. 작업 시작 전에 있던
  registry.yaml의 다른 항목 서식 변경은 보존하고 이번 커밋에서는 제외한다.

## 남은 범위

한 비교 단계 안에서 일부 배치만 성공한 경우의 개별 배치 영수증은 아직 없다. 해당 단계는
재개 시 배치 전체를 다시 수행한다. 개별 자막·단일 비교 항목·검수 요청 자체가 상한을 넘으면
조용히 자르지 않고 보존한 근거와 함께 멈춘다. 의미 판단이 부족하면 여전히 사람/상위 실행자의
보완이 필요하다. 이 변경은 모든 외부 부작용의 exactly-once나 모든 과제의 일정 절감률을 보장하지 않는다.
