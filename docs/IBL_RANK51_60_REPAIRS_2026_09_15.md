## 범위와 한계

외부 API·AI 모델·사용자 화면은 대역으로 검증했다. 실제 메시지 발신·사용자 화면 입력·
라이브 원장 재스캔을 수행하지 않았다. 문서·SQLite 검증은 임시 경로에서 실행했다.
외부 서비스의 현재 가용성과 AI 산문의 사실 정확도까지 보증하는 감사는 아니다.
화면의 ref가 이후 UI 변경에도 유효한지, 접근성 권한 및 실제 OS 장치 동작은 별도 실환경 영역이다.
스토리지 잠금은 같은 프로세스의 관리 경로를 직렬화하며 여러 프로세스의 JSON 원장 병합은 제공하지 않는다.
SQLite 색인과 JSON 요약 메타데이터는 별도 저장소이므로 둘 사이의 전원 차단까지 하나의 트랜잭션은 아니다.
