# 값 자리의 호출 — 연산·내장 함수 인자·보간 (언어 개정)

2026-09-30. 사용자 판정: "네가 추천하는 대로". 앞선 결정은 [객체·목록 값 자리의 호출](IBL_CONTAINER_CALLS_2026_09_26.md)이며
이 문서는 그 경계를 한 걸음 넓힌다. 공통 목적은 [IBL 진화 목적](IBL_EVOLUTION_PURPOSE.md).

## 문제

`sum($행 >> [table:each]{...})`, `"합 " + [fn:표기]{n:$x}`, `($a >> [..]) + ($b >> [..])`는 `PURE_EXPRESSION`으로
거절됐다. 작성자는 같은 호출을 임시 변수로 떼어 다시 제출했다.

- 시스템 AI: 에피소드 4182·4183·4184 의 거절·실패 23회 중 7회(가장 큰 부류). 4182 의 렌더 프로그램 하나는 이 진단 29건을 받았다.
- 훈련자: 긴문장 2·3·4회차 최다 작성 실수, 9회차에도 2건([원장](LONG_SENTENCE_IMAGINATION_LEDGER.md) L4-2·L8-4).
- 진단과 처방은 이미 정확했다(L4-2 수리). 남은 비용은 규칙 자체다 — 거절 한 번이 한 라운드(수만~수십만 토큰의 문맥 되읽기)다.

## 결정

**값을 만드는 자리에서는 호출·조합을 그대로 쓴다.** 객체 필드·목록 원소·호출 인자(09-26)에 더해:

- 산술·비교·이어 붙이기의 피연산자, 단항 연산, 슬라이스
- 내장 함수의 인자
- 보간 `f"${...}"`

**실행 여부나 횟수가 갈리는 자리는 순수 식으로 남긴다.**

- 조건: `[if:]`·`[case:]`·반복의 조건
- 조건 값 `조건 ? 값1 : 값2` 전체, `and`/`or`(오른쪽이 평가되지 않을 수 있다)
- 람다 본문(행마다·도구 안에서 불린다), 인자 기본값

경계의 이유: 효과가 있는 호출이 "실행됐는지, 몇 번 실행됐는지"를 식의 모양만으로 알 수 있어야 한다.
값 자리의 호출은 그 문장이 실행되면 정확히 한 번 실행된다. 조건·람다·단락 평가에서는 그렇지 않다.

`get(레코드, 키)`는 기본값을 생략하면 null 을 돌려준다(`get(레코드, 키, 기본값)`은 그대로). 훈련자와 시스템 AI가 같은 2인자 실수를 했다(L9-3).

## 실행 계약

09-26 계약을 그대로 따른다. 새 실행기·끌어올림 변환·자동 병렬·캐시는 없다.

- 피연산자·인자·보간 조각은 원문의 왼쪽에서 오른쪽 순서로, 중첩 값은 그 자리에서 평가한다. 각 호출은 한 번 실행한다.
- 잡히지 않은 실패가 나면 뒤의 값과 바깥 연산은 실행하지 않는다. 롤백은 없다.
- 호출은 기존 `Runtime.eval`/`invoke`를 지나므로 권한·공유 예산·취소·효과·출처·영수증·resume/reuse 규칙이 위치와 무관하게 같다.
- 정적 검사(타입·필수 인자·병렬 쓰기 충돌·AI 호출 상한·함수 효과)는 방문 중에 중첩 호출을 그대로 관측한다.
- 값 자리에 제어 블록(`[if]`·`[try]`·`[repeat]`)을 직접 넣으면 `VALUE_EXPRESSION`이다. 앞 문장이나 함수 본문에 둔다.
- 기존에 유효하던 코드의 뜻은 바뀌지 않는다(허용 범위만 넓어진다). 판본 1과 기능어 코어 노드 집합은 그대로다.

## 구현

- `ibl_v2_compile.py`: binary(and/or 제외)·unary·slice·pure_call·format 조각의 검사를 `pure()`에서 `container_value()`로 바꿨다.
  람다·조건 값·and/or·조건·기본값은 각자의 방문에서 `pure()`가 재귀로 지키므로 값 자리로 감싸도 효과를 숨길 수 없다.
  런타임은 바꾸지 않았다 — 식 평가는 이미 자식 노드를 `Runtime.eval`로 순차 평가한다.
- `expression_ops.py`: `get` 인자 수 2~3, 생략 시 null. `self:record` 의존 지문 재감사(식 평가의 허용 범위만 넓어짐, 경로·권한·쓰기 불변).
- 진단 `PURE_EXPRESSION`의 기본 처방과 `VALUE_EXPRESSION` 문구를 새 경계에 맞췄다.
- 문서: `system_docs/ibl.md`, 문법 전문 `12_ibl_only.md`, 조합 교재.
