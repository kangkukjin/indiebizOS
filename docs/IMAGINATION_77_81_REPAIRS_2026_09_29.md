# 상상훈련 77~81회차 — 공통 경계 수리

대상: 2026-09-29 작성된 최근 다섯 보고서 `docs/experiments/imagination_round77_2026_09_29/report.md`부터 `imagination_round81_2026_09_29/report.md`까지. 보고서 원본·탐침과 기존 미커밋 핸드오프는 보존한다.

## 근본 원인과 소유 위치

1. **같은 사실을 여러 층이 따로 판정했다.** 실행기는 dict만 보고 성공을 기록했지만 봉투 어댑터는 JSON 문자열도 해석했다. 부작용 선언은 있었으나 판본 2 검사는 재사용하지 않았다. 공통 통화 분류기와 기존 op 해소 규칙을 연결했다. 새 액션 이름을 코어에 박지 않았다.
2. **표시용 축약이 실행 값의 계약을 대신했다.** 성공 문구 속 경로, meta 속 식별자, 메시지 속 검수 결과, 날짜의 표시 시각을 다음 단계가 재해석했다. 생산자가 구조 값을 주고 소비자가 그 필드를 사용하도록 고쳤다.
3. **사용자 선택과 원천의 불완전성을 혼동했다.** 미리보기·정상 limit·가격 필터로 줄어든 결과가 실패였고, 구조가 사라진 외부 응답은 정상 0건이었다. 생산자가 순회 종료·요청 충족·자원 상한을 구분하도록 했다. 실제 원천 상한은 계속 실패로 드러난다.
4. **도메인 저장 행과 공개 반환 행의 경계가 없었다.** 인증 칸이 추가된 DB 행을 그대로 내보냈다. 이웃 생산자에 허용 필드 투영을 두어 list/detail뿐 아니라 save/merge 영수증에도 적용했다. 정당한 포털 자격 발급 API 자체는 유지한다.
5. **읽기와 초기화, 프로젝트 경로와 프로세스 cwd가 섞였다.** 없는 기억·건강 주체 조회와 포털 상태 읽기를 저장 동작에서 분리했다. 미디어 IBL 입구는 ToolContext의 경로 해소기를 사용한다.

## 남은 발견과 제한

- B78-4/5/6: 삭제된 노트북의 포식 기억 수명, book 몸 이름·locus 정규화, 정보나루 특수문자/XML 원천 문제는 미수리. 기존 기억의 의미·이동 및 외부 응답 계약 확인이 필요하다.
- B79-4: 번개장터 지역 후필터의 전국 표본 범위 문제는 미수리.
- B81-3: 사진 기본 범위에서 생성 산출물을 제외하는 정책은 미적용. EXIF 없음만으로 생성물이라고 판정하지 않는다. 촬영일 정렬의 후보 제한은 계속 고지한다.
- B73-4 재확인: 문자열 HTML의 기본 base_path는 연결했지만 모든 깨진 로컬 이미지의 prescreen 검출을 전수 보장하지 않는다.
- F80-3, F81-3/4 및 전체 F77-1: 게시판 detail 주 컬렉션, 음악 분위기/연도와 라디오 연결 키, 모든 원천의 구조 필드 전수화는 미수리.
- 정적 source별 필터 검증, 전체 open_params 축소, 관측 변이 및 과거 코퍼스 교재 재작성은 이번 변경으로 완료됐다고 보지 않는다.
- B80-1의 기존 훈련 영수증은 수정하지 않았다. 기존 자격증명 회전·영수증 처분은 실행 재개 무결성과 현재 포털 이용자에 영향을 주는 별도 작업이다. 새 반환에서는 인증 칸이 차단된다.
- 새 모델 호출·평가 루프·어휘는 추가하지 않았다. 품질 회귀를 검증했으며 완료 시간·전체 토큰 절감의 실제 작업 A/B 수치는 측정하지 않았다.
