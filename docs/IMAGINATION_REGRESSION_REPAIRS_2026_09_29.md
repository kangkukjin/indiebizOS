## 판정 기준과 공통 원인

실행 실패만으로 결함이라고 판단하지 않는다. 선언과 다른 실행, 입력 유실, 허위 완료,
틀린 진단을 결함으로 본다. `incomplete`는 미확정 검사가 남았다는 뜻이며 실행 보장이 아니다.
원본이 없는 과거 재무 데이터와 실제 기기의 위치 미수신도 코드 결함과 구분한다.

고친 공통 원인은 다음과 같다.

- 입력 존재·종류·행 수를 변환 전에 판별한다. 빈 목록은 정상적인 값이며, 목록을 놓친 결과 봉투가 문서 본문으로 새지 않게 한다.
- 문서의 모든 출력 형식 앞에서 같은 블록 정규화·검증을 거친다. 행 객체로 된 표와 제목 없는 카드는 값을 보존하는 표로 바꾸고, 렌더할 수 없는 블록은 파일 생성 전에 거절한다.
- 파이프·어휘 선언과 실제 소비·반환을 맞춘다. 복사 입력은 배열로 선언하고 Cloudflare 성공은 항상 items를 제공한다.
- 예약은 공통 시간 규칙으로 검증한다. 같은 실패 비교에서는 실행별 시각을 제거하되 금액·업무 값은 보존한다.
- 기본 범위를 숨기지 않는다. 주가 history의 상한 생략은 조회된 이력 전체, PC 사진의 경로 생략은 `~/Pictures`다.
