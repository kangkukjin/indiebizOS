# 방법의 지도 충실도 감사 — 2026-09-16

## 판정

기존 지도는 라이브러리·자료원·프로토콜 중심이었고 **조사·인과분석·의사결정·검증·학습의 이름 붙은 방법**이 부족했다.
도구 이름이 기존 상세 가이드에 있어도 짧은 카탈로그에는 빠진 경우도 있었다.
이번 보완으로 **66 → 114항목**이 됐다. 새 항목 48개는 **방법 32개 + 도구 16개**다.

고정한 추가 확인 질문 24개에서 유효한 이름을 선택한 비율은 **2/24 → 20/24**였다.
등재 공백은 메웠지만 4개 질문은 한국어 표현을 연결하지 못했다.
이 수치는 취약 영역을 겨냥한 작은 평가의 결과이며, 세계의 모든 방법에 대한 완성도나 실제 작업 성공률이 아니다.

## 평가 설계와 재현

- 기준판: `781eefc7`의 `data/knowledge_catalog/world.yaml`(66항목).
- [고정 질문](../data/knowledge_catalog/audit_cases.json): 12작업군, 개선용 24개, 추가 확인용 24개, 무관 질문 8개.
- 카탈로그 보완 전에 질문과 허용 후보 집합을 저장했다. 제품명을 숨기고 과제를 표현했다.
- 같은 작성자가 두 표현 집합을 만들었다. 독립 평가자·블라인드·실제 사용자 표본이 아니다.
- 개선용 결과로 별칭과 설명을 고쳤다. 추가 확인용 결과를 본 뒤 그 문장에 맞춰 별칭을 추가하지 않았다.
- 추가 확인 이후 기존 원본과의 대조로 기본 도구 12개를 복원했다. 이 변경은 해당 실패 문장을 겨냥하지 않았으며,
  고정 평가 결과도 바뀌지 않았다. 다음 개선의 확인 집합은 새로운 질문으로 작성해야 한다.
- 정답은 하나의 제품이 아니라 해당 작업을 수행할 수 있는 허용 집합이다.
  `registered`는 그 집합의 이름이 하나 이상 등재됐는지, `hit`는 실제 주입에 하나 이상 들어갔는지다.
- 명시적 부적합 후보(`reject`)와 그 외 미판정 후보(`unjudged`)를 따로 기록한다.
  허용 후보 하나가 나왔다고 모든 선택의 정밀도가 증명되는 것은 아니다.
- 두 판 모두 각각의 카탈로그로 임시 FTS 색인을 만들고 현재 운영 검색·렌더 함수를 사용했다.
  색인 유무에 따른 폴백 차이를 전후 개선으로 오인하지 않는다.
  과거 검색 코드 자체를 재실행하는 역사적 벤치마크는 아니다.
- 최대 4항목·전체 XML 600자 예산을 유지했다. 추가 모델 호출이나 임베딩 다운로드는 없다.

## 보완 내용과 근거

[항목별 근거·적용 조건](world_map/F_methods_and_validation.md)에 공식 문서·저자·기관 자료와 대안을 연결했다.

- 조사·추론: 체계적 문헌고찰, 인용망 추적, 주제분석, 툴민 논증 모형.
- 실험·통계: 무작위 대조 실험, 요인 실험, 부트스트랩, 민감도 분석, 시계열 교차검증, 생존분석.
- 인과: 인과 DAG, 차분의 차분, 성향점수 매칭.
- 의사결정·최적화: MCDA, 파레토 최적화, 동적 계획법, 베이지안 최적화.
- 운영: 이산사건 시뮬레이션, 주공정법, 프로세스 마이닝, 가치흐름도.
- 검증: 속성 기반 테스트, 상태 기반 테스트, 델타 디버깅, FMEA, 결함수 분석, 위협 모델링.
- 사람·학습: 카드 소팅, 사용성 테스트, 여정 지도, 인출 연습, 간격 반복.
- 새 도구: RapidFuzz, Splink, Great Expectations, Playwright.
- 기존 상세 지도에서 복원한 도구: NumPy, Matplotlib, Pillow, pdfplumber, PyArrow, Trimesh,
  Skyfield, Qiskit, Gmsh, PyVista, Cantera, Lean 4.

무작위 실험과 관찰자료 분석, FMEA와 결함수 분석, 문자열 유사도와 개체 연결처럼
비슷해 보이는 방법의 적용 조건을 근거 문서에서 구별했다. 모든 조건을 짧은 주입에 넣거나 검색기가 이해한다고 주장하지 않는다.
주제분석 저자 페이지는 직접 열람이 실패해 공식 도메인의 검색 색인 내용을 확인했으며 해당 항목에 그 상태를 표시했다.
새 도구 네 개의 정확한 pip 이름은 공식 설치 문서로 확인해 [실행 통로 가이드](../data/guides/world_tools.md)에 추가했다.
설치나 실제 도구 실행은 이번 감사에 포함하지 않았다.

개선용 질문에서 보인 오탐은 다음처럼 줄였다.
Zotero의 ‘참고문헌’은 ‘참고문헌 관리’, 성향점수 매칭의 ‘관찰자료’는 ‘관찰자료 매칭’,
MCDA의 ‘우선순위’는 ‘대안 우선순위’로 좁혔다.
Playwright 설명에 있던 사용자·화면 일반 단어가 실험 질문에 붙지 않도록 가능한 연산 중심으로 바꿨다.
무작위 실험의 ‘무작위 배정’은 동사 활용 ‘배정해’에서 연결되지 않아 방법을 식별하는 ‘무작위’ 별칭도 제공했다.
