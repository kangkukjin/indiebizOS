# Mind2Web 에피소드 감사와 수리 — 2026-10-23

대상은 `data/world_pulse.db`의 5427~5439번 에피소드와 study 대화 원장,
`projects/study/mind2web2`의 제출 답변·수집기·채점 결과다. 에피소드·대화 DB는
읽기 전용으로 조회했다. 5427은 시험 선택, 5428은 실행·채점 총괄,
5429~5438은 개발 세트 10문제, 5439는 점수 해석이다.

## 판단 기준

셸 사용은 오류나 낭비가 아니다. 셸만으로 잘 해결되는 일은 그대로 둔다.
IBL과 셸을 오갈 때 같은 값을 모델이 다시 쓰거나 이미 읽은 원문을 재수집하는
비용, 실패의 잘못된 진단, 중복 집계를 고친다. 셸 호출 수 감소를 성과로 삼지 않는다.
