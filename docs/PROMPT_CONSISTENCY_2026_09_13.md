# 의식 계획과 가이드 전달의 불일치 수정

시스템 구조 안내의 대폭 축약은 보류한다. 의식의 문제 규정·멈춤선·전제·권한·기준 출처와
기억 지도는 유지하면서, 확인된 잘못된 안내와 재조회 유도를 고친다.

- 의식 본문의 모든 실행 전 필수 경유 주장을 실제 조건부 호출에 맞춘다.
  질문은 기존 needs_clarification 조건으로 통일하고, 심층연구는 요청의 깊이로 선택한다.
  웹 검색의 1차 자료 접근 불가를 단정하던 예시를 없애고, 수치 비교 예시는 table 계산을
  사용한다. 선택 필드 imagined_ibl에는 불필요한 단순 검색 초안을 넣지 않는다.
- 계획 호출은 PLANNING_TOOL_PROMPT를 명시적으로 붙인다. 중간 감독 ROLE_PROMPT를 문장으로
  잘라 붙이던 경로를 제거해 REWORK·repair_scope 지침이 계획 JSON에 섞이지 않게 한다.
  중간 감독 자체의 지침과 최종 평가 계약은 유지한다.
- 가이드는 전문 시작·끝과 미제공 상태를 표시한다. 동일 파일은 한 번만 주입한다.
  파일 누락·빈 본문·읽기 실패를 전문 제공으로 주장하지 않는다. 현재 전문이 있으면 적용하고,
  이름만 있거나 잘림·요약·변경 근거가 있으면 다시 읽는다. world_tools 전문 주입도 기존
  자작 관문의 지도 확인으로 기록하여 재열람 생략이 불필요한 거절을 만들지 않게 한다.
- 감독의 액션 목록과 상세 계약도 실행자와 같은 self_can_run 및 허용 노드 판정을 사용한다.
  잠든 어휘·이 몸에서 실행 불가능한 어휘를 사용 가능하다고 소개하지 않는다.

검증은 가이드 누락·중복·삭제·읽기 실패와 지도 확인 관문, 계획·재규정 호출 조립,
어휘 잠재우기·깨우기·노드 제한을 실제 코드 경로로 검사한다. 모델 행동의 성공률이나
속도 개선을 증명하는 비교 실험은 아니며, 그런 개선 수치를 주장하지 않는다.

줄 수는 빈 줄을 포함한 물리적 줄 수로 측정한다. 의식 역할 본문은 수정 전후 218줄이고,
계획에 붙는 작업대 지침은 30줄에서 13줄로 줄었다. 시스템 구조 문서는 변경하지 않는다.
역할 본문·구조 코어·계획 작업대 지침을 실제 연결 형식으로 합치면 367줄(23,498자)이다.
이는 감독이 있는 계획 호출의 고정 본문이며, 가변 입력·도구 스키마·외부 하네스 지침은 제외한다.

집중 회귀 107개와 자작 관문을 포함한 추가 검사 27개가 통과했다(두 검사에는 중복이 있다).
전체 `.venv/bin/python3 -m pytest backend/ -q`도 종료 코드 0으로 완료했다.
의식 출력 스키마 검사와 Android 몸 번들 재생성도 완료했다.
