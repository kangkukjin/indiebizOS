Documentation update: 2026-08-28 — **The language's remaining gaps were found by writing real programs in it.** Three reports that had been driven by hand every morning were rewritten as complete IBL programs; the rewrite exposed eight things the language could not say, and all eight were closed in one pass (bracketed path expansion and optional paths, `each` keeping failed rows in the currency, a non-matching `if` in pipe position passing the previous currency through, conditional `when` clauses on document blocks). Alongside that, **failure got a location**: every failure envelope now carries a traceback — frame path, error type, the input at the point of failure — with no exemption for partial failures inside `each` or a parallel branch, and an AI step can fail *on quality* via `criteria`, with one retry and an honest `unjudged` when the judge can't decide. Two operational lessons were recorded with them: **crystallizing a capability is only half the job — a guide has to name the path to it**, or a registered script and a live quality contract simply go unused; and **the lever on speed is not the number of model round-trips but how many characters the model reads**, which now has an instrument. The 2026-08-25 note it replaces stands in the docs: a new action/op is complete only when handler, catalog prose, hippocampus corpus, and observed argument shapes close together. The long-form digest below remains the historical summary through 2026-08-22.

Last updated: 2026-08-22 — **A sentence became a program, and the body learned to remember its own changes.** Two threads. First, **the language grew grammar, not vocabulary**: predicates that read a previous step's result without re-running it, `[try]/[catch]/[finally]` plus an `[on_error:]` statement prefix, `[repeat:]` with an honest reason for stopping, one-line assignment (`$n = $n + 1`), blocks usable as a pipe segment, and `$return`. The entire set cost exactly one new action (`[table:reduce]`) — everything else is syntax. The line was drawn on purpose: general data structures and recursion stay *out* of the language and freeze into registered scripts, because a harness language that grows into a programming language stops being writable by a small model. In the same pass, saved sentences became **functions** — name, signature (any `$name` left unassigned in the body, computed at save time), defaults, return value, isolated scope, composition — with missing arguments now refused honestly instead of flowing through as a literal, and self-calling workflows refused with the call path shown. The agent-facing envelope went on a diet at the same time (step summaries with the full result only at the end, `verbose` to opt out), oversized currency spills to a reference automatically, and a failed pipeline hands back a `resume` token so the next attempt re-runs nothing. Second, **provenance**: the system can now answer *"why did this file change?"* about itself. Git covers tracked files; a write-gate ledger covers the runtime writes git can't see; `[self:body]` is the vocabulary that recalls both; and an actor envelope (who / which task / what origin) rides along so the ledger, the episode log, and the task table join up. Deliberately partial by design — gate hooks only, no filesystem-watching daemon — and the reading verb *advertises* that partiality rather than implying completeness. The documentation got the same treatment: every count in these files is now regenerated from the registry by the build, with a weekly audit flagging prose that has quietly gone stale. **6 nodes, 151 actions, 41 tool packages.**

Previously (2026-08-17) — **The language got smaller, then it learned to make sentences.** Two months of work pulled in the opposite direction from how tool catalogs usually grow. First, **compression**: 163 actions down to **144**, by deleting compounds in favor of universals (one hardcoded-URL research verb became "any RSS/Atom feed"), folding same-shaped words onto an axis (five search verbs → `[sense:search]{source}`, four business-ledger verbs → `[self:ledger]{store, op}`), and refusing to mint a verb for anything that was only an ordering of existing verbs — those freeze as registered scripts instead, which makes "should I add a word?" default to no. The axis has to stay honest: contacts folded into `[others:neighbor]{op}` rather than the ledger, because `store` is the axis of *peer* ledgers and contacts are a child collection. One measurement lesson worth keeping: **a call count is not a life sign** — a retired action had 19 recorded calls and had never once returned a result. Second, **grammar**: a full census of the corpus showed the median pipe was two steps and the language had essentially one sentence shape, because "for each thing you found, do this" was unsayable. `[table:each]{do, as}` is now the one higher-order verb (it takes an IBL *sentence* as a value), `rename`/`flatten` closed the currency algebra, and condition blocks (`[if:]`/`[case:]`/`[else]`, plus `[goal:]` for standing objectives) work at statement position with recursive dry-run inspection. The condition language is deliberately narrow — the left side must be a real IBL source reference, and **a natural-language condition is not evaluated**. Adding grammar exposed a class of bugs worth naming: places where the system *couldn't tell* and reported something definite anyway (a failed condition rendered as "else", an empty result as success). Those became explicit failures, and the shape is now something we hunt on purpose — anywhere there's a fallback branch, check whether "I don't know" is being printed as "no". Third, the parts of the system that aren't user-facing got structural work: the backend's ~195 modules moved into **layer directories** (`base → datastore → ibl → cognition → services → surface`) with a one-way dependency guard at commit time; and self-modification dropped its human-approval gate in favor of a **REPAIR path** (only on a task the user directly commanded, forced to the top model tier, consciousness forced awake, with syntax pre-check, backup, and a *detached* watchdog that restores and reboots if the edit kills the server). That last one taught the most general lesson here: **a step that has to run after your own death cannot be in your plan** — the old convention had the editing agent clean up its own marker, but the edit triggers the reload that kills the turn. Ownership of that step moved to a process that outlives it. **6 nodes, 144 actions, 40 tool packages.**

Previously (2026-08-01) — **What you receive reaches you, what you built gets counted, and the checks grow past the vocabulary.** Three fixes of the same shape: things that existed but had no way of reaching anyone. Incoming messages (Nostr, Gmail) were being *saved* and nothing else — you had to open the messenger to find out. They now pass a single dispatch point: the notification tray, a native OS notification with a badge when the launcher is open, and a dependency-free desktop fallback when it isn't (with a tray icon on Windows and Linux, so closing every window doesn't stop reception). A web-push path was built for the remote launcher on the same principle and then **retired the same day**: it never arrived on the real device, because two PWAs on one origin make Android delegate notification permission to just one of them — permission belongs to an *origin*, not an app. That's recorded rather than retried. Second, this system keeps *producing* web apps — public faces, portal-lent instruments, external workers — and had no list of them. `[self:webapp]` is a registry that is **derived, not kept**: it recomputes from seven sources of truth on every call (a hand-maintained ledger drifts), and `status` measures the whole fleet's liveness in parallel rather than trusting the list. A wild Cloudflare Worker sitting in the outputs folder was picked up on the first run. Third, the three-way check that has long held the *vocabulary* together was extended to the **seams** — the parts that aren't actions: an auth gate that now fails closed instead of open, a guard that asks the live route table (not a re-parsed list) whether every publicly exposed route really has its own gate, an AST scan for blocking calls in async code, and a fresh-clone CI, since `main` turned out to pass only on the machine that wrote it. Boot steps that are allowed to fail are now instrumented instead of vanishing into stdout. Two axes also got separated from each other. Whether an action has **side effects** was being derived from what it *returns*, which meant the cockpit's dry-run waved deletions through as "no side effects"; that is now its own declaration. And a family of actions that returned a list while declaring themselves effects — so pipes silently broke on them — was repaired one by one. The warehouse learned to look outward: browsing by genre, a neocities adapter (1.69M personal homepages become candidates), and public recommendations you rewrite before they go out; business items now publish a self-contained catalogue page (photos embedded, so it still works after someone downloads it). Removal counted as work too — five unused music features were retired, taking their vocabulary, their instrument, their derived cache, *and* their fifteen hippocampus examples with them, because installing and uninstalling should be symmetric. **6 nodes, 163 actions.**

Previously (2026-07-25) — **Bodies stop sharing a dictionary and start talking; a USB stick becomes a limb; the newspaper, the music, and the video all become first-class.** The biggest change is conceptual: bodies (your PC, your phone, a borrowed machine) no longer share one vocabulary over a privileged pipe. Each install now owns **only its own dictionary** — the catalog and the hippocampus both filter for ownership, so *you don't learn someone else's words* — and bodies reach each other by exchanging a **calling card** (`GET /nodes/card`, a description-only projection, ~70 tokens) and then **asking in plain language** (`[others:ask]`): the receiver compiles the request with its own dictionary, runs it, and returns the result, or honestly declines. What makes a body special is not wiring but **rank** — bodies are neighbors in the same CRM at a level you granted, so your phone is just your highest-level neighbor and a stranger's ask is refused by the same gate as anyone else's. In the same spirit the indexical senses (*where am I*, *what do I see/hear*) stopped being phone-only: they mean the same thing everywhere, each body answers its own way, and a body without the hardware says `no_hardware` rather than guessing. The surfaces were split to match — the remote launcher is *part of the PC* (five tabs), the phone app is *its own system* (three), with the phone's cockpit now compiling locally. A stick in your pocket can also be a body: plug it into an unfamiliar PC and `[self:limb]` / `[limbs:guestpc]` make it a **thin limb** — shell and files, no eyes — with the brain and identity staying on your hub, one revocable key on the stick (never your password), and the helper dialing *out* so that PC's firewall is untouched. The `runs_on` tag that used to say `mac_only` now says **`pc_only`**, because what it always meant was *compute-class*, not macOS. Three things also stopped living only in one screen's code: the **morning newspaper** is now a real action (`[engines:newspaper]`, so pressing publish from a phone browser produces the same paper as pressing it on the desktop), your **music library** became `[self:music]` — a scan of your own files with album art and playlists, plus a *related-song graph* (weighted edges, a random walk you can just let play, and a graph instrument you navigate by clicking) — and **public video finally plays like video**: a long film starts in about a second instead of after a full transcode, shows its true length, carries its subtitles, and can be seeked on first watch, with the same encode quietly filling the cache. Action count **157 → 162**, 42 tool packages.

Earlier (2026-07-21) — **The body's address becomes derived, and the author's Mac moves onto its own product**: a body's public identity is no longer configuration scattered through files. The remote launcher and finder now *derive* their URLs from whichever face the warehouse actually serves (one `origin_host` resolver that follows Cloudflare ↔ Tailscale switches), the auth gate went **fail-closed** (an unregistered host is treated as external, and proxy signals are read before `Host` — which cloudflared rewrites), and every open remote address is listed in one place. The installer no longer ships body-exclusive identity or personal data (Worker name, tunnel credentials, `wrangler.toml` separated out), and Cloudflare provisioning now creates the R2-cache Worker as part of issuance — after which the Mac's own hand-crafted Worker and tunnel were migrated onto that same provisioner (token tunnel; extra hostnames keep the phone delegation intact). **The machine this system was built on now runs on exactly the mechanism a fresh install gets.** On the reading side, the warehouse window became a finder, the neighbor tab became feed cards with an in-app finder into a neighbor's warehouse (discovery pinned to `#indienet`), and a neighbor's warehouse takes a **favorite score (0–3)** — your own rating axis, independent of the access level they granted you — filtering feed and search. Public warehouses serve a join page, and signing up or logging in through the in-app browser **captures the credential on the spot** — from then on both your browsing and the poller run at your granted level, with `[others:neighbor]{op: merge}` closing the duplicate-neighbor loose end. And the axis that decides *where a result lands* was corrected: it used to read which body executed, so pressing play in a phone browser sent the sound out of the Mac's speakers. It now reads **which surface asked** — the same instrument plays on the device you are holding, and an explicit `mode` still overrides it. The clipboard rides the same axis in the other direction: any browser ships its clipboard to the hub in one tap (with a paste box for browsers that refuse to read it), labelled for a hub that may be a Mac *or* a Windows PC. And both remote surfaces became **installable to the home screen** — a web app manifest each, so the launcher and the finder (**IBFind**) sit as two real apps with their own icons, no address bar, and service workers that cache nothing. Installer channel at v1.4.0. Zero new IBL verbs, action count unchanged (**157**).

Earlier (2026-07-20) — **Dialect adapters + member subscription + a fresh-environment triple fix**: the warehouse poller gained a **dialect-adapter layer** — nginx/Apache directory indexes, RSS/Atom feeds (auto-discovered from HTML), Nextcloud public shares, and the file links on ordinary web pages all normalize into the same manifest currency, so someone becomes a neighbor without installing anything (a cold-start bypass: the existing web is the warehouse network's first neighbors). Earlier (2026-07-18) — **The shared warehouse — the node gets an address, and a reading half**: the public surfaces so far were destinations you *make*; the warehouse is the node itself being reachable. Level folders (`공유창고/0..4/`) on your disk are served live at the node's bare root with no index and no conversion — schema-on-read, the reader interprets, so serving costs the owner ~nothing. A viewer sees levels `0..their level` merged into one flat list (higher wins, 404 rather than 403 above their level, with a single deliberate `has_restricted` "there is more" smell), and the level is the *same* scale as their grade in your neighbor CRM. Beside the human page, `/manifest` serves the same walk as JSON with a self-describing `about` and a `login` block, so a foreign AI agent can read the node without scraping HTML. The genuinely new half is **subscription**: a background poller fetches registered neighbors' manifests every 30 minutes, diffs paths/mtimes into a timeline (`seed` / `new` / `changed`), and retains a snapshot that doubles as a **filename index of the whole neighborhood** — a pure machine layer, zero model calls. A warehouse address is stored as a *contact type* on a neighbor (so it sits beside their email and Nostr key, and an address-only stranger is still a proper neighbor, self-named from their manifest), and a repost is a plain `.url` pointer file that resolves to the origin when your manifest is served — **friend-of-a-friend discovery reduced to a file**. All of it composes from existing vocabulary: **zero new IBL verbs**, action count unchanged (**157**).

Earlier (2026-07-17) — **The community surface — publishing to the open web at personal scale**: a family of `others` actions turns an IBL flow into a real public web address, no server or deploy — `[others:portal]` personal portals at `/h/<slug>/` (multiple portals, each owning its own member roster + display dial; login by id/pw or an operator-issued key; members *are* your neighbor CRM, levels 0 guest → 4 family; a per-portal audio proxy so borrowed instruments stream through your home IP), `[others:family_news]` a family newspaper at `/n/<slug>/` typeset from phone photos with guestbook + uploads, `[others:bulletin]` login-free bulletin boards at `/b/<slug>/`, and `[others:showcase]` public file shares at `/s/<slug>/` served straight off disk (on-the-fly directory walk, EXIF strip, video transcode).
