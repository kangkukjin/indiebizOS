# 웹 검색·크롤링 신뢰성 수리

2026-09-15 점검에서 발견한 본문 손실·출처 혼선·거짓 성공·무제한 수신 대기를 수리했다.
정본 저장소에서 수정했으며, 기존 액션 이름과 입력 문법은 유지한다.

## 변경

### 요청과 브라우저 페이지를 묶는다

- Playwright는 세션 초기화를 잠금으로 직렬화한 뒤 요청별 새 탭을 만들고, 반환된 ID의 페이지를 직접 읽는다. 기존 headful/headless 모드는 유지한다.
- 초기 탭/새 탭과 context의 page 이벤트가 같은 페이지를 두 번 등록하지 않는다. 탐색 실패·취소 때 호출자가 ID를 받기 전이라도 해당 탭을 닫는다.
- Chrome MCP도 수집 전용 탭을 만들고 마지막에 닫는다. 사용자가 쓰던 탭 ID를 수집에 공유하지 않는다.
- crawl 모듈을 매번 로드하더라도 전용 BrowserSession은 프로세스 싱글턴을 재사용한다.

### 본문 추출과 오류 판정

- DOM 블록의 여닫는 경계를 순회해 div의 직접 텍스트, 중첩 목록의 부모 문장, 본문 머리말, 그림 설명을 순서대로 한 번씩 보존한다. pre의 줄바꿈·들여쓰기도 보존한다.
- `share` 같은 부분 문자열로 주주 서한(`shareholder-letter`)까지 지우던 규칙을 명시적인 UI class/id 일치로 좁혔다. 일반 스크립트·메뉴 등의 제거는 유지한다.
- Playwright의 실제 탐색 응답을 확인해 HTTP 오류를 실패 처리한다. Chrome은 Navigation Timing의 실제 상태·최종 주소를 확인하며, 지원되지 않아 상태를 알 수 없으면 `http_status_unverified`로 다음 경로에 넘긴다.
- 정적/브라우저 HTML 결과는 확인한 `resolved_url`·`http_status`를 보존한다.
- 잘못 추출한 본문·오류 페이지가 들어 있을 수 있는 이전 캐시를 재사용하지 않도록 캐시 키를 v2로 바꿨다. 기존 불변 원문 스냅샷은 삭제하거나 덮어쓰지 않는다.
- 브라우저 future 대기가 30초를 넘으면 취소를 전달한다. Chrome 단계의 시간 초과도 단계 내역에 기록하고 Playwright를 계속 시도한다.

### 검색의 실패와 정상 0건을 구별한다

- HN의 통신·JSON 오류는 상위로 전달한다. 단일/배치/프론트페이지가 같은 실패 경계를 쓰고, 배치는 실패한 검색어를 `errors`에 기록하며 다른 성공 결과를 보존한다.
- Google News/RSS와 HN은 수신을 마친 바이트를 파싱한다. 소켓 대기 5초, 수신 경과 20초, 크기 5 MiB를 넘으면 오류다. 경과 시간은 `read1` 사이에서도 확인하며, 진행 중인 읽기는 소켓 대기 제한 안에서 끝난다.
- gnews/hn 배치 수집은 45초에 미완료 항목을 오류로 반환한다(후속 큐레이션 시간 제외). 실행 전 요청은 취소하고, 이미 실행 중인 수신도 자체 시간 제한으로 끝난다. 스레드를 강제 종료하지 않는다.
- Guardian의 timezone-aware 게시일을 `date`에 보존하며 큐레이션 합류 시에도 유지한다. 정상 0건 응답은 `success:true`를 명시한다.

## 검증

- 새 회귀 검사 27개: 동시 수집의 본문/출처 일치, 차가운 세션 초기화 1회, HTTP 오류 6종과 캐시 금지, 취소·탐색 실패 후 탭 회수, Chrome 독립 탭·상태 불명 처리, HN 부분 실패·정상 0건, Guardian 날짜, 다운로드·배치 시간 제한, 모듈 재로드 시 세션 재사용.
- 기존 관련 검사와 함께 **89개 통과**.
- 실제 독립 Chromium + 로컬 HTTP 서버: `/a`, `/b`, `/missing`을 동시에 수집해 A/B의 본문과 URL 일치, `/missing`의 404 실패, 수집 탭 전부 회수 확인. 로그인 상태는 임시 디렉터리로 격리하고 검사 후 브라우저 종료.
- 실제 네트워크: ddg/naver/gnews/hn/guardian 각 3건 검색 성공. 공개 Python 문서 2개 정적 수집 성공. 튜토리얼 목차의 추출량은 기존 5,425자 → 7,102자, 소개 페이지는 2,379자 → 2,671자.
- 전체 backend 회귀: 4,416개 통과, 정적 값 판정 관문 1개 실패. HTML UI class/id 비교를 사용자 통화 값 비교와 구별하는 규약 주석을 명시한 뒤, 해당 관문과 관련 검사 **97개를 재실행해 모두 통과**했다. 전체 실행 이후 추가한 세션 재사용 검사도 이 재검에 포함된다.
- IBL 파생·정합성, Android 몸 번들, backend 층 가드, diff 공백 검증 통과. 실행 중인 백엔드의 ACTIVE 상태 및 변경 파일의 manifest 일치를 확인했다.

## 검증 범위

Chrome MCP 경로는 가짜 도구 응답으로 오류·정상·상태 불명·탭 정리를 검증했다. 실제 사용자의 Chrome 탭을 조작하지 않았다. 실 브라우저 검증은 독립 Playwright Chromium에서 수행했다. 로그인/봇 차단을 모든 사이트에서 해결한다는 의미는 아니다.

회원 경로의 `principal` 분기는 유지한다. 회원용 검색·크롤은 계속 `member_web`의 공개 주소 검증·무쿠키·주인 브라우저 미사용 경로를 쓰며, 새 일반 수신 함수로 진입하지 않는다. 해당 분기를 재검토하고 web 패키지 실행 지문과 파생 어휘를 갱신했다.
