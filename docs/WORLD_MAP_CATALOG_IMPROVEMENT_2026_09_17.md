> 이 문서는 해당 구현 시점의 기록이다. 현행 공통 주입은 [후속 수정](WORLD_MAP_SHARED_INJECTION_2026_09_17.md)을 따른다.

2026-09-17. 직전 구현: `65af37aa`.

## 바뀐 기준

도서관의 장서와 카탈로그를 구분한다. 지도는 지식 본문을 복제하지 않고 분야·개념·방법·도구·자료원의
통용 이름, 짧은 구별, 편집 분류와 연결을 담는다. 항목별 상세 설명보다 빠진 지식 입구를 보강한다.
좋은 기존 접근과 학습 목적의 직접 구현을 존중하며 관점 전환·새로움을 성과로 요구하지 않는다.
비전·구현계획·기억 문서·편집 기준·두 전달 모드의 안내에 이 의미를 반영했다.

## 구현과 자료

- 기존 128어휘에 38어휘를 추가했다. 전체 166어휘, 편집 분류의 최상위 26개다.
- 명시 관계는 14→44개, 관계에 연결된 어휘는 17→59개다. 나머지도 분류 탐색으로 열람한다.
- 인문(구술사·정독·역개요), 경제(기회비용·비교우위·매몰비용·외부효과), 사업·협상,
  환경(전과정평가), 건강 연구근거, 말뭉치, 공간 분석, 학습·시스템 사고의 입구를 보강했다.
- 새 어휘는 `bridges.yaml`, 연결과 근거는 `bridge_relations.yaml`에 둔다.
  관련 참조는 동의·대체·필수 절차를 의미하지 않는다. 모든 항목에 조건·절차를 채우지 않았다.
- `세계지도` 스크립트에 `browse`를 추가했다. 빈 path에서 분야를 보고 category의 browse 인자로
  하위 분류를 연다. 어휘를 모르는 상태에서도 전체 항목에 도달한다. 분류는 의미론적 상하위 관계와 구별한다.
- 페이지와 하위 분류 이동은 revision을 고정한다. 구조·이름 전달 예산과 권한 경계는 유지한다.
- search에서 어휘 일치가 없고 질의 전체가 정확한 분류명이면 그 분류 항목으로 연결한다.
  일반 문장에 포함된 분야 단어만으로 확장하지 않는다. 검색 0건에도 최상위 browse 인자를 반환한다.
- 구조 전달에 분야 탐색 호출을 안내한다. 추가 모델 호출·임베딩·질문 중 웹 접근은 없다.

## 확인 범위

- 모든 어휘를 빈 path에서 시작하여 분류·페이지를 순회해 중복·누락 없이 찾는 테스트가 통과했다.
- 새 분야의 이름 없는 질문 20개에서 관련 어휘와 연결이 기본 전달 예산 안에 들어갔다.
- 기존 고정 질문 56개의 선택 결과가 이전 실행 기록과 같다.
  작성 24/24, 추가 확인 20/24, 무관 8/8 빈 결과다. 이전 검색 누락 4건은 남아 있다.
- 중간 검사에서 외부효과의 일반적 설명이 고장 분석 질문에 섞였다. 경제적 거래의 뜻으로
  설명을 명확히 하여 제거했다. 고정 질문에 맞춘 별칭을 추가하지 않았다.
- 기존 구조 전달 개발 사례 16/16 유지. 새 사례는 작성한 개발 회귀이며 독립 블라인드 평가가 아니다.
- 최종 관련·문서 검사 및 전체 회귀 결과는 아래 검증 기록에 남긴다.

비교 출력은 `outputs/world_map/catalog_expansion_comparison.json`, 기존 구조 입력은
`outputs/world_map/catalog_expansion_evaluation.json`이다. 출력은 로컬 감사 자료이며 gitignore 대상이다.

## 남은 한계

세계 전체의 완전한 분류나 모든 지식에 이르는 카탈로그를 완성한 것은 아니다.
법·예술·생활·자연과학 등의 입구는 여전히 고르지 않고, 다수 기존 어휘에는 명시 관계가 없다.
조회는 어휘 검색이며 자유로운 바꿔 말하기를 모두 이해하지 않는다. browse는 전체를 탐색할 수 있는
통로이지 소비자 모델이 모든 누락을 스스로 발견한다는 보증이 아니다.

출처 대조 범위는 [근거 노트](world_map/H_catalog_bridges.md)에 기록했다. 본문 열람이 실패한 자료는
공식 검색 색인으로 확인한 범위를 구분했다. 확인일·자료의 존재는 최신성이나 설치 가능성을 보증하지 않는다.
실제 모델의 답변 품질·간섭 감소·총 비용 개선은 이번 결정적 테스트로 측정하지 않았다.
