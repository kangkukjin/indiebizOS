## 비용·효용의 측정 경계

추가 모델 호출·질의 임베딩·질문 중 웹 조회·색인 재생성은 없다.
구조 입력의 기본 한도는 UTF-8 바이트/2 추정 1800토큰·6000문자이며 모델 청구 토큰이 아니다.
평가 스크립트의 elapsed_ms는 snapshot을 읽은 뒤의 검색·문맥 조립 구간이다.

위 검사는 어휘 도달과 구조 전달의 구현 증거다. 실제 소비자 모델이 좋은 접근을 유지하면서
불필요한 재구현을 피하는지, 최종 품질·총 비용이 개선되는지는 아직 모델 비교로 측정하지 않았다.
이름 수·대안 수·전환 횟수 자체를 성공 지표로 사용하지 않는다.

## 자료의 한계와 유지보수

전체 지도는 128어휘이며 모든 어휘에 typed 관계가 있는 것은 아니다. 기존 항목도 전체 분류·뜻·출처를 전달한다.
검색은 어휘 대조+FTS 동점 정렬이다. 별칭을 벗어난 의미 검색이나 조건 충족 자동 판정은 구현하지 않았다.
문맥에서 조건은 unknown이다. source 확인일은 세계의 실시간 갱신을 보증하지 않는다.

Blender·Three.js의 이번 외부 대조는 공식 검색 색인과 기존 가이드에 한정했다(공식 본문 직접 열람 실패).
OR-Tools·DuckDB는 공식 본문을 읽었다. 구체적인 출처·확인 범위는 G_structure_evidence.md에 기록했다.
관계 수정은 원문 대조→데이터·근거 문서/해시/날짜 갱신→build/--check→커밋으로 한다.
