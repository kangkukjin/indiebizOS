# 세계 지도 — 모든 작업 에이전트의 공통 주입

2026-09-17. 이전 구현: `42b68ba2`.

## 문제와 수정

세계 지도는 전체 카탈로그에서 현재 질문에 필요한 작은 어휘 조각을 추출하는 공통 인지 자료다.
그러나 기존 구현은 설정 미지정 시 꺼졌고, 로컬 설정은 한 에이전트의 허용 목록만 가졌다.
주체·Reflex·강제 역할·문맥 갱신에도 별도 제외가 있어 모든 작업 에이전트에 도달하지 않았다.

- 설정 파일/섹션이 없어도 켜짐·structure 모드로 동작한다.
- 에이전트 ID와 요청 주체로 세계 어휘 회상을 제한하지 않는다. 과거 허용 목록은 선택에 사용하지 않고
  `ignored_config` 사건 필드로 남긴다. 로컬 설정에서 그 목록을 제거했고 배포 예제도 기본 켜짐이다.
- 시스템·프로젝트·회원·위임 등 공통 `cognitive_stream`에 들어오는 작업 에이전트가 받는다.
  THINK/EXECUTE/REPAIR 외에 Reflex·포식 등 강제 역할·문맥 갱신 경로도 포함한다.
- 의식과 실행에 같은 조각을 한 번 전달한다. 내부 분류·증류 같은 개별 보조 모델마다 새 검색을 하지 않는다.
  모델 호출 없는 세션 초기화는 제외한다. 관련 어휘가 없으면 빈 결과가 정상이다.
- 전체 진단용 enabled=false만 명시적으로 끌 수 있다. 에이전트별 실험 허용 목록은 은퇴했다.
- 세계 어휘 공유와 주인의 개인 기억은 다른 경계다. 개인 기억 회상·실행 권한·주체 좁힘 규칙을 바꾸지 않았다.

## 전체 크기와 추출 크기의 구분

전체 지도 항목 수를 프롬프트 한도로 제한하지 않는다. 기존 문자·추정 토큰 상한은 추출 결과의
비정상 팽창을 막는 상한이며, 전체 지도의 크기나 에이전트별 사용 예산이 아니다.

자동 조각은 이름·분류·짧은 뜻·핵심 관계 중심으로 줄였다. 일반 관계의 상세 설명·출처 파일 경로·
확인일을 매번 반복하지 않는다. 필수 조건의 설명·미확인 표지는 보존한다.
근거 검증과 내부 WorldContext의 evidence는 유지하며 상세 조회 open에서도 계속 제공한다.

동일 seed를 비교한 예: Blender 1,565→1,208자, 근무표 1,639→1,300자,
KWIC 1,403→1,022자. 이 비교에서 포함된 어휘는 동일하다. 문자 수이지 실제 모델 토큰이나 비용 실측이 아니다.
측정은 `outputs/world_map/shared_injection_size.json`에 남겼다. 그 표의 '역개요' 단독 질의는
기존 어휘 검색에서 0건이며 크기 절감의 성공 사례로 세지 않는다. 자유로운 이름 변형 검색의 한계는 남아 있다.

## 폰 배포

기존 폰 번들은 검색 코드를 포함하면서 지도 데이터를 누락했다. 몸 번들 파생기가 실제 카탈로그를
읽어 본문·분할 파일·참조 자료의 목록을 자동 생성하고, Gradle이 같은 상대경로로 묶도록 고쳤다.
개인 설정이나 기억은 이 목록에 포함하지 않는다. 새 분야 자료도 카탈로그에 연결하면 함께 파생된다.

실제 `:app:bundleIndiebizBase --offline` 빌드가 성공했다. 생성된 ZIP에서 지도 자료 12개만 추출한
빈 디렉토리에서 166개 어휘를 로드하고 Blender 검색→5개 어휘·1,208자 주입을 확인했다.
개인 설정과 로컬 색인이 없는 배포 환경이므로 어휘 검색 폴백을 사용했다. 설치된 폰 앱을
교체한 것은 아니며 다음 앱 빌드에 이 자료가 포함된다.
