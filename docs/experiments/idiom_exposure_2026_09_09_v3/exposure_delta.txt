- [fn:원장에누적]{옛것: "…", 새것: "…", 키: "…", 원장: "…"} → effect
  언제: 기존 목록과 새 목록을 하나 또는 여러 열의 키로 중복 제거해 JSON에 누적 저장할 때. 같은 키는 기존 행 보존. 기존 행 갱신(upsert)은 하지 않는다.
  골격: union → dedup → self:write
  입력: 옛것·새것: items 봉투 또는 JSON 행 목록(변수 자체를 전달). 키: 열 이름 문자열 또는 열 이름 목록(복합키, 예 ["id","kind"]). 원장: 저장 경로. 같은 키면 기존 행 전체를 보존한다. 합성키 열을 만들지 않는다.
  조합 예: $옛목록=[self:read]{path:"기록.json"}; $새목록=[self:read]{path:"추가.json"}; [fn:원장에누적]{옛것:"$옛목록",새것:"$새목록",키:["id","kind"],원장:"기록.json"}

- [fn:최신범위읽기]{폴더: "…", 패턴: "…", 시작줄: "…", 줄수: "…"} → scalar  · 사용 1회
  언제: 좁힌 폴더에서 수정시각이 최신인 파일의 지정 줄 범위를 읽을 때. 파일명 순서가 아니다. 후보 200건 초과·동률이면 전체 최신 보장은 못 한다.
  골격: self:file_find → filter → sort → take → if → self:read
  입력: 폴더·패턴: 파일 검색 범위. 시작줄: 1부터 시작, 줄수: 1 이상의 읽을 줄 수. 반환은 본문 문자열; 후보 없음은 빈 items. 최신 후보 검색 상한은 200건이다.
  조합 예: [fn:최신범위읽기]{폴더:"reports",패턴:"*.md",시작줄:1,줄수:220}
- [fn:위치마다읽기]{위치: "…", 개수: "…", 줄수: "…"} → items⟨열 미상⟩
  언제: 파일·줄번호 열이 있는 위치 목록(grep 결과·JSON 파일·filter 결과)의 앞 개수곳을 각 줄번호부터 줄수만큼 읽어 위치·본문·실패를 한 목록으로 모을 때. 위치만 필요하면 그 목록을 그대로 쓴다.
  골격: take → each → self:read
  입력: 위치: 파일·줄번호 열이 있는 items(변수 자체를 전달 — grep 결과·read 로 읽은 JSON 행·filter/sort 결과). 개수: 읽을 위치 수(0 이상). 줄수: 위치당 읽을 줄 수(1 이상). 반환: 파일·줄번호·value(본문) 행, 실패한 위치는 _error 행으로 남는다. 본문 의미 판단은 하지 않는다.
  조합 예: $위치 = [self:grep]{path:"notes",pattern:"TODO",file_pattern:"*.txt",limit:20}; [fn:위치마다읽기]{위치:$위치,개수:5,줄수:12}
