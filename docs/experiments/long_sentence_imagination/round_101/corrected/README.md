## 오프라인 작업 조건

- 일반 앱 작업은 필요한 앱·파일이 Mac에 준비되어 있고 네트워크 없이 해당 파일을 열기·편집·저장할 수 있을 때 가능하다. 온라인 인증·클라우드 전용 파일 등 의존 여부도 확인해야 한다. 현재 해당 조건은 미검증이다.
- 후속 메모의 결론·실행 위치 표·U3·시작 가능 범위에 같은 조건을 적용했다. 확인 조건 C17, 질문 Q9, 점검 항목 J10을 연결하고 기존 질문 Q1·점검 J1에도 반영했다.
- 수동 검토 Q13에 따라 사용자가 AI 작업을 명시한 것처럼 쓰지 않고, AI까지 요구하는 경우에 한해 충족 불가로 판정했다. Q16에 따라 일반 앱의 작업을 AI 작업 지속의 성과로 세지 않는다.
- 회원 앱의 장시간 단절 기능(Q2)과 일반 앱의 편집·저장(C17)을 구분했다. D1 L176의 중앙 중단 시 로컬 파일 열기 서술만으로 일반 앱의 오프라인 편집·저장을 보장하지 않는다.
- B2의 진행 중 작업 즉시 정지 단정을 신규 단계 차단으로 한정했다. 이미 OS에서 실행된 명령의 즉시 종료는 D1 L217에서 보장하지 않으며 Q3 확인 대상으로 남겼다. 직접 편집 파일의 로컬 저장과 일반 앱 동기화·회원 원장 기록 여부도 구분했다.

## 중앙 보관 범위 교정

D1 L131·L153-L158은 기기의 장기 정본과 중앙 최소 메타데이터를 설명한다. D1 L238은 데스크톱 v2 접수 메타데이터의 등록 수명 보관과 본문/최종 결과의 RAM 최대 30분 조회를 서술한다. 반면 D1 L295-L301은 중앙 관리 화면에서 요청 내용을 포함한 통계·상세 작업을 조회한다고 적는다.

따라서 중앙 전체에 원문이 장기 보관되지 않는다는 단정과 로컬 백업이 유일한 보존 경로라는 결론을 철회했다. 통계 본문의 저장 위치·형태·보존 기간·삭제 조건·기기 기록 복원 범위는 **기존 문서만으로 미확인**이다. 최근 30일 조회 범위를 30일 후 삭제 규칙으로 바꾸지 않았다. 중앙 통계를 전체 원문의 백업으로 보장하지도 않는다.

A 첫 메모의 표·운영상 함의·문서 차이 10·권고 순서를 수정하고 C18과 점검 A9를 연결했다. 후속 메모의 보관/분실 설명·Q10과 점검 J11에도 반영했다. C12~C17은 기존 후속 확인 조건이므로 새 조건은 C18을 사용한다. 첫 메모 차이 10 추가에 맞춰 후속 차이 번호는 11~14로 정렬했다.

## API 평가 모델 설정 교정

R2 L36-L37은 현재 기어의 실행 에이전트와 별도 API 보조 모델 설정 불요를, R1 L441-L442는 연구 전용 CLI→API 보조 모델 치환 및 API 필수 검사 제거를 서술한다. 그러나 R2 L40에는 API 평가 모델 미설정 시 오류를 먼저 해결하라는 문장이 함께 남아 있다.

S8의 일괄 API 평가 모델 설정 지시를 철회했다. 선택한 실행 기어·제공자 설정을 확인하되, **보조 모델과 평가 역할의 관계 및 R2 L40의 적용 조건은 미확인**으로 남긴다. R2 L40이 단순히 폐기된 문장이라고 단정하거나 공통 평가 역할까지 언제나 설정 불요라고 주장하지 않는다. 해당 역할을 요구하는 조건·실제 오류가 확인된 경우 그 범위에서 설정을 확인하도록 했다. 이번 작업에서 실제 설정을 조회하거나 변경하지 않았다.

B 첫 메모 M10·D8·미확인 10과 시작 목록 S8, 후속 검토 K8·Q12·S8이 같은 결론을 가리킨다. 기존 후속 문서 D7(대화 삭제), Q10·Q11과 새 항목을 구분했다.

## 판정 범위

앞선 인용 10건·오프라인 조건 교정에 이어, 이번에는 A1 중앙 보관 범위와 B1 모델 설정 지적을 A/B 교정본에 반영했다. **지적된 문서 결함의 사후 편집은 완료했지만, 미확인 제품 동작을 검증 완료로 바꾸지는 않았다.** 최초 훈련 산출물의 품질 일부 미충족·독립 전이 및 비용 개선 미검증 판정은 유지한다. 교정본은 새 훈련 성과나 전수 품질 합격본이 아니다.

정답표·원시 비용·원래 인용 검사 결과는 보존했다. 편집의 운영자 토큰은 미측정이며 원래 실행 비용에 합산하지 않았다. 첫 점검 목록도 이제 보관 조건을 추가한 교정본이고, B 과제의 원본 3편을 바탕으로 별도 교정본을 추가했다.
