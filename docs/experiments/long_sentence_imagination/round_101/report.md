### 대화 공유와 접근 기록의 한계

훈련 표식 HTTP 경로가 리허설 legacy 세션을 이어 썼다. A1도 기존 이력을 가진 후속 턴이고,
B1·B2에는 A1·A2가 대화 이력으로 보였다. 설계의 독립 A/B 대화 조건은 충족하지 못했다.
도구 입력의 금지 경로 문자열 탐지 0건은 그 범위의 관측이며 접근 권한 격리나 이력 오염 부재의 증명이 아니다.
따라서 같은 세션에서 두 과제를 수행한 사실만 인정하고 **독립 전이 판정은 미검증**으로 둔다.

### 좌표 범위와 인용 정확성

최초 검사기의 552건은 문서 ID를 매번 쓴 좌표의 범위 검사였다. 이를 인용 전체의 의미 정확성으로
해석하지 않는다. 최초 검수자는 표본 68건 일치를 기록했으나 전수 의미 검증은 아니다.

수정 검사기는 `D1 L7, L101`·`D1 §5(L82)`처럼 같은 줄에서 문서 ID를 이어 쓰는 좌표도 읽고,
각 따옴표 구절을 독립 검사한다. 줄·구절 발생 위치와 일치 후보를 모두 남기며,
한 구절의 일치가 다른 구절이나 잘못된 좌표를 통과시키지 않는다. 인접 ±2줄만 일치하면 별도 검토다.

기존 산출물 재검사: **좌표 799건 모두 범위 안. 따옴표 구절 39건 중 정확 범위 후보 일치 17,
문구 불일치 12, 같은 줄 유효 좌표 없음 10**. 마지막 22건은 보존 사본과 주변 문맥으로 수동 판정했다.
**좌표 보완 1건, 원문에 부합하는 요약 9건, 자체 표현·내부 참조 7건, 자체 운영 권고 5건**이다.
직접 인용으로 쓸 때 좌표·표시를 보완할 항목은 10건이며, 이 22개 구절에서 새로 확인된 원문 날조는 없다.
자체 표현·권고 12건을 외부 원문의 직접 인용으로 세지 않는다. 상세 구절·좌표·대조 원문·보완 문안은
[22건 수동 판정](harness/quote_manual_review.md)에 남겼다.

Q13의 AI 파일 작업은 사용자 원문의 조건부 해석이며, Q16 주변의 일반 프로그램 작업 가능 단정은
로컬 앱·파일과 오프라인 편집 조건을 확인해야 한다. Q18의 snippet 제한과 Q21의 정본 위치는
이번 과제의 운영 권고이지 제품의 강제 규칙이 아니다. 따라서 이번 검토로 전체 품질을 합격으로 올리지 않는다.
후보 일치 17건도 문장 전체의 논리·귀속이 옳다는 보증은 아니다. 새 수치를 옛 552건과 동일 모집단으로 비교하지 않는다.
상세는 correction_audit.json의 `citation_results`에 전건 보존했다. AI 원문은 수정하지 않았다.

## 4. 실제 근거 활용과 비용 해석

**‘후속 본문 재독 0’과 ‘새 인용을 모두 문맥에서 회수’라는 최초 설명은 철회한다.**
기존 도구 입력 원문에서 다음을 확인했다([source_read_commands.json](harness/source_read_commands.json)).

| 턴 | 보존된 호출 | 해석 |
| --- | --- | --- |
| A2 / event_seq 42 | 입력 D*.md에서 오프라인·단절·격리·OS 계정 등의 `grep -n` 검색 후 `cut -c1-200` | 조건 변경에 맞는 원문 일부 재조회. 목록·줄 수 확인만 한 것이 아님 |
| B2 / event_seq 52 | R1 11곳·R2 3곳·R3 4곳의 `sed` 조회 후 줄당 80바이트 표시 | 저장 뒤 18개 원문 좌표를 재검수. R3 인용 범위 자기 교정 1건과 연결 |

기본 턴에도 A1의 D4 일부 재확인과 B1의 좌표 검수가 있었다. 전부 중복 낭비로 세지 않는다.
관측한 행동은 **전체 본문 재적재 없이 이전 결과·문맥과 선택적 재조회를 사용해 수정함**이다.
특정 새 좌표가 기억과 검색 중 어느 경로에서 왔는지는 이 기록만으로 전건 귀속할 수 없다.
IBL 호출은 네 턴 모두 0이므로 IBL 영수증 재사용이나 언어 작성 능력의 성과로 세지 않는다.

주요 비용 후보는 기본 턴의 넓은 자료 읽기, 결과 작성·검수, 실행 외 모델 호출이다.
필요한 판단·검수에 기여했지만 그 양 전체가 최소 필요 비용이었다고 입증한 것은 아니다.
현재 기록에서 **확정한 불필요 중복은 없음**, 최적 비용이라는 주장도 없음으로 남긴다.
A1/A2와 B1/B2는 서로 다른 요구이고, 과거·수리 후의 맞춘 비교쌍도 없다. 후속이 빠르다는 사실을 절감률로 쓰지 않는다.

## 6. 최종 판정과 증거 보존

1. **수행:** 네 요청에 실제 산출물이 있고 최초 파일을 보존했다. 조건 변경의 핵심 요구는 처리했으나 A1·B1 공통 품질 기준 미충족으로 전체 합격은 아니다.
2. **활용:** 이전 결과·문맥과 부분 원문 재조회를 함께 활용했다. 재조회 0이나 모든 비용의 필요성을 입증하지 않았다.
3. **전이:** 동일 세션에서 두 과제를 처리한 관측이다. 독립 새 대화에서의 전이는 미검증이다.
4. **효율:** 공유 세션 조건의 비용 기록은 확보했다. 비교 가능한 전후 쌍·전체 운영자 비용이 없어 비용 개선은 미검증이다.

정정 전 문서 8개는 `data/_backups/2026-10-28_round101_evidence_correction/`에 보존했다.
기계 재검사 출력에는 입력 산출물 해시와 모든 좌표·따옴표 구절 판정이 있다. 정답표·AI 출력·원시 비용은 수정하지 않았다.
검증: 인용 검사·비용 합산 회귀 **14건 통과**, 보존 입력 7편의 원래 해시 일치와 산출물 7개의 기계 재검사.
직접 실행 시 pytest로 위임하는 진입점을 보완한 뒤 단일 러너 규약 4건을 포함해 **18건 통과**했다.
추가 검증: 수동 대상 22건의 누락·중복 없음, 원문 사본 7편과 감사에 기록된 원시 수집·산출물 해시 일치, 검토 문서의 근거 링크 확인.
의미 검토는 수동 구절 22건·위 특정 쟁점·기존 표본 범위이며 799개 주장 전수 검토가 아니다.
훈련 재실행·실모델 호출·제품 백엔드 수리는 하지 않았다.
