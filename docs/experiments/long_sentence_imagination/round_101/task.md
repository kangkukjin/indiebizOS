## 실행 구성·진입점·격리
- 네 요청 전문 = `msg_A1.txt`·`msg_A2.txt`·`msg_B1.txt`·`msg_B2.txt`(설계 §4 문안 + 입력/출력 경로 + 격리 문장만 추가. IBL·함수·재사용·읽기 순서 지정 없음).
- 진입점 = 검증된 `POST /system-ai/chat {message, origin:"training", background:true}` → `GET status_url?wait=20`(가이드 §4-5). 전송·회수 = `send_ai.py`, 집계 = `collect.py`(world_pulse.db 읽기 전용, call_id 중복 제거).
- 출력: A → `ai_out/A/`, B → `ai_out/B/`. 각 기본 턴 종료 직후 산출물 목록·sha256 스냅샷(`harness/snapshot_*.json`)을 떠서 후속 턴의 "최초 파일 보존"을 대조한다.
