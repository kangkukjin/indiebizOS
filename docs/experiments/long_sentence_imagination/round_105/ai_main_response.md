## 등록한 것
- **함수 `장비점검청구대사`** (인자: 장비, 점검, 청구 목록)

  - 금액은 amount를 쓰고, 없으면 fee에서 ₩와 쉼표를 떼어 씁니다.

  - 연결되지 않는 청구는 원래 행 그대로 unmatched에 넣습니다.
- 기존 기능 중 이런 대사를 하는 것은 없었습니다. 대신 등록에 쓰는 기존 기능 `능력변경완료`를 활용했습니다.
- 파일 읽기와 저장은 등록 함수 밖에서 합니다. 다음 달이나 다른 지점은 파일 세 개를 읽어 같은 함수를 부르면 됩니다.

## 어디까지 확인했는지
1. **등록 절차:** 함수 원장에 실제로 저장되었고, 다시 조회했을 때 판본이 일치했습니다(`complete:true`, `observed.matches:true`). 이 함수는 소스 코드 반영이 필요 없는 종류여서 해당 항목은 "필요 없음"으로 처리되었습니다.
2. **등록 과정의 동작 검사:** 5행짜리 합성 표본(fee 표기, 재접수, null, 대장에 없는 번호 포함)을 넣은 새 호출 1건이 손으로 계산한 기대값과 정확히 일치했습니다.
3. **이번 실제 처리:** 함수 정의를 따로 넣지 않고 등록된 함수를 불러서 처리했습니다. 실행 기록에 호출된 판본(`06cb658c…`)이 등록 판본과 같게 남아 있습니다. 결과는 위 검산과 저장 파일 다시 읽기로 확인했습니다.
