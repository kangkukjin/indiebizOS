청구 형식 정규화를 별도의 등록 스크립트로도 제공해 줘. 다른 월말 프로그램이 IBL 함수 본문 대신 등록 스크립트의 JSON 입력·출력 계약을 호출해야 해. 입력 {rows:[원청구행]}에서 invoice_id, asset_id(없으면 machine), amount(원 정수, amount 숫자 또는 fee의 ₩/KRW 접두·쉼표)를 해석하고 원행은 raw로 보존해 {items:[{invoice_id,asset_id,amount,raw}]}를 돌려주면 돼. 금액이 없거나 정수가 아닌 경우에는 0으로 바꾸지 말고 실패시켜 줘. 기존 같은 기능의 등록 스크립트가 있으면 개정하고, 없으면 적절한 이름으로 등록해 줘. 호출 계약을 선언하고 등록된 이름으로 정상 입력·잘못된 입력을 확인해 줘. 이 부품의 결과를 실제로 소비해 inputs_variant의 전체 대사를 outputs/report_script.json에 만들어 줘. 보고서 조건은 report_variant와 같아. 등록부 반영, 새 호출 검증, 소스 각인 상태를 구분해 알려줘.
