## 3. 접근과 선택 이유
이 질문은 '무엇이 어떤 조건에서 더 효과적인가'와 '실패가 어디서 생기는가'를 묻는다. 그래서 방법 소개를 모으는 것이 아니라, 같은 자료와 같은 질문, 같은 관련성 판정으로 방법을 비교하는 작은 검색 실험을 설계한다. 실험 결과는 질문별 실패 분류로 해석한다. 원문 조사는 각 방법이 어떤 실패를 고친다고 주장하는지, 그리고 그 주장의 조건(도메인, 언어, 단위)을 확인하는 데 쓴다.

**비교 후보(잠정).** 시간이 모자라면 아래 번호 순서대로 줄인다.
1. BM25, 공백 토큰화. 사용자가 말하는 '키워드 검색'의 기준선이다.
2. BM25, 한국어 처리(문자 bigram 등). '키워드 검색 개선'에 해당한다. 한국어는 조사·어미 때문에 공백 토큰이 잘 일치하지 않는다. 그래서 1번만으로 어휘 검색의 한계를 판정하면 오독이 된다.
3. 로컬 밀집 임베딩(다국어 문장 임베딩). 의미 검색에 해당한다. 로컬 모델을 확보하지 못하면 미확인으로 남기고, 대신 다른 방식을 썼다면 그렇게 밝힌다.
4. RRF로 2번과 3번의 순위를 결합. 혼합 방식에 해당한다.

**단위.** 모든 방법을 문서 전체 단위와 문단 단위 두 가지로 실행한다. 문단 단위에서 문서 순위는 문단 점수의 최대값으로 집계한다. 단위 차이가 결과를 바꾸면 '방법보다 단위가 원인'이라는 판단으로 이어질 수 있다.

**참고 원문 후보(아직 열람하지 않음, 접근성 미확인).**
- Robertson & Zaragoza, BM25/확률적 관련성 프레임워크. 어휘 검색이 무엇을 가정하는지 확인한다.
- Karpukhin 외 2020 DPR, Thakur 외 2021 BEIR. 밀집 검색의 장점과 도메인 이동 시 BM25 대비 결과를 확인한다.
- Cormack, Clarke & Büttcher 2009 RRF. 결합 방식의 원리와 실험 조건을 확인한다.
- 시간이 남으면 문단·청크 단위 검색이나 답 없는 질문을 다룬 자료.

각 원문은 실제로 읽은 범위(초록, 특정 절, 전문)를 기록한다. 원문 실험의 데이터셋과 언어가 이 자료와 다르다는 한계를 함께 적는다.

## 4. 핵심 질문과 조사 방법
**Q0. 자료와 질문은 어떤 모습인가? (가장 먼저)**
- 확인할 것: manifest, 문서 길이와 문단 수, 실제/합성 구분, 질문 유형.
- 그다음 할 일: 결과를 보기 전에 질문별 근거 문서와 문단, '답 없음', '여러 문서 필요'를 `qrels.json`에 자기 판정으로 기록한다. 판정 기준도 적는다. 이것은 정답표가 아니라 자기 판정이라는 한계를 명시한다.

**Q1. 키워드 검색 개선으로 충분한가?**
- 비교: 1번과 2번, 각각 두 단위.
- 판단: 기준선이 놓친 질문을 토큰화나 단위 변경이 고치면 '키워드 개선으로 상당 부분 해결'이다. 못 고치는 질문은 Q2로 넘긴다.

**Q2. 의미 검색이나 혼합 방식이 도움이 되는가?**
- 비교: 3번과 4번을 2번 대비로 본다.
- 판단: 어휘 불일치(동의어, 다른 표현) 질문에서만 개선되는지, 반대로 정확한 용어를 묻는 질문에서 악화되는지 질문별로 본다.

**Q3. 검색을 바꿔도 남는 문제가 있는가?**
- 모든 방법이 실패한 질문을 직접 읽고 원인을 분류한다: 답 없음, 여러 문서 종합 필요, 질문 모호, 근거가 너무 길어 단위에 묻힘, 합성 자료와 실제 자료의 충돌.
- 판단: 검색 순위에 근거 문단이 있는데도 '답이 안 되는' 경우는 답 생성과 근거 확인 단계의 문제로 분리한다.

**Q4. 원문 근거가 이 결과와 어떻게 맞는가?**
- 원문이 주장하는 조건과 이번 관측을 대조한다. 예상과 다른 결과(예: 의미 검색이 짧은 기술 용어 질문에서 뒤짐)는 해당 문단, 토큰, 점수를 직접 보고 원인을 확인한 뒤 판단을 고친다.

**지표.** 질문 6개뿐이므로 평균 수치보다 질문별 hit@3과 근거 문서의 순위를 표로 보인다. 수치는 기술적 요약일 뿐이며 통계적 우위로 해석하지 않는다.

## 5. 프로그램과 산출물
**run_experiment.py**

## 6. 결과의 종합
질문별 표(방법 × 단위 × 근거 순위 × 실패 원인)에서 다음을 대조한다.
- 키워드 개선(토큰화, 단위)이 고친 것
- 의미 검색과 혼합 방식이 추가로 고친 것과 악화시킨 것
- 어떤 방법으로도 남는 것

이 대조를 원문의 조건과 맞추어 '이 자료에서는 어떤 조건에서 무엇이 도움이 되었다'는 조건부 결론을 낸다. 충돌하거나 근거가 부족한 부분은 미해결로 남긴다. 어떤 추가 관측(더 많은 질문, 다른 임베딩 모델, 답 생성 시험)이 있으면 판단이 바뀔지도 적는다.
