2026-11-01 14:50:36 KST 시작, 15:50:36 종료 상한. 사용자 요청은 앞서 설계한 심층연구 긴문장 상상훈련의 실행이다. [설계](../../../LONG_SENTENCE_DEEP_RESEARCH_DESIGN_2026_11_01.md)를 따른다. 이 문서는 실행 전에 저장한 start.json·입력·기대값·요청을 모은 기록이며 파일 자체는 초기 실행 중 정리했다.

## 과제와 입력

개인 문서에서 필요한 답·근거를 못 찾는 문제를 연구하고, 관련 원문을 조사한 뒤 같은 문서·질문으로 기준 검색과 대안을 실제 비교한다. 실패의 원인과 조건부 권고, 미확인 사항, 재실행 프로그램을 남긴다. 문서 두 개가 갱신되는 후속에서 판본·조건 변화와 답 없음의 보존을 확인한다.

입력은 실제 가이드 8개와 합성 문서 4개, 개발 질문 6개와 보류 질문 6개다. 원문 판본과 내용 SHA는 manifest.json에 고정했다. 개발 질문은 실행자 공개, 보류 질문은 방법 고정 뒤에만 사용한다. 정답 문서 목록은 운영자 영역에 두었다. 문서 수집과 방법 조사에서 외부 원문 읽기는 허용하되 문서 업로드·가입·구매·발송·공개·다른 에이전트 위임·제품 수리·등록·시딩은 금지했다.

실자료는 research_project, research_questions, ibl_composition, result_quality, script, disk_search, capability_change, workflow 가이드의 사본이다. 합성 규정은 실제 제품의 계약이 아니다. 가상의 푸른숲 랩의 현행 보관기간은 기본 30일, 후속 14일이다. 과거판 90일은 현재 효력이 없다. 자료열람 모드와 온라인 조사 모드의 외부 획득 허용은 조건이 다르며, 개인 문서 업로드는 둘 모두 허용하지 않는다. 월 비용과 임베딩 모델 이름은 어느 판본에도 없다.

## 완료 조건

- 사전 계획의 저장과 실행 전달, 실제 첫 조사 순서를 확인한다. 훈련자 계획과 시스템 의식 계획은 구분한다.
- 같은 자료와 질문, 같은 상위 문서 수(k=3)로 기준과 대안을 실제 실행한다. 방법 설정·단위·미구현 방법을 밝힌다.
- 자료 위치뿐 아니라 실제 답을 지지하는 구간, 판본·적용 조건·답 없음과 불확실성을 확인한다.
- 관련 원문을 실제로 읽고 열람 범위·해석·이번 실험의 적용 한계를 남긴다.
- 실행 프로그램·입력·설정·결과를 보존하고, 실패 질문을 숨기지 않는다.
- 후속 입력의 변경과 영향받지 않은 결과를 구분한다. 보관기간 14일, 계속 미확인인 비용·모델명을 바르게 처리한다.
- 검사 통과·실행 종료·과제 달성을 각각 판정한다. 종료·문서 작성만으로 연구 성공을 선언하지 않는다.

정답 문서의 포함률은 검색의 대리 지표다. 여러 문서가 같은 답을 지지하면 전부 찾지 못했다는 이유만으로 답변 실패로 판정하지 않는다. 최종 의미 판정은 실제 인용 구간과 답을 대조한다. 보류 질문을 이미 알고 있는 훈련자의 결과는 새 질문 독립 수행 증거가 아니며, AI의 설정 고정 후 실행만 해당한다.

## 실행 경로와 독립성

훈련자는 공개된 계약·가이드를 이용해 IBL로 읽기·검색 부품·모델 답변·저장·재독을 조합한다. 검색 부품만 Python으로 구현한다. 사전에 시스템 내부 구현과 기대값을 알고 있어 이 영향은 분리할 수 없다.

시스템 AI는 POST /system-ai/chat, origin=training, background=true. 실제 의식의 연구계획 경로를 시험하려고 #think를 명시했다. 자동 연구 필요성 판단은 미검증이다. 기존 rehearsal 대화의 최근 이력이 계승될 수 있으며 새 대화 격리는 지원된다고 가정하지 않는다. 이번 과제의 훈련자·정답·보류 자료는 읽지 않도록 지정하고 실제 도구 조회를 확인한다. 같은 요청/해법의 사전 노출과 이전의 무관한 대화 이력은 구별한다.

전체 산출물은 정본의 outputs/long_sentence_imagination/2026-11-01_106회차 아래에 있다. trainer, ai/base, ai/variant, private와 runs를 분리한다. 운영 원장에는 훈련 출처만 사용한다. 시스템 소유의 계획 저장은 기본 경로를 허용한다. 제품 코드·프롬프트·운영 가이드는 수정하지 않는다.
