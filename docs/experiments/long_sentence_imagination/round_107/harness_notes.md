# 훈련 하네스의 작성 마찰

초기 run_cases_v0.py는 모든 사례의 project_path를 새 사례 폴더로 지정했다. 기본 사례는 독립 공간이라 타당하지만, C09·C10의 C05 계획 경로는 이 새 공간 밖이다. research_planning.read_current는 같은 작업공간 계획만 읽으므로 read_error가 발생한다. 실제 계획의 내용은 대화 이력으로 함께 주었지만 파일 계승 조건은 충족하지 못한다.

C05 완료 뒤 코드를 점검하며 이 차이를 발견했다. 이미 실행 중인 배치 코드를 변경하거나 중단하지 않고 최초 기록을 보존한다. 수정 runner는 후속의 project_path만 C05와 같게 하고, 별도 _recheck 결과 폴더에 같은 요청·같은 원계획으로 다시 실행한다. C09와 C10은 각각 C05에서 분기하며 서로의 결과나 운영자 판정을 받지 않는다. 이 수정은 제품의 루트 경로 제한을 우회하거나 완화하지 않으며, 시험 입력을 실제 동일 연구 작업공간에 맞춘다.

최초 후속의 파일 계승 오류는 제품 품질 결함으로 세지 않는다. 재시도도 공개하고 원래 결과를 덮어쓰지 않는다. 원인은 하네스 작업공간 설정이며 모델 프롬프트·가이드·판정 조건·모델 등급은 변경하지 않는다.
