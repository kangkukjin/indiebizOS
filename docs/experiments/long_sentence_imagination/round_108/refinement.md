# 첫 수정의 잔여에 따른 두 번째 보완

첫 수정은 최종 필드 일관성·제약 보존·맥락 복원 후 의식 소유권을 명시했다. R01_final에서는 본문이 감소 시점을 미확인으로 두지만 expert_choice가 개점보다 먼저 시작된 감소를 전제했다. N01_final은 균등한 주별 접수라는 가정하의 계산을 제대로 분리했으나 task_framing에서 실제 도입 전 감소의 가능성이 높다고까지 적었다. 가정의 개연성은 입력에 없다.

N02_final은 로컬/클라우드와 원본/비식별문을 구별했지만, Q2에서 이번 달 시험할 수 없는 후보를 문서 비교로 남기는 경로와 종합 탈락 필터의 '이번 달 결제 필요(비교 단계)'가 모호하게 연결됐다. 실제 후보가 제외됐다고 주장하지 않으며 기간 제한의 단계 경계가 불명확한 문제로 판정한다.

두 번째 보완은 같은 원인에 대한 마지막 수정 주기다. 의식의 사실/가설 원칙에 집계·요약으로 세부 분포·변화 시점을 확정하지 않고 같은 입력과 양립하는 다른 경우를 확인하도록 한다. 가정하의 계산을 실제 결론의 개연성으로 승격하지 않는다. 가이드는 기간 제한으로 미룰 시험과 이후 도입 후보 탈락을 구별한다. 주제명·정답 수치·특정 후보를 지침에 넣지 않는다.

refinement_cases.json에 R01·N01·N02·N03·N04와 새 N07(전체 만족도 평균→연령별 향상)을 고정하고 별도 _refined 결과를 남긴다. 첫 시도나 기준을 덮어쓰지 않는다. 전후 각 1회 결과는 관측 비교이며 확률적 개선율이나 비용 절감을 입증하지 않는다. 새 모델 단계는 추가하지 않고 기존 규정·계획 작성 호출을 쓴다.

N03_final의 익명화 예시는 병원 간호사를 교대 근무가 있는 직종으로 바꿔 원문에 없는 근무형태를 추가했다. 의미 보존 규칙에도 잔여가 있으므로 같은 두 번째 보완에서 익명화의 속성 추가도 금지하고 N03을 다시 확인한다. 이는 익명화 예시 한 곳의 결함이며 실제 면담 변경은 없다.

N04도 같은 원래 N03_final에서 다시 분기한다. 새로 잘된 초안으로 바꿔 주지 않고, 이전 AI 계획의 잘못된 익명화 예시를 새 지시 아래에서 그대로 계승하는지 검사한다.
