# 구술기록 200건 정리안 A·B 선택을 위한 연구계획 (판본 1)

## 0. 출처와 이 문서의 지위

- 근거 원문: fixture:prior-user-turn-2. 합성 시험용 이전 사용자 발화이며, 실제 사용자의 과거 자료가 아니다.
  > 지역 도서관에서 구술기록 200건을 정리하는 두 제안 A와 B를 비교하고 싶어. A는 직원이 기존 폴더와 수동 태그를 정비하는 방식이고, B는 로컬 전문 검색 인덱스를 만드는 방식이야. 목적은 직원 두 명이 주어진 인물·사건에 관한 원문 구절을 정확히 찾아 출처로 돌아가는 시간을 줄이는 거야. 원본 파일과 기존 파일명은 보존하고 시험은 사본에서만 해. 기록 원문을 외부 서버에 보내지 마. 이번 주에는 설치·적용하지 말고 공개 설명과 허용된 샘플로 조사 계획을 세워. 매월 운영비는 1만 원까지 가능해. 예전 보고서에 B가 빠르다는 말이 있지만 실측은 없으니 이미 검증된 결과로 삼지 마.
- 이번 요청: 위 두 제안 중 무엇을 택할지 깊이 연구할 계획을 쓴다. 이 문서는 계획이다. 조사·설치·시험은 아직 하지 않았다.
- 현재 확인된 사실은 위 원문뿐이다. 이 문서의 성능·비용·효과 관련 내용은 모두 미확인이거나, 앞으로 정할 제안값이다.

## 1. 목적과 판단 질문

- 목적(원문): 직원 두 명이 주어진 인물·사건에 관한 원문 구절을 정확히 찾아 출처로 돌아가는 시간을 줄인다.
- 성공의 구성: 목적은 세 요소가 함께 충족되어야 달성된다.
  - 정확한 구절을 찾는다.
  - 원본 출처(파일과 그 안의 위치)로 돌아간다.
  - 이 과정의 시간이 줄어든다.
  - 빠르더라도 틀린 구절을 내거나 출처로 돌아가지 못하면 목적 미달이다.
- 판단 질문: 절대 조건을 모두 지키면서 위 목적을 더 잘 달성하는 안은 A인가 B인가.
- 양자택일 유지: 사용자의 질문은 양자택일이다. 혼합안은 두 안이 모두 조건을 통과하고 근거가 가리킬 때만 부가 의견으로 적는다. 혼합안이 선택을 대체하지 않는다.

## 2. 절대 조건과 탈락 심사

조건은 원문 그대로 쓰며 완화하거나 점수화하지 않는다. 판정은 통과·위반·미확인 셋이다.

- 위반: 그 구현 방식은 탈락한다. 같은 제안의 다른 구현으로 조건을 지킬 수 있으면 그 변형만 다시 심사한다. 예를 들어 태그를 파일명 대신 목록표에 두는 방식이다.
- 미확인: 탈락 근거가 아니다. 확인 질문으로 남기고 우선 확인한다.

### C1. 원본 파일과 기존 파일명은 보존

- A 확인 사항: 폴더 정비가 원본의 이동·이름 변경을 포함하는가? 태그를 파일명이 아닌 목록표·사이드카에 두는가? 원본 내부 메타데이터에 쓰는 방식은 원본 변경인지 확인한다.
- B 확인 사항: 인덱싱이 원본을 읽기만 하는가? 원본 폴더 안에 파일을 만드는가?

### C2. 시험은 사본에서만

- A 확인 사항: 시범 정비를 사본 경로에서만 하는가?
- B 확인 사항: 인덱스 구축·시험을 사본 경로에서만 하는가?

### C3. 기록 원문을 외부 서버에 보내지 마

- A 확인 사항: 태그·목록 도구가 원문을 클라우드나 공유 서비스에 올리는가?
- B 확인 사항: 도구가 완전 오프라인으로 동작하는가? 텔레메트리, 클라우드 동기화, 외부 전사·임베딩 API를 쓰는가? 전사가 필요하면 로컬 전사만 허용된다.

### C4. 이번 주에는 설치·적용하지 말고 공개 설명과 허용된 샘플로 조사 계획

- A·B 공통: 이번 주에는 공개 문서 열람, 허용 샘플 검토, 계획 보완만 한다. 시범은 사용자 승인 후 다음 주 이후로 둔다.

### C5. 매월 운영비는 1만 원까지

- A 확인 사항: 도구 비용이 드는가? 인건비가 운영비에 포함되는지는 미확인이다.
- B 확인 사항: 라이선스·호스팅 등 월 경상비가 있는가? 초기 비용을 따로 보는지는 미확인이다.

### C6. 예전 보고서의 B 속도 주장은 검증된 결과로 삼지 마

- 판단 규칙에 적용되는 조건이다. 예전 보고서는 근거표에 실측 없음·가설로만 적는다.
- 시범 결과와 일치하더라도 독립 근거로 세지 않는다.

## 3. 접근과 선택 이유

- 문제 유형: 목적과 제약에 맞춰 무엇을 도입할지 고르는 문제다.
- 진행 순서: 조건 심사, 같은 과제로 하는 비교 시험, 운영 부담 순으로 진행한다.
- 효과 측정 방법: 두 가지를 결합한다.
  - 정보검색 평가의 테스트 컬렉션 방식: 정답이 미리 확정된 질의 세트로 재현율과 오답률을 잰다.
  - 실제 과업 시간 측정: 직원이 질의를 받아 출처를 확인하기까지의 시간을 잰다.
- 적용 한계:
  - 직원이 2명이고 질의 수가 적어 통계적 일반화는 할 수 없다. 결과는 기술통계와 조건부 결론으로 낸다.
  - 공개 문서는 기능이 있다는 것만 확인해 준다. 이 자료에서의 효과는 시범 전까지 미확인이다.

## 4. 핵심 질문과 조사 방법

### Q1. 기록의 형태는 무엇인가 (모든 판단의 전제)

- 증거:
  - 200건이 음성·영상·전사 텍스트·스캔 중 무엇인가
  - 전사본의 비율
  - 구절 위치를 어떻게 표기하는가(쪽, 타임코드 등)
- 확보 방법: 이번 주에 허용 샘플의 형식을 확인하고, 기관 목록이나 사용자에게 묻는다.
- 판단 규칙:
  - 전사 텍스트가 대부분이면 B를 바로 적용할 수 있다.
  - 음성 위주이면 B는 로컬 전사가 먼저 필요하다. 이 공수와 비용을 Q4에 반영한다.
  - 음성 위주이면 A의 태그 단위도 파일 단위로 제한될 수 있다.
- 부족할 때: 샘플에 접근할 수 없으면 형식을 사용자에게 묻는다. 그동안 Q2~Q4는 전사본 있음·없음 두 시나리오로 병행한다.

### Q2. 각 안이 절대 조건을 지킬 수 있는가 (탈락 심사)

- 증거:
  - 2절의 조건별 확인 사항
  - A의 정비 절차 설명
  - B 후보 도구의 공개 문서(오프라인 동작, 데이터 저장 위치, 외부 통신, 한국어 처리, 비용)
- 확보 방법:
  - 원문에 B의 도구명이 없다. 먼저 사용자가 염두에 둔 도구가 있는지 묻는다.
  - 없으면 이번 주에 공개 문서로 로컬·오프라인 후보를 소수 정리한다.
  - 한국어 조사 결합형(예: 홍길동은)을 검색할 수 있는지, 형태소 분석이나 n-gram 지원이 문서에 있는지 확인한다.
- 판단 규칙:
  - 공개 문서에 명시되어 있으면 잠정 통과로 보고 시범에서 재확인한다.
  - 명시가 없으면 미확인이다.
  - 반대로 명시되어 있으면 위반이다.
- 부족할 때: 원 제공자의 문서가 없고 제3자 소개만 있으면 판정을 유보하고 미확인으로 남긴다.

### Q3. 목적 지표에서 어느 안이 나은가 (승인 후 사본 시범)

- 범위: 200건 전체를 정비하는 것은 공수가 크다. 그래서 허용 샘플 하위집합의 사본에서 A와 B를 각각 구축한다. 하위집합 결과를 200건으로 확장한 값은 추정이며 측정이 아니다.
- 질의 세트:
  - 직원이 실제로 받는 형태의 인물·사건 질의로 만든다.
  - 정답(구절과 원본 위치)은 시험 전에 확정하고, 판정자와 확정 방법을 기록한다.
  - 난이도가 비슷한 두 세트 S1과 S2를 만든다.
- 측정 항목:
  - 정답 구절 재현율
  - 오답 제시 수
  - 출처 복귀 성공(원본 파일과 위치 일치)
  - 과업 시간: 질의를 받은 때부터 출처를 확인할 때까지의 실제 작업 시간. 대기는 제외한다.
  - 제한 시간을 넘긴 질의는 실패로 기록한다. 시간 처리 규칙은 시범 전에 정한다.
- 교차 배정:
  - 직원1: A-S1, 그다음 B-S2
  - 직원2: B-S1, 그다음 A-S2
  - 같은 질의를 두 방식에서 반복하지 않는다.
- 기준선: 가능하면 현재 상태(정비 전 폴더)의 시간도 잰다. 기준선이 없으면 현재 대비 얼마나 줄었는지는 미확인으로 남긴다.
- 판단 규칙:
  - 정확성(정답 구절과 출처 복귀 성공)이 명확히 낮은 안은 시간이 빨라도 우선하지 않는다.
  - 정확성이 대등하면 과업 시간으로 가른다.
  - 명확한 차이의 기준은 시범 전에 사용자와 정하는 제안값이다.
  - 차이가 작으면 2인 표본에서는 구분 불가로 보고한다.
- 부족할 때: 시범을 승인받지 못했거나 샘플이 부족하면, 문서상 사실과 성능 예상을 구분해 조건부 결론을 낸다. 측정을 하지 않았다는 점을 명시한다.

### Q4. 도입 공수와 월 비용은 얼마인가

- 증거:
  - A: 시범에서 잰 건당 태깅 시간
  - B: 설치·인덱싱·필요 시 전사에 든 시간
  - 공개 가격표
- 확보 방법: 공개 문서는 이번 주에, 시범 기록은 승인 후에 확보한다. 200건 환산은 추정으로 표시한다.
- 판단 규칙:
  - C5를 위반하면 탈락이다.
  - 조건 안의 안끼리는 순 시간 절감으로 비교한다. 순 절감은 검색 1회당 절감 시간 × 검색 빈도에서 유지 공수를 뺀 값이다.
- 부족할 때: 검색 빈도와 인건비 포함 여부를 사용자에게 묻는다. 답이 없으면 빈도 범위별로 계산한다.

### Q5. 신규 기록이 들어올 때 유지 부담은 어떤가

- 증거:
  - A의 신규 태깅 절차와 두 직원 사이의 태그 일관성
  - B의 재인덱싱 절차
  - 담당자가 바뀔 때 특정 사람에게 의존하는 정도
- 확보 방법: 공개 문서를 보고, 시범 중에 신규 건 추가를 한 차례 시험한다.
- 판단 규칙: 유지 공수를 Q4의 순 절감에 반영한다.
- 부족할 때: 문서상 절차만으로 정성적 평가를 하고, 미확인으로 표시한다.

## 5. 종합 규칙

1. 탈락 심사:
   - 위반한 안은 탈락한다.
   - 둘 다 위반이면 선택 불가로 보고하고, 어느 조건 때문인지 밝힌다.
   - 미확인이 남으면 그 확인을 먼저 한다.
2. 목적 지표: 정확성, 출처 복귀, 과업 시간 순으로 본다.
3. 비용·유지: 조건 안에서 순 시간 절감을 비교한다.
4. 민감도: 다음 경우 결론이 뒤집히는지 확인한다.
   - 전사본이 없을 때
   - 한국어 토큰 처리가 약할 때
   - 직원 시간이 부족할 때
   - 검색 빈도가 낮을 때
5. 근거가 충돌하면 대상·조건 차이로 설명되는지 본다. 설명되지 않으면 조건별 결론으로 남긴다.

결론은 넷 중 하나로 낸다: A 권고, B 권고, 조건부 권고, 판단 보류. 각 결론에는 근거와 남은 미확인을 함께 적는다.

## 6. 진행 순서와 멈춤 조건

### 진행 순서

- 단계 0 (이번 주, 설치 없음):
  - 예비 질문에 대한 답을 받는다.
  - 허용 샘플의 형식을 확인한다.
  - 공개 문서로 탈락 심사를 한다.
  - 결과에 따라 계획 판본을 갱신한다.
- 단계 1 (승인 후, 사본·로컬): Q3~Q5 시범을 한다.
- 단계 2: 종합하고 보고한다.

### 멈춤 조건

- 탈락 심사로 한 안만 남고 그 안의 조건이 확인되면, 비교 측정 없이 결론을 낸다. 단, 목적 달성 정도는 미측정으로 표시한다.
- 시범에서 정확성 차이가 명확하면 질의를 더 늘리지 않는다.
- 차이가 불명확하면 질의를 한 차례만 보강한다. 그래도 불명확하면 구분 불가로 보고한다.
- 승인이나 샘플을 얻지 못하면 단계 0 결과로 조건부 보고를 하고 멈춘다.
- 시범 규모와 시간 한도는 사용자와 정한다. 지정된 예산은 월 운영비뿐이다.

3. A의 폴더 정비에 원본 이동이 포함되는가?
4. B로 염두에 둔 도구가 있는가?
5. 월 운영비 1만 원에 인건비나 초기 비용이 포함되는가?
6. 직원의 가용 시간과 검색 요청 빈도는 어느 정도인가?
7. 시범 실시를 승인하는가? 시점은 이번 주 이후로 언제인가?
8. 예전 보고서를 열람할 수 있는가? 가설의 맥락을 확인하는 용도이며, 근거로 쓰지는 않는다.

## 8. 보고 전 대조 절차

- 질문별로 네 가지를 대조한다.
  - 답
  - 근거 위치
  - 실제 열람 범위: 공개 문서의 제목·요약만 봤는지 본문 절을 읽었는지, 샘플을 몇 건 봤는지
  - 남은 불확실성
- 조건 6개의 판정표를 최신 상태로 맞춘다.
- 원문과 근거에 없는 성능·가격·효과 주장이 들어가지 않았는지 확인한다.
- 이 계획이 조사 전에 저장되었는지, 조사 중 바뀐 내용이 판본에 기록되었는지 실행 순서로 확인한다.

## 9. 현재 상태

- 판본 1 작성 완료.
- 수행한 조사는 없다. 확인된 것은 복원 원문뿐이다.
- 다음 행동: 사용자가 진행을 지시하면 7절의 예비 질문을 확인하고 단계 0을 시작한다.
