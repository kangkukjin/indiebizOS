# 108회차 과제와 사전 판정

사용자가 승인한 의식 프롬프트·심층연구 가이드의 보완 후 문제규정·목적·연구계획 품질을 다시 검사한다. 이번 범위도 계획 단계 중심이며 연구 실행·평가는 하지 않는다. 긴 IBL 업무 전체를 만드는 일반 훈련 대신 사용자가 지정한 의식의 계획 작성 능력에 집중한다.

cases.json은 모델 호출 전에 고정했다. 107회차의 C01/C02/C08을 R01/R02/R03으로 재사용하고 새 요청 N01~N06으로 전이를 본다. N04와 N06은 각각 N03에서 독립 분기하며 동일 작업공간의 이전 계획을 읽는다. checks는 모델 입력에 주지 않는다. 판정은 원문 조건·관측/가설 구분·목적/이번 범위·질문에 맞는 방법·근거 충돌·첫 행동/부족 대응·멈춤과 지시 일치다. 문체·목차·길이로 평가하지 않는다.

R03에는 초기 규정 후 사전에 만든 합성 기록 recovered_context.json을 재규정의 evidence로 제공한다. 실제 execute_reframe→Supervisor.reframe→의식 재규정→research_planning 저장을 호출한다. 운영자가 복원 결과와 방아쇠를 제공하므로 실행자의 자동 기억 검색·reframe 선택 시험은 아니다. 실제 재규정 경로가 자료를 보존해 의식의 계획을 반환하는지 확인한다. 허위 성능 주장을 확인 결과로 승격하지 않고 원문·파일명 보존·사본 시험·외부 반출 금지·이번 주 설치 금지·월 1만 원을 보존해야 한다.

모델은 현재 의식 설정을 쓰고 origin=training, 기본 독립 신원·빈 이력이다. 107회차 하네스를 재사용한다. 실제 채팅의 자동 분류·기억 회수·주제 결속은 미검증이다. 유효한 입력·출력·저장·토큰을 보존하고 초기 시도나 실패를 덮어쓰지 않는다. 시작 17:20:58, 상한18:20:58. 제품 수리는 문서 두 개이며 새 모델 호출 단계나 스키마·엔진 분기는 추가하지 않는다.
