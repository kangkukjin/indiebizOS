# 지원센터 평균 처리시간 감소의 원인 검증과 인력 검토 근거 — 연구계획 (초안)

> 상태: 계획만 작성했다. 자료 조사·분석·외부 연락은 수행하지 않았다. 아래 수치 기준은 모두 제안값이며, 관측 사실은 사용자가 보고한 '12분 → 8분'과 '올해 자동 분류 도입'뿐이다.
> 이 계획서는 직원 감축·운영 변경·데이터 접근·외부 연락의 권한을 만들지 않는다. 조사 착수는 사용자의 별도 요청과 자료 접근 허락이 있을 때만 한다.

## 1. 목적과 현재 질문

- **결정 목적:** 인력 감축을 '검토할 근거가 있는지' 판단한다. 감축 여부의 결정은 이 연구의 산출물이 아니다. 연구는 판단 근거와 보류 조건을 제공한다.
- **검증할 사용자 가설(H):** 자동 분류 도입으로 단순 문의와 복잡 문의가 모두 빨라졌고, 그 결과 전체 평균이 12분에서 8분으로 줄었다.
- **핵심 질문:** ① 평균 감소는 어떤 성분으로 이루어졌는가. ② 그 중 자동 분류에 귀속할 수 있는 부분은 얼마인가. ③ 그 변화가 실제 필요한 상담 인력시간과 서비스 수준을 바꾸는가.

## 2. 출발점과 범위

**확인된 것(사용자 보고):** 작년 평균 12분, 올해 평균 8분, 올해 자동 분류를 도입했다. 이 밖의 사항은 모두 미확인이다. 지표 정의, 기간, 대상 채널, 자동 처리 건 포함 여부, 도입 시점이 여기에 해당한다.

| 미확인 항목 | 판단에 미치는 영향 | 첫 확인 질문 |
|---|---|---|
| 유형별 건수·처리시간(두 해) | 구성 변화와 유형 내 변화를 가를 수 없으면 H의 '두 유형 모두'를 판정할 수 없다 | 유형 체계와 건별 원자료가 두 해 모두 남아 있는가 |
| 측정 시작·종료 기준 | AHT(상담+후처리)와 접수~종료 달력시간은 다른 양이다. 정의가 바뀌었으면 12와 8은 직접 비교할 수 없다 | 각 해의 '처리시간' 필드 정의와 변경 이력, 자동 처리·봇 종료 건의 포함 여부 |
| 미해결·재접수 비율 | 시간이 줄어든 것이 조기 종료·재접수 전가라면 총업무량은 줄지 않았을 수 있다 | 미해결 종료 코드, 재접수 판정 기준(동일 고객·동일 사안·N일 내; N은 제안값 7일) |
| 자동 분류 적용률 | 적용률이 낮으면 감소 대부분을 자동 분류로 설명할 수 없다. 적용 건이 처음부터 쉬운 건이었는지도 알아야 한다 | 건별 적용 여부 표시, 도입 날짜·단계, 오분류·재분류 기록 |
| 유형 분류 기준의 변화 | 작년 유형은 사람이, 올해 유형은 분류기가 정했다면 '단순/복잡' 자체가 비교 불가능할 수 있다 | 최종 처리 코드처럼 두 해에 공통인 분류 기준이 있는가 |
| 동시 변화 | 채널(챗봇·FAQ), 인력 구성·숙련, 정책·상품, 계절·이벤트가 바뀌었을 수 있다 | 같은 기간 운영 변경 이력 |

**잠정 가정:** 두 해 모두 건 단위 기록이 존재한다(미확인). 이 가정이 깨지면 계획은 '집계표 기반 제한 분석'으로 축소한다(7절).

## 3. 경쟁 설명과 각 설명이 바꾸는 판단

| 설명 | 이 설명이 맞으면 | 판별 관측 |
|---|---|---|
| A. 구성 변화 | 단순 문의 비중이 늘어 평균만 내려갔다. 효율 개선이 아니다 | 유형별 시간은 유지되고 비중만 이동 |
| B. 측정·분류 기준 변경 | 지표가 바뀐 착시다 | 정의 변경 이력, 동일 정의로 재산출한 차이 |
| C. 유형 내 실제 단축 | H와 부합한다. 다만 원인은 아직 미정이다 | 공통 유형 기준에서 유형별 시간·분포가 감소 |
| D. 자동 분류 외 동시 변화 | 단축은 실재하지만 자동 분류 효과는 아니다 | 도입 시점과 무관한 시점에 변화가 시작되거나, 미적용 건도 동일하게 감소 |
| E. 부담 전가 | 건당 시간은 줄었지만 총업무량·품질은 악화됐다 | 재접수·미해결·이관 증가, 고객 단위 누적시간 유지 또는 증가 |
| F. 자동 분류가 사람 처리분을 대체 | 봇 종료 건이 평균을 끌어내렸다. 사람 상담 건의 시간은 오히려 늘었을 수 있다 | 자동 처리 건 포함 여부, 사람 처리 건만의 AHT |

설명들은 배타적이지 않다. 목표는 각 성분의 크기를 추정하는 것이다.

## 4. 질문별 조사 방법

**Q0. 지표 정렬(선행 조건):** 두 해의 처리시간 정의, 자동 처리 건 포함 범위, 유형 체계를 문서와 필드로 대조한다. 같은 정의로 다시 산출할 수 있으면 이후 분석의 기준 지표로 삼는다. 다시 산출할 수 없으면 12→8 비교는 '비교 불가'로 표시하고, 같은 정의가 유지된 구간만 쓴다.
- 방법 선택 이유: 이후 모든 분해가 이 정렬에 의존한다.

**Q1. 구성 분해:** 공통 유형 기준(예: 최종 처리 코드 또는 표본 재라벨링)으로 다음을 계산한다.
- 전체 평균 변화 = Σ(비중 변화×유형 평균) + Σ(비중×유형 평균 변화)
- 분해 순서의 영향을 피하려고 Kitagawa 대칭 분해를 쓴다.

결과는 A와 C의 크기다. 공통 기준을 만들 수 없으면, 분류기 라벨과 사람 라벨의 일치율을 표본으로 확인하는 단계를 먼저 추가한다.

**Q2. 유형 내 변화의 모양:** 평균뿐 아니라 다음을 함께 본다.
- 중앙값과 75·90분위수, 긴 꼬리 건의 비중
- 단순·복잡 각각의 변화

H의 '두 유형 모두'는 두 유형 각각에서 감소가 확인되어야 지지된다.

**Q3. 품질과 전가(E):** 다음 지표를 두 해 같은 정의로 비교하고, 재접수까지 합친 고객·사안 단위 누적 처리시간을 계산한다.
- 재접수율, 미해결 종료율, 이관·에스컬레이션률, 첫 접촉 해결률, 만족도(있으면)

**Q4. 자동 분류의 기여(C 대 D, F):**
- 적용률과 적용 건의 특성을 먼저 기술한다.
- 적용 건과 미적용 건을 같은 유형·시기 안에서 비교한다. 적용이 쉬운 건에 몰렸을 수 있으므로(선택 편향), 단순 비교만으로 효과를 주장하지 않는다.
- 주 단위 시계열로 도입 시점 전후의 단절을 본다(단절 시계열).
- 팀·채널별로 단계 도입했다면 이중차분을 쓴다.
- 오분류 후 재라우팅 시간도 비용으로 포함한다.
- 비교 설계가 불가능하면 '도입 시기와 부합' 수준까지만 말한다.

**Q5. 동시 변화(D):** 같은 기간의 운영 변경 이력(채널, 인원·신규 비율, 정책, 상품, 계절 이벤트)을 연표로 만들어 Q4의 시계열에 겹쳐 본다. 담당자 문의는 사용자의 승인 후에만 한다.

**Q6. 인력 판단과의 연결:**
- 업무량(시간) = Σ 유형별 건수 × 동일 정의 AHT + 재접수·이관 부담
- 피크 구간별 필요 인원을 Erlang C 또는 시뮬레이션으로 산출한다. 목표 서비스 수준과 이탈·휴무 비율(shrinkage)은 사용자와 정할 제안값이다.
- 평균이 줄어도 피크 수요나 복잡 문의 비중 때문에 필요 인원이 거의 줄지 않을 수 있으므로, 평균이 아니라 피크 기준으로 판단한다.

## 5. 종합 방식

Q0 → Q1 → Q2·Q3 → Q4·Q5 → Q6 순으로 결과를 연결한다. 감소분 4분을 다음 성분으로 나누고, 성분별 근거 강도(직접 측정/추정/미확인)를 함께 표시한다.
- 측정·분류 착시(B, F)
- 구성 효과(A)
- 유형 내 단축 중 자동 분류 귀속분(C)과 그 밖의 변화(D)
- 전가로 상쇄된 부분(E)

서로 다른 정의의 수치는 평균하거나 합치지 않는다. 해소되지 않는 충돌은 조건별 결론으로 남긴다.

## 6. 판정 규칙

- **H 지지:** 동일 정의·공통 유형 기준에서 단순·복잡 각각의 처리시간이 감소한다. 재접수·미해결·품질이 사전에 정한 허용 범위 안에서 악화되지 않는다(비열등 여부를 신뢰구간으로 판정; 허용폭은 제안값으로 사용자와 합의). 비교 설계에서 자동 분류 적용과 감소의 연관이 동시 변화로 설명되지 않는다.
- **H 부분 지지:** 한 유형만 감소하거나, 감소는 실재하지만 자동 분류 귀속이 불확실하다.
- **H 기각:** 감소 대부분이 A·B·F로 설명되거나, E로 상쇄되어 총업무량이 줄지 않았다.
- **판정 보류:** 동일 정의로 다시 산출할 수 없거나, 유형 비교가 불가능하거나, 품질 지표가 없다.
- **인력 검토로 넘길 수 있는 조건:** H 지지 또는 부분 지지에서, 피크 기준 필요 인원 감소가 추정 불확실성을 넘어 일관되게 나타날 때만 '검토 근거 있음'으로 보고한다. 그 밖의 경우는 '근거 부족·보류'로 보고한다. 어떤 경우든 감축 실행 권고를 확정하지 않는다.

## 7. 진행 순서와 멈춤

0. 사용자가 조사 착수와 자료 접근 범위를 승인한다(현재 미승인).
1. 예비 조사: 다음을 확인하고 계획을 보완한다. 이 단계에서는 분석을 하지 않는다.
   - 지표 정의 문서와 필드 목록
   - 건 단위 기록의 존재
   - 적용 여부 표시와 도입 날짜
   - 공통 유형 기준의 가능성
2. Q0 정렬과 Q1 분해.
3. Q2·Q3.
4. Q4·Q5.
5. Q6.
6. 질문별 검수와 보고.

**방향 전환:**
- 건 단위 기록이 없으면 집계표로 할 수 있는 A 분해와 정의 대조까지만 하고 인과 판단은 보류한다.
- 정의가 달라 다시 산출할 수 없으면 12→8 비교 자체를 결론에서 제외한다.

**멈춤:** 각 질문에서 판정 규칙을 적용할 근거가 갖춰지면 그 질문을 닫는다. 접근 불가로 막히면 해당 판정을 보류로 남긴다. 기한·예산은 사용자 지정이 없으므로, 착수 시 Q0·Q1·Q3를 우선순위로 정한다.

## 8. 현재 상태와 산출물

- **확인한 것:** 없음(사용자 보고만 있음).
- **다음 행동:** 사용자의 검토와 착수 여부 결정. 착수하면 1단계 확인 목록을 자료 소유자에게 요청할 항목으로 정리한다. 요청은 승인 후에 한다.
- **갱신 규칙:** 조사 중 근거와 진행은 이 파일에 갱신한다. 중요한 목적·방법 변경은 이유와 함께 기록한다.
- **보고 전 대조:** Q0~Q6마다 다음을 대조하고, 계획이 조사 전에 저장됐는지와 변경 반영 순서를 확인한다.
  - 답(지지/부분/기각/보류)
  - 근거 위치(파일·필드·기간)
  - 실제 열람 범위(전체 원자료/표본/집계표)
  - 남은 불확실성

## 9. 한계

- 관측 자료만으로는 인과를 확정할 수 없다. 비교 설계의 질에 따라 결론 강도가 정해진다.
- 만족도·품질 지표가 없으면 비열등을 판정할 수 없다.
- 인력 산정은 목표 서비스 수준에 대한 합의에 의존한다.
- 이 연구는 상담원의 업무 경험이나 감축의 조직적 영향은 다루지 않는다.
