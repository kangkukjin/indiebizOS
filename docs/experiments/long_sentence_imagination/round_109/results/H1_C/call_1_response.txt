있는 경우\n\n평균 처리시간이 줄어도 필요 인력이 줄지 않는 경우가 있다.\n- 건수가 늘어난 경우\n- 재접수·이관으로 같은 사안에 여러 번 일하게 된 경우\n- 피크 시간대의 서비스 수준이 인력을 결정하는 경우\n- 측정된 처리시간이 상담원 업무의 일부만 덮는 경우\n\n따라서 평균 처리시간을 감축 판단의 성공 기준으로 쓰지 않는다. 처리시간 변화가 업무량과 서비스 수준에 어떻게 연결되는지를 4절의 질문 5로 따로 확인한다. 그 연결을 확인할 증거가 없으면 가능한 결론은 다음 수준에 그친다: 처리시간 지표는 줄었으나 인력 필요량 변화는 미확인.\n\n## 3. 접근과 선택 이유\n\n이 문제는 두 가지 질문의 조합이다.\n- '왜 변했는가'라는 원인 설명 질문\n- '무엇을 결정해도 되는가'라는 판단 질문\n\n그래서 방법을 다음 순서로 고른다. 앞 단계가 성립해야 다음 단계의 비교가 의미를 갖는다.\n1. 보고값의 원래 산식 재현과 같은 정의로 맞추는 재산출\n2. 구성과 유형 내 변화를 나누는 분해\n3. 부담 이동 확인\n4. 원인 설계\n5. 인력 환산\n\n각 방법의 적용 조건과 한계는 해당 질문에 적는다. 문헌 수집으로 원자료 분석을 대신하지 않는다. 인력 산정 방식(Erlang C, 시뮬레이션)과 인과 설계(단절 시계열, 이중차분)는 표준 접근이다. 다만 이번 센터에 맞는지는 자료 구조를 본 뒤 정한다. 자료 구조 확인은 예비 조사 질문으로 둔다.\n\n## 4. 핵심 질문과 조사 방법\n\n### 질문 0. 어떤 자료가 있고, 두 해의 정의는 같은가 (예비 조사)\n\n- **증거:** 다음을 확인한다.\n  - 문의 기록 시스템의 필드\n  - 시각 기록의 종류: 접수, 배정, 상담 시작, 종료, 후처리 종료, 해결\n  - 연도별 처리시간 정의와 보고서 산식, 대상 채널·포함 건·기간 범위\n  - 유형 라벨의 생성 방식: 사람이 매겼는지, 자동 분류가 매겼는지\n  - 자동 분류 적용 여부 플래그와 작동 방식(라벨링만 하는지, 배정·대기열에 영향을 주는지)\n  - 도입 날짜\n  - 미해결 건이 포함되는지\n- **확보:** 사용자 또는 사용자가 허가한 담당자에게서 자료 목록과 정의 문서를 받는다. 이 단계도 사용자의 별도 진행 지시와 접근 허가가 있어야 시작한다.\n- **판단:** 질문 1~5 중 어느 것을 설계대로 수행할 수 있고, 어느 것은 축소하거나 미확인으로 남길지 정한다.\n- **부족할 때:** 건별 기록이 없고 집계표만 있으면 분해와 원인 판단의 범위를 줄인다. 그 사실을 계획서에 반영하고 사용자에게 알린다.\n\n### 질문 1. 보고값은 어떻게 나왔고, 동일한 정의로 다시 재도 처리시간이 줄었는가\n\n- **방법 1단계 — 재현:** 각 연도의 원래 산식과 대상 범위(채널, 포함 건, 기간)로 12분·8분을 다시 계산해 보고값과 일치하는지 확인한다. 두 해의 원래 산식·범위가 같은지도 이 단계에서 대조한다.\n- **방법 2단계 — 공통 정의 재산출:** 두 해를 하나의 정의와 같은 대상 범위로 다시 산출한다.\n  - 실제 작업시간(활동 구간의 합)과 접수~종료 경과시간(대기 포함 달력시간)을 별도 지표로 둔다.\n  - 평균과 함께 중앙값과 분포(상위 꼬리)를 본다.\n  - 미해결 절단을 처리한다: 두 해 모두 접수 후 같은 관찰 기간(예: N일, N은 예비 조사에서 정함) 안의 결과로 비교한다. 기간 말 미해결 건의 비율도 함께 보고한다.\n- **판정:**\n  - 재현이 되지 않으면 보고값의 출처·정의는 미확인으로 남고, 이후 판단은 재산출값을 기준으로 하되 보고값과의 관계는 설명하지 않는다.\n  - 재현된 원래 산식·범위가 두 해에 달랐다면 그 차이가 (d) 또는 (h)의 후보이며, 같은 정의·범위로 맞췄을 때 감소폭이 얼마나 변하는지로 그 기여를 본다.\n  - 미해결 절단을 맞춘 전후의 차이만 (e)의 기여로 본다.\n  - 두 해의 원래 산식·범위가 같았는데 새 지표(작업시간·경과시간·중앙값)에서 감소폭이 다르게 나오면, 이는 연도 간 정의 변경이 아니라 지표가 측정하는 구간의 차이다. 이것만으로 (d)·(e)를 지지하지 않는다. 어느 구간(대기, 상담, 후처리)에서 시간이 줄었는지에 대한 정보로 질문 4·5에 넘긴다.\n  - 차이를 이 성분들로 나눌 수 없으면 해당 부분은 미확인으로 둔다.\n\n### 질문 2. 감소는 구성 변화와 유형 내 변화 중 어디서 왔고, 두 유형 모두 빨라졌는가\n\n- **선행 확인:** 두 해의 유형 라벨이 같은 기준인지 확인한다. 올해 라벨이 자동 분류에서 나왔다면, 두 해에 공통으로 적용할 수 있는 기준(예: 기존 필드 또는 같은 규칙)으로 표본을 재분류해 일치도를 본다. 일치도가 낮으면 유형별 비교는 미확인이다.\n- **방법:** 같은 정의와 같은 유형 기준에서 Kitagawa 방식의 믹스 분해를 한다. 전체 평균의 변화를 세 성분으로 나눈다.\n  - 구성 효과: 비중 변화 × 기준 처리시간\n  - 유형 내 효과: 기준 비중 × 처리시간 변화\n  - 상호작용\n  - 유형별 처리시간 변화에는 불확실성 구간을 함께 낸다.\n- **판정:**\n  - '두 유형 모두 빨라졌다'는 각 유형의 동일 정의 처리시간이 불확실성을 넘어 감소했을 때만 지지된다.\n  - 한 유형이라도 불명확하면 해당 부분은 '미확인'이다.\n  - 어느 유형이든 증가했으면 가설은 기각된다.\n\n### 질문 3. 처리 부담이 다른 곳으로 옮겨갔는가\n\n- **증거:**\n  - 미해결 비율\n  - 재접수율: 같은 고객의 같은 사안이 정해진 기간 안에 다시 들어온 경우. 정의와 기간은 예비 조사에서 정한다.\n  - 이관·에스컬레이션 비율\n  - 오분류에 따른 재배정 건수와 시간\n  - 사안 단위 누적 처리시간(한 사안에 들인 모든 접촉의 합)\n- **판정:** 건당 시간은 줄었지만 사안 단위 누적 시간이나 재작업이 늘었다면, 인력 판단에는 사안 단위 값을 쓴다. 이 자료가 없으면 부담 이동 여부는 미확인으로 남고, 인력 결론은 보류 쪽으로 기운다.\n\n### 질문 4. 자동 분류가 원인인가\n\n- **증거와 방법:**\n  - 실제 적용률(건수 기준, 유형별)을 확인한다.\n  - 도입 날짜를 기준으로 월별 또는 주별 유형별 처리시간에 단절 시계열을 적용한다. 도입 전후 추세의 단절을 보는 것이다.\n  - 단계적 도입이나 미적용 채널이 있으면 이중차분을 쓴다. 다만 자동 분류가 배정·대기열을 통해 미적용 건에도 영향을 줄 수 있다면 미적용 집단이 오염되어 효과를 과소평가할 수 있으므로, 질문 0에서 확인한 작동 방식에 따라 이 설계의 해석 범위를 제한한다.\n  - 적용 건과 미적용 건의 단순 비교는 쓰지 않는다. 자동 분류가 원래 쉬운 문의에 주로 적용됐을 수 있기 때문이다(선택 편향). 같은 유형·시기 안에서 비교하고, 적용 조건을 확인한 뒤에만 쓴다.\n  - 같은 시기의 동시 변화 목록은 사용자 확인으로 작성한다. 추측으로 채우지 않는다.\n- **판정:**\n  - 미적용 건에서도 비슷한 감소가 나타나면 두 해석이 모두 가능하다: 자동 분류 외의 동시 변화(g), 또는 자동 분류가 배정·대기열을 정리해 전체 부하를 줄인 파급 효과. 이 관측만으로 어느 쪽으로도 판정하지 않는다.\n  - 둘을 가르는 증거: 미적용 건의 시간이 대기·배정 단계와 상담 단계 중 어디서 줄었는지, 감소 시점이 자동 분류 도입 시점과 동시 변화 시점 중 어디에 맞는지, 적용률이 늘어날수록 미적용 건의 감소도 커지는지. 이 증거로 가를 수 없으면 원인은 미확인이다.\n  - 도입 시점의 단절이 확인되고 동시 변화로 설명되지 않을 때만, 자동 분류가 기여했다고 조건부로 말한다.\n  - 이런 설계가 불가능하면 결론은 '시기적으로 함께 일어났으나 인과는 미확인'이다.\n\n### 질문 5. 처리시간 변화가 필요 인력에 무엇을 의미하는가\n\n- **방법:**\n  - **업무량(상담원 시간):** 건수 × 실제 작업시간에 재작업과 후처리를 더한다. 두 해를 같은 정의로 계산한다.\n  - **전체 시간 절감률:** 기준 연도의 유형별 시간 비중 × 유형별 절감률로 계산한다. 한 유형의 효과가 미확인이면 전체 절감도 미확인이다. 건수 비율을 시간 비중으로 대신 쓰지 않는다.\n  - **서비스 수준:** 도착·대기 기록이 있을 때만 피크 시간대에 Erlang C 또는 시뮬레이션을 적용한다. 질문 1에서 감소가 대기 구간에서만 났다면, 상담원 작업시간은 줄지 않았을 수 있음을 함께 적는다.\n  - **품질 지표:** 해결률, 재접수율, 고객 평가(측정되는 경우)를 함께 본다.\n  - **업무량 감소와 인원 감소는 다르다.** 근무 편성, 최소 배치, 문의 외 업무 같은 조건은 미확인이며 사용자 확인 대상이다.\n- **판정:** 감축을 권고하지 않는다. 대신 다음과 같은 조건부 시나리오로 정리한다: 업무량과 피크 서비스 수준이 이러하면 필요 상담원 시간은 이 범위다. 품질 지표가 악화되지 않았다는 근거가 없으면 '판단 보류'로 둔다.\n\n## 5. 결과의 종합\n\n대안 경우 (a)~(h)를 행으로, 질문 1~4의 결과를 열로 하는 대조표를 만든다. 각 경우가 지지되는지, 기각되는지, 미확인인지를 근거 위치와 함께 적는다. 여러 경우가 함께 작용하면 성분별 기여를 적고, 나눌 수 없으면 미확인으로 둔다. 종합 결론은 다음 중 하나 또는 그 조합이 된다.\n\n- **A.** 동일 정의에서 유형별 감소, 부담 이동 없음, 업무량 감소, 피크 서비스 수준과 품질 유지가 모두 확인된 경우 → 인력 규모 재검토의 근거 후보가 된다. 결정은 사용자와 경영진이 하며, 이 연구가 운영 변경을 하지는 않는다.\n- **B.** 원래 산식 재현과 성분별 판정으로 구성 변화, 연도 간 측정 정의 변화, 미해결 절단, 대상·기간 범위 차이가 감소의 대부분을 설명한다고 확인된 경우 → 처리 효율 개선의 근거가 아니다.\n- **C.** 부담 이동이 확인된 경우 → 감축 근거가 아니다. 사안 단위 업무량으로 다시 판단한다.\n- **D.** 핵심 자료가 없거나 정의를 맞출 수 없는 경우 → 판단을 보류한다. 무엇이 확보되면 판단이 달라지는지 목록으로 남긴다.\n\n근거가 서로 충돌하면 먼저 정의·기간·대상의 차이로 설명되는지 확인한다. 설명되지 않으면 조건별 결론이나 미해결로 둔다.\n\n## 6. 진행 순서와 멈춤 조건\n\n**현재 단계:** 계획서 작성까지만 한다. 이후 단계는 사용자의 진행 지시와 내부 자료 접근 허가가 있을 때만 시작한다. 외부 연락과 운영 변경은 어느 단계에서도 하지 않는다.\n\n**이후 순서:** 질문 0 → 질문 1 → 질문 2·3(병행 가능) → 질문 4 → 질문 5 → 종합.\n- 질문 0에서 건별 기록이나 정의 문서를 확보할 수 없으면 그 시점에서 멈춘다. 가능한 결론의 범위(D)와 필요한 자료 요청 목록을 보고한다.\n- 각 질문은 판정 규칙을 적용할 근거가
