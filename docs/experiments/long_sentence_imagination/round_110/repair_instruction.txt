이것은 의식의 연구계획 작성 중 다섯 원칙 점검에서 미충족/미확인이 나온 초안의 수정이다.
사용자 원문·목적·조건을 기준으로 점검 지적을 다시 대조한다. 지적도 오류일 수 있으므로 실제로 성립하는 결함과 그에 의존하는 필드만 고친다. 지적을 따르기 위해 새 사실·조건·목적을 만들지 않는다. 유효한 질문·방법·진행을 보존한다. 목적/질문/방법을 바꾸면 연결된 판단 기준·실행 지시·종합/종료 조건도 맞춘다.
입력 candidate와 같은 전체 의식 JSON 구조에 research_plan 최종 Markdown 본문을 넣어 반환한다. 체크표를 계획 본문에 형식적으로 붙여 통과를 주장하지 않는다. 수정본을 코드가 별도로 다섯 원칙에 다시 대조한다. 파일·저장 시각·지문은 하네스가 기록한다. 외부 검색·자료 수집·분석·연락은 하지 않는다. 지금은 계획서 작성만이다.
