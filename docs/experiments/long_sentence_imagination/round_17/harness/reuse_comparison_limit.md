# 재사용 비교의 해석 한계

시스템 AI ep4336은 네 원자료와 기본 조건 계산을 반복했다. 훈련자는 P1 결과 참조를 사용했다. 그러나 독립 요청의 '입력 밖의 다른 훈련 결과·정답·코드는 참고하지 마'는 훈련자 산출물 누출 방지를 의도했지만, 시스템 AI가 자신의 직전 기본 결과까지 제외했을 수 있다. 실제 보고서도 기본 결과 파일을 읽지 않고 재계산했다고 적었다. 그러므로 관측된 재작업 비용은 보고하되 이를 자발적 재사용 실패나 언어 한계로 확정하지 않는다. 다음 비교는 '너 자신의 직전 결과·참조는 사용 가능, 다른 실행자의 trainer/harness/drafts만 참조 금지'로 명시하고 재검증해야 한다. 이번 요청·결과를 사후 변경하거나 최초 비교를 성공으로 세지 않는다.
