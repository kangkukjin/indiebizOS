## 실험 조건과 격리
훈련자 공개 교재·describe만 사용, 내부 구현 미열람. 시스템 AI에는 request 원문+입력/출력 위치만 전달한다. 생성기·기대값·훈련자 코드/산출물은 inputs 바깥 별도 폴더. 같은 계정이라 OS 접근 차단은 아니며 추적에서 누출 여부 검사한다. origin:training은 증류·실사용 문맥 분리이며 파일 접근 차단 아님. 합성 파일 읽기/회차 파일 쓰기만 수행, 외부 발송/예약/운영 변경 없음. 자연어 진입점 openapi에서 POST /system-ai/chat, ChatMessage(message,origin,background) 확인. 주/변형 순차 제출, 같은 리허설 문맥이며 상태 복원·단절 비교 없음.
