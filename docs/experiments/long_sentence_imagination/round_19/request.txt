합성 창고 재고를 주문에 선입선출로 배분해 줘. skus.json은 알려진 품목 전체(재고가 없는 품목도 있음), lots.json은 이미 전량 사용 가능한 입고 묶음(sku,lot,received,qty,unit_cost), orders.csv는 주문(order,sku,seq,qty)이야. 파일 순서는 무작위다. 같은 order의 완전히 동일한 중복 행은 한 번만 처리해. 수량은 양의 정수만 유효하고 빈칸·미정·0·음수·소수는 invalid_qty, 알려지지 않은 품목은 unknown_sku로 제외해(두 조건이 겹치면 invalid_qty 우선). 품목별 주문 순서는 숫자 seq 오름차순, 동률은 order 사전순. 재고는 received 오름차순, 동률은 lot 사전순으로 먼저 온 묶음부터 소비해. 부분 배분을 허용하고 재고가 다 떨어지면 부족량을 남겨. 원가는 배분 수량×해당 묶음 unit_cost다. 실제 주문·예약·발송은 하지 마.
result.json에 summary(raw_orders,unique_orders,duplicate_rows,lots,requested,allocated,shortage,remaining,cost 및 fulfilled_orders,partial_orders,shortage_orders,cancelled_orders,invalid_qty_orders,unknown_sku_orders), orders(order,sku,qty,status,allocated,cost,shortage), allocations(order,sku,lot,qty,cost), lots(sku,lot,remaining), unknown_cancellations를 저장해. qty는 유효한 경우 정수, 아니면 null. 상태는 fulfilled/partial/shortage/invalid_qty/unknown_sku이고 취소 없는 기본의 cancelled_orders는 0, unknown_cancellations는 []다. 제외 주문의 allocated/cost/shortage는 0. requested는 제외하지 않은 주문 수량 합. 배분 행은 양수만 기록. orders는 order 순, allocations는 order/lot 순, lots는 lot 순으로 정렬해. report.md에는 요약 모든 수치·6가지 상태별 주문수·부족량 상위10 주문(부족 내림차순, 동률 order순)·FIFO/제외 규칙과 입력 출처를 기재해. 저장 뒤 재읽고 수량보존·원가·전건 개수 및 보고서와 JSON 일치를 검증해. 스스로 선택한 방법으로 계산하되 다른 실행자의 trainer/harness/drafts·정답은 참조하지 마.
