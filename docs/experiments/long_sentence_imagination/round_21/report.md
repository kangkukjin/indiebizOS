## 발견과 수리

### L21-1 — 빈 본문과 본문 누락의 혼동

구현 결함. 평문 `""`는 성공하지만 `{text:""}`와 `field:"text"` 입력은 본문을 못 찾았다고 실패했다.
명시적 `text:""`/공백은 무시되어 이전 입력으로 넘어갔다. Record 전체 실행에서 빈/공백 문서
두 개가 실패했다. 빈 값은 유효한 원문인데 `.strip()`의 참/거짓으로 존재 여부를 판단한 것이 원인이다.

소유 위치는 `data/packages/installed/tools/data-ops/chunk_ops.py::_chunk_source_text`.
세 진입점에서 문자열 타입으로 존재를 판단해 원문을 그대로 전달한다. 없는 키·비문자열 오류,
items 행의 누락/빈 본문 경고, 봉투 안내문보다 items 우선인 기존 계약은 보존한다.
공개 카탈로그·조합 교재도 빈 본문과 빈 행을 구분했고 용례4건을 재검토했다.
새 어휘나 입력 방식은 추가하지 않았다.

### L21-2 — 줄·문단 길이 확인마다 누적 본문 재결합

반복해서 복사했다. 길이만 누적하고 덩이를 확정할 때 한 번 합치도록 바꾸었다.
