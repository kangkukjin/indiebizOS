# 21회차 — 문자 조각 색인과 경계 보존

시작 2026-10-05T22:45:29.822724+09:00; 상한60분. HEAD 0e85d86f96ac0baf72ac99380a77993f57cc457c

합성 매뉴얼 묶음 documents.json과 queries.json을 사용해 검색용 문자 조각 색인을 만들어줘. 각 문서의 text를 최대512자, 인접 조각 겹침64자로 나누고 마지막 조각은 짧아도 돼. 조각에는 doc_id, index(문서 안 0부터), start(원문 0부터 문자 위치), end(배타 끝), chars, text를 넣어줘. 모든 원문 문자를 보존하고 앞뒤 공백도 없애지 마. 빈 문서는 0조각, 공백만 있는 문서는 내용을 보존한 1조각이다. 각 조각의 text가 원문[start:end]와 정확히 같은지, 인접 조각 사이에 누락이 없고 요청한 겹침이 맞는지 확인해줘. 같은 문서에서 어떤 조각이 원문 끝에 도달하면 종료해 마지막 꼬리만 중복하는 불필요한 조각을 만들지 마. 검색어별로 조각 안에 리터럴 검색어가 포함된 문서 ID를 중복 없이 원래 문서 순서로 내줘. 검색어는 모두64자보다 짧다. 각 문서의 원문 글자수·조각수·조각 글자수 합·중복 글자수와 전체 합계를 보고해줘. index.json에 전체 조각과 문서별 통계를, report.json에 검색 결과·합계·검증 결과를 저장하고 두 파일을 다시 읽어 비교해줘. 네트워크나 발송은 하지 마. 다른 실행자의 trainer/harness/drafts·정답·훈련 보고서는 참조하지 말고, 네가 만든 결과는 재사용해도 된다.

입력: 합성12문서×160문단+빈/공백문서, NFC 문자열. 주 조건512/64, 변형777/64. 기대: 원문 슬라이스·간격·최소 조각수 전건 일치, 마지막 꼬리 중복없음, 각 검색어 첫3개는D00~D11만, 마지막은빈목록. 원천을 바꾸지 않는 크기변형에서는 자기 이전 값/파일 재사용 허용. 정답·초안은 독립 AI에 미제공.

분해: 읽기 → 문서별 문자 분할·원문/경계 확인 → 문서통계·검색 후보 → JSON 저장·재독. 공개 교재·describe만으로 최초 작성, 최초 관측 뒤에만 구현 진단.

주 과제 성공 뒤 경계 길이 변형을 추가: 0,1,63,64,65,447,448,449,511,512,513,895,896,897,959,960,961자. 요청한 512/64와 동일 조건, 최소 조각수는 빈0·512이하1·그외 1+ceil((n-512)/448). 기존 AI 원자료는 수정하지 않는다.

내부 진단 뒤 추가한 도움 받은 표현 변형: 본문 문자열 대신 문서 Record와 field:text를 chunk에 직접 전달. 내용·크기 조건은 동일하므로 결과도 동일해야 한다. 원래 초안과 분리하며 기본 작성 성공으로 세지 않는다.
