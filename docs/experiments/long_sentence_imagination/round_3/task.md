# 긴문장 상상훈련 3회차 — task (실행 전 기록, 2026-09-30 09:21 KST)

## 자연어 요구 원문
"세계 지리 수치 논쟁을 공부할 학습 자료를 만들어 줘. 주제는 에베레스트 높이, 만리장성 길이, 나일강 길이(아마존강과의 최장 논쟁 포함) 세 가지야.
주제마다 한국어·영어 위키백과 두 곳을 읽고, 각 원천에서 수치 주장(값·단위·측정 연도나 기관)을 뽑아 줘.
원천끼리 수치가 다르면 상충으로 표시하고, 정의 차이(예: 명나라 성벽만 vs 전체)인지 진짜 불일치인지 설명해 줘.
모든 수치에는 어느 페이지 몇 번째 문단에서 나왔는지 근거를 달고, 읽지 못한 원천이나 확인 못 한 부분은 따로 적어 줘. 결과는 파일로."

## 선정 이유
원장 2회차 "다음" 후보 세 가지를 한 과제로: ① 웹 원천 조사(실웹, sense:crawl 6건) ② each 안 행별 모델 호출(원천마다 table:ai 로 주장 추출, 병렬)
③ 계산/저장 분리 뒤 reuse 재측정(L2-1 수리 후 실웹 읽기 복원 여부). 새 연결 = 큰 웹 본문(문단 1,000+)을 키워드로 좁혀 모델 입력 한도 안에 넣기,
모델 출력 수치를 코드로 정규화해 원천 간 대조, 두 번째 모델 호출(주제별 해설)과 규칙 판정 합류, 문단 근거 보존.

## 입력 (실웹, 비민감 공개 자료) — inputs.원천 (주제·언어·URL·키워드)
T1 에베레스트: https://ko.wikipedia.org/wiki/에베레스트산 · https://en.wikipedia.org/wiki/Mount_Everest
T2 만리장성: https://ko.wikipedia.org/wiki/만리장성 · https://en.wikipedia.org/wiki/Great_Wall_of_China
T3 나일강: https://ko.wikipedia.org/wiki/나일강 · https://en.wikipedia.org/wiki/Nile
실웹이므로 페이지 내용은 실행 시점 판본(재현성 한계). 수치 기대는 영문판의 알려진 값만 고정하고 한국어판 값은 미리 단정하지 않는다.

## 환경
라이브 POST /ibl/execute, edition 2, project 컨텐츠, origin training, agent LSI3_trainer. 모델 = table:ai 시스템 기본 기어. HEAD 556ee4c9.
작성 조건: 기본(교재 ibl_composition.md·문법 전문 해당 줄·describe·작은 관측 실행 1건(probe_crawl)만). 개발 세션이라 내부 지식 분리 불가.

## 완료 조건과 기대값
1. 6개 원천 모두 읽음(또는 실패를 원천별로 명시). 주제별 원천 수 표기.
2. T1: 8,848.86 m(2020 네팔·중국 공동 측량)가 en 근거와 함께 있음. ko 원천의 값이 다르면 상충 표로, 같으면 일치로 표시.
3. T2: 21,196 km(전체, 2012 조사)와 8,850 km(명나라 성벽) 두 값이 모두 있고 "정의 차이"로 설명됨(진짜 불일치로 오판하지 않음).
4. T3: 나일 약 6,650 km 가 있고 아마존과의 최장 논쟁(측정 기준 차이)이 언급됨.
5. 문서의 모든 수치 행에 원천(언어/URL)·문단 번호(paragraph_index) 근거. 모델이 지어낸 수치 금지 = 수치 문자열이 인용 문단 원문에 실제로 있어야 함(코드로 검사).
6. "확인 못 한 부분" 절: 읽기 실패 원천, 키워드 문단을 상한으로 자른 경우 그 사실(총 적중 수 vs 사용 수).
7. out/study_notes.md 저장 후 재읽기 일치.

## 변형
- 변형 A (견고성 — 같은 프로그램, 다른 입력): T2 ko URL 을 존재하지 않는 문서(…/wiki/만리장성_LSI3_없는문서)로. 기대: 실행은 계속, 해당 원천 "읽지 못함"+이유,
  T2 는 en 1곳만으로 작성(원천 수 1/2 표기), 지어낸 ko 수치 없음, source_complete false. 나머지 주제 결과는 원래와 같은 성격.
- 변형 B (변경 용이성 — 요구 변경): "수치마다 영미 단위 환산(m→ft ×3.28084, km→mi ×0.621371, 코드 계산)과 주제별 확인 퀴즈 2문항(정답=출처 수치+근거)을 추가".
  원래 성공 실행을 reuse 로 보내 크롤 6건 복원 여부, 추출 모델 호출 재실행 여부(현 계약상 재실행)를 관측.
