# 긴문장 35회차 — 국제 접수 기록의 마감·시간순 대사

여러 시간대가 섞인 국제 행사 접수 기록을 감사해줘. events.json의 모든 행은 id, desk, at(시간대가 명시된 ISO 8601 시각), seats를 갖는다. 마감은 policy.json의 cutoff이며 같은 순간도 접수에 포함한다. 표기의 사전순이나 각 지역의 벽시계가 아니라 실제 순간으로 비교해. 접수된 행을 실제 시각 오름차순, 동률이면 id 오름차순으로 정렬해 accepted에 원문 그대로 보존하고, 나머지는 rejected에 같은 기준으로 정렬해줘. 접수된 행을 창구별로 건수와 seats 합계로 집계하고 desk 순으로 정렬해 summary에 담아줘. result.json은 {accepted:[],rejected:[],summary:[{desk,count,seats}]} 형식으로 저장하고 report.md에는 마감 원문·접수/마감후 건수·접수 좌석 합계·창구별 전건 표를 넣어줘. 두 파일 저장 뒤 재독해 확인해.

합성 1200행, 8창구. 기본 마감 2026-10-08T00:00:00Z. 변형은 같은 입력의 역순 및 마감 1시간 연장. 독립 Python datetime UTC oracle로 모든 행·순서·원문·집계·보고서 셀을 대조한다. 입력 불변도 확인한다. 수리후 새 변형은 UTC 자정 양쪽 1마이크로초 및 +14:00/-12:00 표기·동일순간 동률·빈 입력.

분해: 읽기(파일→값), 판정(행·마감→두 목록), 집계(접수→창구 합계), 전달(두 파일→재독). 계산은 IBL로 작성한다. 공개 조합 교재·문법·명세·describe만 참고, 최초 초안 전에 내부 구현 미열람. 회차 훈련 상한60분; 이후 수리 별도. 규모 및 반복 업무이므로 독립 시스템 AI 비교 포함. 외부발송·공개 없음. 훈련자 토큰 미측정.

기본·원변형 달성 후 내부 진단으로 추가한 boundary 변형(도움 받은 탐침): 유효한 0001년 +14:00 두 행과 9999년 -12:00 두 행. 기대 접수 MIN1/MIN2, 거절 MAX1/MAX2, 좌석3. UTC 변환으로 Python 표현범위를 넘더라도 비교·정렬과 원문 보존이 가능해야 한다. 기본 작성 성공의 근거와 구분한다.
