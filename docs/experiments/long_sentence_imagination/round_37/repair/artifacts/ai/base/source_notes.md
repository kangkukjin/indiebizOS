## 2. 읽지 못했거나 실패한 자료

- HBS 공식 PDF(Dell'Acqua): `https://www.hbs.edu/ris/Publication%20Files/24-013_...pdf`. 'Human Verification' 봇 확인 페이지로 차단됐다.
- kalre.com의 Dell'Acqua 사본: HTTP 404.
- SSRN 4573321 초록 페이지, HBS 교수 페이지: 크롤 실패(도구 오류).
- Science 게재판(Noy·Zhang, doi 10.1126/science.adh2586): 크롤 실패. 검색 요약에 나온 '40% 시간 감소·18% 품질 향상' 같은 수치는 본문으로 확인하지 못했으므로 보고서에 쓰지 않았다.

## 3. 원문에서 추출하지 못해 비워 둔 수치

- METR(S4)의 19%에 대한 신뢰구간: 부록 D에 있다고 적혀 있지만 이번 발췌에서는 수치를 얻지 못했다.
- DORA 2024의 해당 연도 응답자 수: 보고서의 '39,000명 이상'은 10년 누적치라 쓰지 않았다.
- Cursor 연구(S5)의 커밋 수 효과 크기와 결과 표 전체: 읽지 않았다.
- Cui(S2)의 재직기간·직급별 수치: 그림 3의 축 라벨만 읽혀 숫자와 막대의 대응을 확정하지 못했다. 보고서에는 본문 서술('단기 재직·주니어에서 유의, 장기·시니어 유의하지 않음')만 썼다.

## 4. 후보였으나 쓰지 않은 자료

- Uplevel의 'Copilot 버그 41% 증가' 주장: 검색 결과가 2차 블로그 위주였다. 원 보고서의 방법을 확인하지 못해 연구 수에 넣지 않았다.
- GitClear 등 코드 품질 관련 업계 보고서: 원문을 확인하지 않아 제외했다.
- 검색 결과의 2차 요약(storytell.ai, mezmo, tsukumo 등 블로그): 근거로 쓰지 않았다.

## 5. 원문에서 발견한 주의점

- Google RCT(S3) 본문은 로그 평균값을 'AI 4.6 vs 무AI 4.3'으로 적었다. 이는 원평균(96분 vs 114분) 방향과 맞지 않아 표기 오류로 보인다. 결론에는 원평균과 회귀계수만 썼다.
- S2 Microsoft 실험에서 처리군과 통제군의 주니어 비율에 차이가 있다(0.61 vs 0.55, p=0.03, 균형표).

## 6. 지킨 제약

- 외부 발송·공개는 하지 않았다. 세 파일 모두 로컬에만 저장했다.
- 실제 회사 정보는 넣지 않았다. 다른 실행자의 trainer·harness·drafts는 참조하지 않았다.
