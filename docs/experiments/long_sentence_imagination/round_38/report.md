## 발견과 수리

### L38-1 — 브라우저 경로의 본문 선택 불일치·코드 손실·중복 호출

Playwright/Chrome은 DOM으로 main/article 선택 정보를 만들면서 본문은 별도 body 텍스트로 읽었다. 선택 범위와 실제 입력이 달랐고, 줄마다 strip하고 빈 줄을 접어 코드 들여쓰기를 손상했다. 이미 DOM을 받았는데 텍스트를 다시 읽는 브라우저 호출도 있었다.

수리: 렌더된 DOM도 정적 경로의 공통 본문 파서를 사용한다. DOM 실패 때만 표시 텍스트로 대체하고 `rendered_body_fallback`으로 범위를 밝힌다. 코드 들여쓰기·빈 줄을 보존한다. 일반적인 탐색 메뉴·검색 오버레이의 정확한 class/id만 공통 잡음 집합에 더했다. 제품·도메인·보고서 정답을 코드에 넣지 않았다.

합성 페이지는 본문·제목·그림 설명·코드·복수 프레임을 보존하면서 메뉴/푸터를 제거했다. Chrome 정상 수집 호출은 대역에서6→5, Playwright는 정상 DOM을 얻은 경우 inner_text 호출0. 실제 DuckDB 두 문서 입력은7154→5706자(약20.2% 감소), SQL 들여쓰기도 보존했다. 모든 페이지의 잡음 제거 또는 전체 토큰/시간20% 절감을 뜻하지 않는다. 일부 일반 div 푸터는 남는다. 단순히 DOM 파서로 바꾸기만 하면 숨은 메뉴가 더 많아지는 중간 관측도 [증거](evidence/browser_scope_mismatch.json)에 보존했다.

### L38-2 — 프레임 누락 은폐와 캐시 오염

Playwright는 frame DOM·text 둘 다 실패하면 조용히 건너뛰었다. Chrome은 iframe 미수집을 내부 구조 오류로만 남겨 content 응답에서 숨겼다. 성공 캐시가 불완전한 본문을 완전한 것처럼 재사용할 수 있었다. 추가 대역에서 더 긴 정적 본문을 최종 선택할 때 뒤에서 확인한 프레임 실패가 다시 소실되는 경로도 재현했다.

수리: 누락은 source_complete:false·errors로 보존하고 IBL 경계에서는 읽을 수 있는 partial을 포함한 PARTIAL_SOURCE가 된다. 최종 본문 선택이 이전 실패를 지우지 않는다. 불완전한 결과는 불변 사본으로 남기되 성공 캐시에는 넣거나 꺼내 쓰지 않는다. 캐시 판본v8로 이전 판정 캐시를 분리했다. links 요청도 content 캐시를 오염시키지 않게 시험했다.

원래 collect_v0 전체 프로그램을 실제 Runtime에 연결해 원천만 대역으로 교체했다.4입력/3고유 URL 중1부분실패는 failed와 partial 근거를 보존하고 나머지2건을 저장했다. 빈 입력은0호출·빈 인덱스다. 새 변형은 원래 프로그램을 수정하지 않았다.

### L38-3 — 조건 변경·검증 절차의 의미 공백

기존 결론을 전달하지 않고 근거만 넘겨 변형 보고가 자기 이전 결정을 비교하지 못했다. 복원 검증도 행수/키만 비교하거나 실제 백업과 다른 시점의 원본을 비교했다. AI는 덤프 형식과 복원 도구를 혼용했고 파일 완료표시를 트랜잭션 일관성 대신 제안했다.

수리: report_v2가 이전 research.md와 근거표를 함께 전달한다. 조사 가이드에 기존 결정 전달, 근거에 없는 숫자 금지, 앞 단계 출력/다음 단계 입력 형식 대조, 검증 대상의 전체 값·같은 스냅샷, 완료표시의 한계를 추가했다. 최종 재실행은 이전 결론 비교·형식 짝·동일 스냅샷 비교를 실제로 포함한다. NAS 변형은 웹 수집·재추출0, repair/base 20파일의 SHA-256·mtime 불변이다.

그러나 지침은 의미 정확성의 강제 장치가 아니다. 재생성 결과에도 archive_timeout의 보장 범위 과장, SQLite의 과거 버전 조건을 모순으로 읽기, SQLite 파일+WAL 보존만으로 백업 절차를 대체하는 오해가 남았다. 원문 조건을 검수해 별도 파일에 기본6개·변형5개 정정을 적용했다(추가 모델0). 자동 생성본을 덮어쓰지 않았다. 이 갭은 **관측 사례의 입력·교재·산출물 수리**, 일반적인 무검수 정확성은 미해결이다. 새 의미검수기를 만들거나 해결했다고 주장하지 않는다.

이는 진화 목적의 원문 보존·실패 전파·부분 재사용·완료 판단에 해당한다. 일반 능력 수리계획의 R3/R6 근거 전달과 R4 재사용에 연결되지만 철회된 카탈로그 축소 우선순위를 재도입하지 않는다.
