같은 팀의 조건이 바뀌었어. 분석가들은 이제 서로 다른 컴퓨터에서 일하고, 누군가는 NAS/NFS에 둔 하나의 DB 파일을 각 컴퓨터에서 직접 열면 서버 운영을 없앨 수 있다고 제안했어. 수집 프로세스는 계속 쓰고 분석가들은 동시에 읽어야 해. 기존 근거를 재사용해 이 제안과 대안을 검토하고 variant/decision.md로 저장·재독해. 파일시스템 공유와 DB 서버 접속, 단일 호스트와 다중 호스트를 구분하고 기존 권고에서 바뀐 부분을 명시해. 기존 산출물은 보존해. 꼭 필요한 근거가 비어 있을 때만 그 부분을 추가 조사하고 이유를 남겨. 자신의 직전 결과·중간 참조는 재사용해도 되고 다른 실행자의 trainer/harness/drafts·정답은 참조하지 마. 실제 시스템 변경·외부 발송·공개는 하지 마.
