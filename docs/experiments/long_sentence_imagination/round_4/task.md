③ 모델 원출력 보존(model_output_ref). 새 연결 = 검색 결과에서 공식 원천 고르기(URL 규칙), 3개 프로그램(수집→추출→렌더) $ref 연결,
PEP 번호로 버전 간 결합(join), 렌더만 바꾸는 요구 변경에서 모델 0회 재실행.
