# 인터페이스 A/B 사용자 실험 — 연구 보고서

## 초록·한계(산문)
본 연구는 조건 A와 B를 세 과제(T1–T3)의 완료시간과 만족도로 비교하였다. T1에서는 B의 완료시간이 A보다 짧다는 가설이 지지되었으나(t(56) = −10.1752, Cohen's d = −2.6272, n_a = 30, n_b = 30), T2에서는 반대 방향의 유의한 차이가 나타나 가설이 지지되지 않았다(t(57) = 6.6565, d = 1.7187, n_a = 30, n_b = 30). T3에서는 두 조건 간 유의한 차이를 찾지 못했다(t(55) = 0.6415, d = 0.1656, n_a = 30, n_b = 30). 만족도는 B가 A보다 높다는 가설이 지지되었으나(t(55) = 8.4674, d = 2.2101, n_a = 29, n_b = 30), 완료시간에 대한 B의 효과는 과제에 따라 방향이 달라 세 과제 전체에서 B가 더 빠르다고 결론지을 수는 없다.

판정 표에는 t·자유도·Cohen's d·n만 있고 유의수준·신뢰구간·집단 평균·과제별 가중치가 없으므로, 효과 추정의 정밀도와 실제 시간 차이의 크기를 평가할 수 없고 과제 전체를 아우르는 완료시간 효과도 추정할 수 없다. T3의 비유의 결과는 두 조건이 동등하다는 증거가 아니며, 동등성을 주장하려면 별도의 동등성 검정이 필요하다. 만족도 분석에서는 A 집단의 n이 29로 완료시간 분석의 30과 달라 결측 처리가 결과에 영향을 주었을 수 있으며, 자유도가 n에서 기대되는 값과 달라 적용된 검정 방식을 표만으로는 확인할 수 없다.

## 방법
- 설계: 인터페이스 A/B × 과제 T1~T3, 참가자 60명, 각 과제 4회. 사전등록 design.json 의 규칙을 그대로 따랐다.
- 분석 단위: 참가자×과제별 유효 trial 평균. 조건당 최소 n=8.
- 제외 규칙: 완료시간 0 이하·600초 초과, errors 비수치, 같은 파일 안 중복 trial_id(첫 것만 유효).
- 신뢰구간: 평균 ± t(0.05, n-1) × sd/√n, 표본 표준편차. 검정: Welch t, 자유도 Welch–Satterthwaite 내림, 양측 임계값 t_critical.json p0125. 보정 α=0.0125. 효과크기: Cohen's d, pooled sd.
- 설문: Q3·Q6 역문항 반전 뒤 7문항 평균 = 만족도.
