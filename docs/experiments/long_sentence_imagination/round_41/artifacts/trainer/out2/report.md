# 인터페이스 A/B 사용자 실험 — 연구 보고서

## 초록·한계(산문)
본 연구는 A와 B 조건을 비교하여 과제 T1·T2·T3의 완료시간과 만족도에 관한 네 가설을 검정하였다. 과제 T1에서는 B의 완료시간이 A보다 짧다는 가설이 지지되었고(t(56) = −10.1752, Cohen's d = −2.6272, n_A = 30, n_B = 30), 만족도도 B가 A보다 높다는 가설이 지지되었다(t(55) = 8.4674, d = 2.2101, n_A = 29, n_B = 30). 반면 과제 T2에서는 가설과 반대 방향으로 유의한 차이가 나타나 B의 완료시간이 A보다 길었다(t(57) = 6.6565, d = 1.7187, n_A = 30, n_B = 30). 과제 T3는 B 조건 표본이 n_B = 6에 그쳐 검정을 수행할 수 없었다.

과제 T3는 B 조건 표본(n_B = 6)이 A 조건(n_A = 30)보다 크게 적어 검정이 불가능했다. 따라서 T3에 대해서는 유의한 차이를 찾지 못한 것이 아니라 가설을 판단할 근거 자체가 없다. 또한 완료시간에 대한 B의 효과가 T1과 T2에서 서로 반대 방향으로 나타나 과제 전반에 걸친 B의 우위로 일반화할 수 없으며, 만족도 분석은 A 조건 표본이 n_A = 29로 완료시간 분석(n_A = 30)과 달라 같은 참여자 집단의 결과로 함께 해석하는 데 주의가 필요하다.

## 방법
- 설계: 인터페이스 A/B × 과제 T1~T3, 참가자 60명, 각 과제 4회. 사전등록 design.json 의 규칙을 그대로 따랐다.
- 분석 단위: 참가자×과제별 유효 trial 평균. 조건당 최소 n=8.
- 제외 규칙: 완료시간 0 이하·600초 초과, errors 비수치, 같은 파일 안 중복 trial_id(첫 것만 유효).
- 신뢰구간: 평균 ± t(0.05, n-1) × sd/√n, 표본 표준편차. 검정: Welch t, 자유도 Welch–Satterthwaite 내림, 양측 임계값 t_critical.json p0125. 보정 α=0.0125. 효과크기: Cohen's d, pooled sd.
- 설문: Q3·Q6 역문항 반전 뒤 7문항 평균 = 만족도.
