# 인터페이스 A/B 사용자 실험 — 연구 보고서

## 초록·한계(산문)
본 연구는 A와 B 두 조건을 세 과제(T1–T3)의 완료시간과 만족도로 비교하였다(완료시간 분석은 조건별 n=30, 만족도 분석은 A n=29·B n=30). T1에서는 B의 완료시간이 A보다 짧아 가설이 지지되었으나(t(56)=-10.1825, d=-2.6291), T2에서는 B의 완료시간이 오히려 길어 가설과 반대 방향의 유의한 차이가 나타났다(t(57)=6.6565, d=1.7187). T3에서는 두 조건 간 완료시간의 유의한 차이를 찾지 못했다(t(55)=0.6415, d=0.1656). 만족도는 B가 A보다 높아 가설이 지지되었으나(t(55)=8.4674, d=2.2101), 완료시간에 대한 B의 효과는 과제마다 방향이 달라 하나의 결론으로 요약할 수 없다.

본 보고는 가설 판정 표만을 근거로 하므로 p값·신뢰구간·조건별 평균과 분포를 제시할 수 없으며, 자유도가 분석마다 달라 적용된 검정 방식과 결측 처리도 표만으로는 확인되지 않는다. T3의 비유의 결과는 두 조건이 동등하다는 증거가 아니며, 만족도 분석에서 A 집단의 n이 29로 완료시간 분석보다 작은 이유도 표에 나타나 있지 않다. 과제별 효과의 방향이 엇갈리므로, 세 과제를 합친 전체 완료시간에 대해 결론을 내리려면 과제별 비중과 전체 효과의 불확실성을 추가로 확인해야 한다.

## 방법
- 설계: 인터페이스 A/B × 과제 T1~T3, 참가자 60명, 각 과제 4회. 사전등록 design.json 의 규칙을 그대로 따랐다.
- 분석 단위: 참가자×과제별 유효 trial 평균. 조건당 최소 n=8.
- 제외 규칙: 완료시간 0 이하·600초 초과, errors 비수치, 같은 파일 안 중복 trial_id(첫 것만 유효).
- 신뢰구간: 평균 ± t(0.05, n-1) × sd/√n, 표본 표준편차. 검정: Welch t, 자유도 Welch–Satterthwaite 내림, 양측 임계값 t_critical.json p0125. 보정 α=0.0125. 효과크기: Cohen's d, pooled sd.
- 설문: Q3·Q6 역문항 반전 뒤 7문항 평균 = 만족도.
