## 2. 제작 경로
1. `[self:lecture]{op:create}`로 덱 생성.
2. 등록 스크립트 `슬라이드틀적용`으로 공통 HTML 틀 + 장별 JSON을 `layout:custom` HTML 슬라이드 4장(s001~s004)으로 렌더(모델 호출 0). 본문은 상단 540px, 하단 180px(25%)은 배경색만 있는 빈 띠. 테마가 우하단(y≈688)에 자동으로 넣는 "indieBizOS" 서명은 틀의 CSS로 제거함(첫 렌더에서 발견→수정→재렌더).
3. visual은 구성 참고로만 사용해 선화 SVG(바늘·천 / 단추→실→꿰매기 3단계 / 옷·도구·마음 세 칸 / 달력·시계)로 그림. visual 문구 자체는 화면에 싣지 않음.
4. `[self:deck]{op:video, engine:"edge", voice:"ko-KR-SunHiNeural", captions:true, width:1280, height:720, wait:true}` — rate 미지정(렌더러 기본 `+0%`), bgm_path 미지정, 전환 fade(기본). 결과: slides 4, narrated 4, missing_notes [], skipped [], captions 8, caption_burned true.
5. 실측 길이 27.84초가 20~70초 범위 안이라 무음 여유 추가는 하지 않음.

## 5. 스트림 (ffprobe 실측)
- 컨테이너: mp4 (mov,mp4…), 27.840 s, 207 kb/s
- 비디오 1개: h264 High, 1280×720, yuv420p, 24 fps
- 오디오 1개: aac LC, 44100 Hz, stereo, 112 kb/s
- 음량: mean −21.1 dB, max −6.6 dB
- 배경음악: bgm_path를 지정하지 않았다. 문장 사이에 −45 dB 이하 무음이 12번 나타나 배경에 연속음이 없는 것과 정합한다(신호 기반 판단).

## 8. 한계·주의
- 장면별 길이는 렌더러 자막 타임라인(실측 나레이션 길이 기반)에서 얻었으며, 장면별 개별 오디오 파일은 렌더러가 남기지 않아 따로 ffprobe하지 않았다.
- 프레임 육안 판독은 장면당 1장(큐 4개)만 했고, 나머지 4개 큐는 픽셀 측정으로만 확인했다.
- 이 영상은 합성 훈련 자료이며 공개·발송·예약하지 않았다.
