## 변경

- **L42-1 수리:** PNG가 누락되면 부분 MP4/ASS는 보존하면서 `source_complete:false`,
  `expected_scenes`, `rendered_slide_ids`, 장면별 `errors`와 안내를 반환한다.
  기존 IBL 경계가 이를 `PARTIAL_SOURCE`로 전달한다. 동기 실행, `check:true`,
  백그라운드 작업 status/wait/cancel에 같은 판정이 적용된다. 옛 done 상태도 skipped가
  있으면 불완전하다. 프로세스 succeeded와 원천 완전성은 구분한다.
  실강에서 의도적으로 띄우지 않은 장면과 무나레이션 장면은 누락으로 오판하지 않는다.
- **L42-2 수리:** 기존 `슬라이드틀적용`은 저장된 덱의 실제 제목·노트를 반환한다.
  틀의 `fields.title`이 행의 확정 제목과 충돌하면 쓰기 전에 거절한다.
  [수정 전체 프로그램](drafts/main_repaired.ibl)은 실제 반환과 원고를 대조한 후 영상화한다.
  검증된 기존 HTML 틀을 재사용해 하단 180px를 확보하고 테마 서명을 제거했다.
  재사용 때 사용자 노트를 입력값으로 덮거나, 입력을 실제 결과라고 보고하지 않는다.
- 영상 가이드·어휘 설명·등록 Script 안내를 갱신했다. 새 어휘나 IBL 코어 변경은 없다.
  계약 용례 14건을 정독하면서 완료 확인이 재렌더를 시작하던 예시와 Edge 음성의

  재현 가능한 `scripts/seed_deck_video_examples.py`를 남겼다.
