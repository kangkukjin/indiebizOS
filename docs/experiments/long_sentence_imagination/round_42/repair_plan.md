# 42회차 후속 수리 검증 계획

기준 리비전: 0136fffb. 기존 훈련·AI 작업 종료 후 사용자 수리 요청으로 시작했다.

- 원래 main_v0.ibl 전체를 원문 그대로 새 덱/출력 폴더로 재실행한다. 생성 모델의 임의 제목·장식을 보장하는 경로가 아니라 기존 실행 회귀 확인이다.
- main_repaired.ibl은 원래 4장 원고를 공통 HTML 틀로 제작하고 실제 저장 제목·노트를 대조한다. 최종 MP4/ASS·PNG의 제목·원고·하단25%를 전건 검증한다.
- 원래 누락 변형: 새 수리 덱의 s003.png를 임시 보존·이동하고 원래 render_existing_v0.ibl을 실행한다. PARTIAL_SOURCE와 source_complete:false, 부분 MP4/ASS 및 누락 진단이 기대값이다. 복원 뒤 4장 완전한 영상으로 회복되어야 한다.
- 새 변형: 원고·시각자료를 역순으로 바꾸고 마지막 제목을 `<함께 & 수선>`으로 변경한다. 동일 수정 프로그램으로 순서·정확한 제목·HTML escape·여백·자막을 확인한다.
- 비동기 작업 status/wait/cancel, 옛 done 상태, 실강 미노출 장면, 무노트, 반복 누락, 전장 누락, 틀 재사용은 backend 회귀 검사로 확인한다.
- 원래 영상과 입력은 지문으로 보존을 확인한다. 사람의 발음/자연스러움 승인은 범위 밖이며 최초 훈련 성능과 후속 수리 실행을 합산하지 않는다.
