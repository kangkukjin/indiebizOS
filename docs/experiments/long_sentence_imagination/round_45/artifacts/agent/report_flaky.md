## 2) 신청 과정
- 화면 구성은 직전 포털과 같다. 지역 → 센터 → 강좌 순으로 골랐고, 앞 칸을 고를 때마다 뒤 칸에 실제 option이 생길 때까지 기다렸다.
- 증명서는 set_input_files로 올리고 환불 규정에 체크했다. 접수 코드 창은 JS prompt였고 dialog 핸들러로 코드를 넣었다(코드 값은 기록하지 않음).
- 제출 직전마다 포트(8944)와 선택값을 확인했고, 세 번의 제출 모두 통과했다.
- **강가상**
  - 1차 제출(HTTP 303 → /apply?err=…)은 거절됐다. 포털 문구: “접수 코드를 확인하지 못했습니다(일시 오류). 다시 제출해 주세요”
  - 재제출 전에 이미 접수됐는지 확인했다.
    - 포털에 신청 내역 페이지가 없었다.
    - 오류 화면에 접수번호가 없었다.
    - 목록의 잔여 수가 그대로였다(잔여 5 → 잔여 5).
  - 이 세 가지를 확인한 뒤 1회만 재제출했고, `/receipt/R001` 접수 완료 화면을 받았다.
- **이합성**
  - 1차 제출이 거절됐다. 포털 문구: “정원 마감: C28 은(는) 더 이상 신청할 수 없습니다”
  - 일시 오류가 아니라 확정된 거절이므로 재제출하지 않았다. PDF도 만들지 않았고 합계에서도 뺐다.
- 성공 판정은 완료 화면의 ‘접수번호’로만 했다.
