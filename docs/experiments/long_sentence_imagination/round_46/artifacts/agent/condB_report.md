## 1. 검색
- 두 포털 모두 로그인 → 날짜 선택 버튼으로 달력 열고 2026-11-14 클릭 → 박수 2박 선택 → 인원 + 1회(1→2명) → 검색.
- 화면 표시 조건이 두 포털 모두 「체크인 2026-11-14, 2박, 2명」으로 trip.json과 같음을 확인한 뒤 표를 읽음.
- 탭: 바다숙소 t1, 산장숙소 t2(tab new). tab list로 두 탭이 함께 열린 것을 확인.
- 쿠키 창: 산장숙소는 '필수만 동의' 클릭함. **바다숙소는 클릭이 REF_NOT_RESOLVED로 실패했고, 다시 조회했을 때 창이 이미 사라져 있어 필수만 동의가 적용됐는지 미확인.**

## 4. 미리보기 대조 — **미실행**
- 시작 전: 화면이 잠기지 않았고 맨 앞 앱은 Electron(indiebizOS)이었음(캡처 판독). [limbs:screen] snapshot은 AX -25204로 앱 조회에 실패.
- [limbs:os_open]은 OS 기본 앱으로만 열 수 있는데, 이 컴퓨터의 PDF 기본 앱은 **PDFgear**였음. wait(expect_app=com.apple.Preview, 10초)가 실패했고, 캡처로도 맨 앞 앱이 PDFgear로 판독됨.
- 미리보기가 맨 앞에 오지 않았으므로 **cmd+w를 포함해 어떤 키도 보내지 않음.** PDFgear 창(hold.pdf)은 열린 채로 둠.
- 참고: PDFgear 화면에서 HB001이 읽혔지만, 미리보기 대조가 아니므로 결과로 치지 않음.
- 막힌 어휘: os_open에 지정 앱(app) 인자가 없음. 사용자 재실 여부를 판정할 어휘가 없음.
