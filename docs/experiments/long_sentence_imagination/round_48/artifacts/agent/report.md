# 진열 개편 결과 — 가상 상점 관리 콘솔

- 콘솔: http://127.0.0.1:8984 (Playwright 헤드리스, scripts/run.py; 증거 evidence.json·shots/)
- **최종 판정: 성공**

## 1) 상품 편집 (자동완성 정확 일치 → 새 탭 편집 → 저장 → 새로고침 재확인 → 탭 닫기)
| 상품 | ID | 전 가격/문구 | 목표 | 시도 | 결과 |
|---|---|---|---|---|---|
| 호두 도마 | P-01 | 38,000 / 호두 도마 기본 문구 | 42,000 / 가을 한정 — 10/17까지 무료 각인 | 1 | 저장됨(1차 성공, 새로고침 값 일치) |
| 유리 화병 대 | P-05 | 32,000 / 유리 화병 대 기본 문구 | 28,000 / 재입고 기념 특가 | 2 | 1차 `저장 실패(500)` → 새로고침 값 변화 없음 확인 후 재시도 → 2차 저장됨 |

- 두 상품 모두 자동완성 후보 중 이름이 정확히 같은 것만 선택했고, 선택 표시(`선택: 이름 (ID)`)와 편집 탭 제목·상품번호로 신원을 확인함.
- 슬라이더는 키보드(→/←, 1000원 단위)로 맞춘 뒤 값을 다시 읽어 목표와 일치(보조 JS 설정 미사용).
- 중복 저장 방지: 매 시도 뒤 편집 탭을 새로고침해 서버 값을 읽고, 이미 반영됐으면 다시 저장하지 않음.
- 저장 후 탭을 닫고 원래 탭(`/products?pick=ID`)으로 돌아옴, 열린 탭 1개 확인.
- 마지막에 별도 탭으로 두 편집 화면을 다시 열어 서버 값 재확인(일치), 그 탭은 닫음.

## 2) 진열 순서 (안정 재배치)
- 바꾸기 전: 황동 촛대 → 호두 도마 → 편백 도마 → 유리 화병 대 → 도자 머그 백 → 린넨 앞치마 → 밀랍 초 2P → 옻칠 젓가락
- 목표: 유리 화병 대 → 밀랍 초 2P → 호두 도마 → 황동 촛대 → 편백 도마 → 도자 머그 백 → 린넨 앞치마 → 옻칠 젓가락
- 마우스 끌기 3회(각각 `순서 저장됨(n번째)` 표시). 판정은 도구 응답이 아니라 **페이지를 새로 불러 읽은 순서**로 함.
- 새로 불러온 순서: 유리 화병 대 → 밀랍 초 2P → 호두 도마 → 황동 촛대 → 편백 도마 → 도자 머그 백 → 린넨 앞치마 → 옻칠 젓가락 → 목표와 **일치**

## 3) 내보내기·display.csv 대조
- `내보내기 완료 — 8행`까지 기다린 뒤 download 이벤트로 받아 `display.csv` 저장(1회 시도).
- 다시 읽은 CSV 순서가 목표와 일치; 호두 도마 42000 / 문구 일치, 유리 화병 대 28000 / 문구 일치. 나머지 6개 상품은 가격·문구 변경 없음(기본값).
- CSV 대조 종합: **모두 일치**
