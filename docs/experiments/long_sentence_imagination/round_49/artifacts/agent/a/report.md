### 사진별 결과
- **변환 46장**: 나머지 전부. 원래 크기별 결과는 1600×2400→533×800, 2000×1125→800×450, 1200×800→800×533, 900×1350→533×800, 2400×1600→800×533이다. 600×600은 키우지 않고 형식만 바꿨다.
- **제외 1장**: `가을 들판 (6).png`. 0바이트라 min_bytes=1 규칙에 걸렸다. name_prefix는 빈 값이라 이 규칙으로 제외된 사진은 없다.
- **실패 1장**: `바닷가 아침 (3).png` (4,008 B). 실패 원문:
  ```
  rc=13 sips: Error: Cannot extract image from file. Error 13: an unknown error occurred
  ```
  크기 조회 때 sips가 `<nil>`을 돌려줘 stderr에 `[: <nil>: integer expression expected` 경고가 2번 남았다. 이 파일의 지문은 여기 원본과 같다. 따라서 보내는 길에 생긴 손상이 아니라 원본 자체가 열리지 않는 파일로 보인다(추정).

## 5. 원본 지문 대조
맥12의 `manifest.sha256`(48줄)과 로컬 원본의 SHA-256을 NFC로 맞춘 이름 기준으로 대조했다.
**일치 48 / 불일치 0 / 누락 0 / 추가 0.** 48장 모두 한글 이름이다. 원래 이름은 양쪽 모두 NFC였고 NFD 변환이나 이름 깨짐은 없었다. 파일별 행은 result.json의 `step5_original_fingerprints.rows`에 있다.
