# 긴문장 상상훈련 5회차 — task (실행 전 기록, 2026-09-30 11:56 KST)

## 자연어 요구 원문
"9월 법인카드 경비 정산해 줘. receipts 폴더의 영수증 PDF 들과 카드 명세서 CSV 를 맞춰 보고,
금액이 다른 것, 영수증은 있는데 카드 내역이 없는 것, 카드 내역은 있는데 영수증이 없는 것, 같은 결제가 두 번 청구된 것 같은 걸 찾아 줘.
가맹점 이름은 영수증과 카드사 표기가 다를 수 있어. 10만 원 이상은 결재가 필요하다고 표시하고,
읽지 못한 영수증은 따로 알려 줘. 사람이 볼 보고서(md)와 후속 처리용 이상 항목 목록(json)을 둘 다 만들어 줘."

## 선정 이유
4회차 원장 "다음" 후보 중 표·PDF 원천. 새 연결 = self:list 로 폴더 전건 → PDF 읽기(글자 층 없음·손상 파일의 부분 실패),
자유 서식 영수증에서 모델 추출(table:ai), 날짜·금액 결합 뒤 표기가 다른 가맹점 동일성 판정(table:judge 첫 사용 — 미결정 null 처리),
중복 청구 탐지, 두 산출물(md·json) 저장·재읽기. 4회차 교훈대로 추출(P1)과 대조·렌더(P2)를 $ref 로 분리.
(4회차 L4 갭은 다른 세션이 작업 트리에서 수리 중 — 라이브 백엔드가 그 미커밋 변경을 포함·재기동할 수 있음)

## 입력 (합성, 비민감) — input/ (gen.py, pymupdf)
- receipts/R01~R12.pdf: 텍스트 서식 7·표 서식 3 / R11 글자 층 없음(그림만) / R12 깨진 PDF
- card_statement.csv 13행: 승인일,가맹점(카드사 표기),금액,승인번호 · policy.json {정책:{결재필요_금액:100000}}

## 프로그램
P1 추출: 폴더 목록 → PDF 전부 읽기(실패·빈 글자 보존) → 글자 있는 영수증을 한 번의 table:ai 로 {가맹점,날짜,합계} 추출 → 합계 표기가 원문에 있는지 검사 → 반환
P2 대조: inputs.추출={$ref P1}, CSV·정책 읽기 → 날짜+금액 짝 → 같은 날 금액 다른 짝은 가맹점 동일성 judge → 분류 → md·json 쓰기·재읽기

## 완료 조건과 기대값 (gen.py 손 계산)
1. 영수증 12개 전부 상태 표시: 읽음 10, R11 "글자 없음(스캔 추정)", R12 "읽기 실패". 0원·빈 영수증으로 처리 금지.
2. 정상 짝 8건: R01,R02,R04,R05,R06,R08,R09(첫 청구),R10.
3. 금액 불일치: R03 교보문고 영수증 45,000 vs 카드 54,000(A1002).
4. 카드 내역 없음: R07 동네 문구점 5,000.
5. 중복 청구 의심: EDIYA선릉 2026-09-11 19,200 두 번(A1008·A1009) — 하나는 R09 와 짝, 다른 하나 중복.
6. 영수증 없음: 우버 택시 23,400(A1005). 김밥천국 15,000(A1011)·GS25테헤란 9,000(A1012)은 "읽지 못한 영수증(R11·R12)과 대응 가능 — 확인 필요"로, 단정적 누락 아님.
7. 결재 필요(≥100,000): R05 111,000 · R08 119,600.
8. 합계: 카드 506,000 / 읽은 영수증 435,400.
9. md·json 저장 후 재읽기 일치, json 은 이상 항목마다 종류·승인번호·영수증 id·금액.
