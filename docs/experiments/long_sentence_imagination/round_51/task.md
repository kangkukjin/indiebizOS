상태: 설계 00:50 → **실행 00:50~01:19 완료**(사용자 "시작해"). 결과는 [report.md](report.md). 설계와 달라진 점: 문진의 독립 대조는 핵심 항목만(검수 도구), 변형 A 는 기본 실행의 밤일 3.7분째·5.4분째에 두 번, 연결 끊김은 없었음.

## 조건이 바꾸는 것
49·50회차는 "맥12 가 켜져 있고 붙어 있다" 를 당연하게 썼다. 이번 조건은 그 전제를 과제로 만든다.
- **가 볼 사람이 없다** → 맥12 가 스스로 돌아오지 못할 수 있는 일은 설계에서 뺀다(아래 "하지 않는 것"). 권한 창이 뜨면 눌러 줄 사람도 없다.
- **뚜껑이 닫혀 있다** → 켜져 있는 것 자체가 조건부다(전원·바깥 화면·잠들기 설정). 화면은 내장이 아니라 바깥 화면이거나 없다.
- 그래서 주제는 "일을 시키기 전에 **그 몸이 일을 받을 상태인지 묻고**, 사람이 자리를 비운 사이를 **기억 없는 두 번의 호출**로 잇는 것" 이다.

## 축
① **몸 상태 문진**: 뚜껑·전원·화면·잠들기 설정·마지막 입력·부하·열 제한·디스크·무선·시계 차이를 한 번에 묻고, 못 본 것은 "못 봄" 으로. 추측 금지
② **맡겨도 되는지 판단을 프로그램이**: 전원 없음 / 잠들 설정 / 디스크 부족 / 열 제한 중 하나면 맡기지 않고 이유를 낸다. 지금은 전부 통과하므로 **거절 경로는 변형으로** 만든다(아래 변형 C — 일감이 요구하는 조건을 맥12 가 못 채우게)
③ **기억 없는 두 번의 호출**: 저녁 실행이 접수증을 파일로 남기고 끝난다. 아침 실행은 그 파일만 보고 같은 일을 찾아 확인·회수한다. 50회차의 재부탁은 "같은 부탁을 또 받음" 이었고, 이번은 "**다른 부탁이 앞 부탁의 일을 이어받음**" 이다
④ **너무 일찍 온 아침**: 일이 아직 도는 중에 아침 호출이 오면 "몇 분째 도는 중" 으로 보고하고 접수증을 그대로 둔다. 다시 시키지 않는다
⑤ **사이에 무슨 일이 있었나**: 밤일이 5초마다 남기는 맥박 기록의 빈 구간 + 맥12 전원 기록(`pmset -g log`)으로 "잠들었거나 멈춘 적" 을 판정. 없었으면 없었다고
⑥ **화면 없이·소리 없이 되는 것 가리기**: 화면 한 장 찍기(만지지 않음)가 닫힌 뚜껑·화면 잠든 상태·권한 없음에서 각각 무엇을 돌려주는가. 무음 파일을 음량 0 으로 재생 접수 → 상태 → 중지(재생 관용구 첫 실전, 실제 소리는 "알 수 없음" 으로 구분)
⑦ **깨우기 관용구의 "이미 깨어 있음" 가지**: 연결된 PC 에는 신호를 보내지 않는가(원장에 wake 작업 0)
⑧ 50회차 수리의 실전 확인: 출력 통로를 문 자식이 남아도 명령 성공으로 판정되는지, 일 둘이 도는 중에도 확인 명령이 바로 도는지, 끊긴·멈춘 일의 시각이 관용구에 실리는지 — 우회 없이 가이드대로

## 자료 (전부 합성, `harness/prepare.py`)
- `night.json`: `{pc, remote_dir, mark, requires:{ac_power:true, sleep_setting:"never_or_longer_than_job", min_free_gb:5, no_thermal_limit:true}, job:{cmd, minutes, limit_s, result}}`
- 밤일 `jobs/night.sh`: 5초마다 `beat.log` 에 `초(epoch) 번호` 한 줄, 끝에 `night.json`(맥박 수·가장 긴 빈 구간·시작·종료). `sleep` 으로만 시간을 쓴다 — **닫힌 뚜껑은 열이 잘 안 빠진다. CPU 를 태우는 일은 넣지 않는다.** 길이는 기본 6분(변형 B 는 제한 3분, 변형 D 는 2분·3분).
- 무음 파일: 중앙에서 만든 30초짜리 무음 WAV(약 240KB). 음량 0 과 겹쳐 이중으로 무음.
- 프로세스 표식 `R51=<실행>-…`, 훈련 폴더 `~/indiebiz-training/r51/<실행>/`.

## 하지 않는 것 — 가 볼 사람이 없으므로
- **재우기·잠들기 설정 변경·예약 깨우기**: 닫힌 노트북이 안 깨어나면 끝이다. `pmset` 은 읽기만.
- **헬퍼 재시작·종료·교체, 등록 일시 중지·해제**: 다시 못 붙으면 끝이다.
- **sudo, 네트워크 설정, 재부팅, 디스플레이 설정**.
- **화면 입력**(클릭·키·끌기): 화면 찍기 한 장만. 권한 창이 뜨면 그대로 두고 보고한다(없애려고 키를 보내지 않는다).
- **들리는 소리**: 무음 파일 + 음량 0 만. 시스템 음량·출력 장치는 읽기만.
- **CPU·디스크를 많이 쓰는 일, 큰 파일 전송**.
- 모든 원격 명령에 제한시간. 남기는 프로세스는 밤일 하나뿐이고 표식으로 찾을 수 있다.

## 시간 배분(60분)
탐침 6분(문진 명령의 출력 모양 · 화면 한 장 · 무음 재생 접수/중지 · 깨우기의 "이미 깨어 있음" 가지 — 넷 다 처음) · 작성 12분(저녁·아침 두 프로그램) · 훈련자 실행 18분(밤일 6분이 가장 긴 줄기, 그 위에 변형을 겹침) · 독립 AI 16분(저녁 → 밤일 6분 → 아침) · 검수·진단 8분. 독립 AI 저녁이 8분을 넘기면 아침은 밤일 길이를 줄인 자료로 바꾸지 않고 다음 회차로 넘긴다.
