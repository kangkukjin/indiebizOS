# 관공서의 공휴일에 관한 규정 제2조(양력 고정일) + 국경일에 관한 법률 제2조 — 이번 실행에서 원문으로 가져온 것만
FIXED_HOLIDAYS = {(1,1),(3,1),(5,1),(5,5),(6,6),(7,17),(8,15),(10,3),(10,9),(12,25)}

def D(s): return dt.date.fromisoformat(s)
def fmt(d): return '%s(%s)' % (d.isoformat(), WD[d.weekday()])
def add_months(d, n):
    y, m = divmod(d.month - 1 + n, 12)
    return y + d.year, m + 1
def is_off(d):
    return d.weekday() >= 5 or (d.month, d.day) in FIXED_HOLIDAYS

def fwd(event, n, unit):
    """민법 제157조(초일 불산입)·제160조(역에 의한 계산)·제159조·제161조를 적용한 만료일."""
    steps = []
    d0 = event + dt.timedelta(days=1)
    steps.append('기산일: 초일 %s 불산입(민법 제157조) → %s' % (event.isoformat(), d0.isoformat()))
    if unit == 'day':
        end = d0 + dt.timedelta(days=n - 1)
        steps.append('%d일째 되는 날: %s' % (n, end.isoformat()))
    else:
        months = n * 12 if unit == 'year' else n
        y, m = add_months(d0, months)
        last = calendar.monthrange(y, m)[1]
        if d0.day <= last:
            end = dt.date(y, m, d0.day) - dt.timedelta(days=1)
            steps.append('최후의 %s에서 기산일 해당일(%s)의 전일(민법 제160조 제2항): %s' % ('연' if unit == 'year' else '월', dt.date(y, m, d0.day).isoformat(), end.isoformat()))
        else:
            end = dt.date(y, m, last)
            steps.append('최종의 월에 해당일 없음 → 그 월의 말일(민법 제160조 제3항): %s' % end.isoformat())
    raw = end
    while is_off(end):
        end = end + dt.timedelta(days=1)
    if end != raw:
        steps.append('말일 %s이 토요일 또는 공휴일 → 익일로 만료(민법 제161조): %s' % (fmt(raw), fmt(end)))
    else:
        steps.append('말일 %s: 토요일·일요일·양력 고정 공휴일 아님(음력 공휴일·임시공휴일은 미대조)' % fmt(end))
    return end, steps

def remain(end):
    n = (end - CONSULT).days
    if n >= 0:
        return n, '상담일(%s) 기준 %d일 남음' % (CONSULT.isoformat(), n)
    return n, '상담일(%s) 기준 %d일 지남' % (CONSULT.isoformat(), -n)

def cite(law_id, no, br='', pick=None):
    if '-' in no:
        no, br = no.split('-')
    a = art.get(law_id, no, br)
    assert a, (law_id, no, br)
    text = a['text']
    note = ''
    if pick:
        lines = text.split('\n')
        sel = [lines[0]] + [l for l in lines[1:] if any(l.startswith(p) for p in pick)]
        text = '\n'.join(sel)
        note = ' (발췌: 머리말과 %s만 옮김)' % ', '.join(pick)
    return {'law': a['law'], 'law_id': law_id, 'law_eff': a['law_eff'], 'article': a['article'], 'title': a['title'], 'art_eff': a['art_eff'], 'text': text, 'note': note}

def ymd(s):
    return '%s-%s-%s' % (s[:4], s[4:6], s[6:]) if s and len(s) == 8 else s

def P(i):
    p = prec.get(i)
    return {'id': i, 'case_no': p['case_no'], 'date': ymd(p['date']), 'court': p['court'], 'name': p['name'], 'holding': p['holding'], 'refs': p['refs']}

    L = ['# 상담 준비 메모 — %s' % c['no'], '', DISCLAIMER, '',
         '- 상담 창구: 느티나무 마을 법률상담 창구', '- 상담일: %s' % fmt(CONSULT), '- 신청인(가명): %s · 접수일: %s' % (c['applicant'], c['intake']), '',

    for a in c['cites']:
        L += ['', '### 「%s」 %s(%s)%s' % (a['law'], a['article'], a['title'], a['note']),
              '- 법령 시행일: %s · 조문 시행일: %s · 법령ID %s' % (ymd(a['law_eff']), ymd(a['art_eff']), a['law_id']), '']
        L += ['> ' + l if l else '>' for l in a['text'].split('\n')]

    else:
        L += ['- **' + c['deadline_text'] + '**']

        L += ['> ' + l.strip() if l.strip() else '>' for l in p['holding'].split('\n')]
