## 확인하지 못한 것 / 상담 때 확인할 날짜
- **C01 월급 정기지급일**: 표의 기한(2026-12-14)은 퇴직 금품청산 기일 기준의 가장 늦은 기한이다. 각 월급의 정기지급일이 기산점이면 앞선 달 월급의 3년 시효는 상담일 전후에 이미 끝났을 수 있다 — 상담 시 최우선 확인. 퇴직금 미지급 여부도 미확인.
- **C02**: 해고 효력일이 2026-08-03인지 08-04인지("내일부터"), 상시 근로자 수 미확인. 문자 해고통지의 서면성 판례는 못 찾음.
- **C03**: 갱신요구 기간 마지막 날(2026-11-30)은 달력상 역산 결과 — 역산 방법을 정한 조문 원문은 이번에 가져오지 못함.
- **C04**: 계약내용 서면(주문 확인) 수령일 미확인 — 기산점이 바뀔 수 있음.
- **C05**: 상속개시를 "안 날"(2026-08-20)을 증명할 자료 미확인. 사망일 기준이면 2026-11-16(월). 제1026조(법정단순승인) 원문은 이번에 가져오지 않음.
- **C06**: 일부 치료비 지급의 시점·주체(시효 중단 여부) 미확인. "손해 및 가해자를 안 날"을 직접 다룬 판례 못 찾음.
- **C07**: 시효 중단 사유(승인·일부 변제·청구) 유무 미확인 — 있으면 결론이 달라짐. 2026년 추석 연휴의 양력 날짜는 법령 원문으로 대조하지 않음(결론에는 영향 없음).
- **C08**: 계약서에 청약철회 안내가 적혀 있었는지, 2026-10-15 전에 철회 의사를 발송했는지 미확인. 계속거래 해지·위약금 대법원 판례 못 찾음.
- **C09**: 모친 사망일(2025년 6월 며칠)·증여 일자 미확인 → 10년 기한과 제1114조(산입될 증여) 해당 여부는 날짜 확인 필요.
- **C10**: 계약 종료일·퇴거일 미기재 → **날짜 확인 필요**(기한 계산 안 함).
- **C11**: 계약일·직전 증액일 미기재 → **날짜 확인 필요**. 신청인이 적은 「임차인보호특별법」 제5조는 국가법령정보 검색 5회에서 실재하지 않음으로 판정(유사명 「부도공공건설임대주택 임차인 보호를 위한 특별법」 제5조는 매입방법 조항). "3%" 상한은 가져온 원문 어디에도 없음 — 원문상 상한은 "20분의 1". 해당 시·도 조례, 주거용 여부는 미확인.
- **공휴일 대조 범위**: 「관공서의 공휴일에 관한 규정」 제2조·「국경일에 관한 법률」 제2조 원문의 양력 고정일과 토·일만 대조. 음력 공휴일(설·추석·부처님 오신 날)의 양력 환산과 임시공휴일은 미대조 — 계산된 기한 가운데 이에 걸린 것으로 보이는 날은 없음.
- **법령 시행일 표기**: 「근로자퇴직급여 보장법」은 검색 목록에 시행일자 2026-09-18, 상세 본문 기본정보에 2026-07-01로 서로 달라, 메모에는 실제 조문을 가져온 상세 본문의 값을 적음.

## 자료·방법
- 법령: [sense:legal] target=law 검색 → 법령ID로 상세 조회, 원문 JSON은 out/_sources/law_<법령ID>.json 에 보존. 조문은 그 파일에서 기계적으로 발췌(손으로 옮겨 적지 않음).
- 판례: target=prec 사건명 검색(대법원 결과 검토) → 판례일련번호로 상세 조회, out/_sources/prec_<번호>.json 보존. 판시사항은 원문 그대로.
- 기한: 민법 제157조(초일 불산입)·제159조·제160조(역에 의한 계산)·제161조(말일 토요일·공휴일 → 익일) 원문에 따라 계산. 남은 날 = 기한 − 상담일(2026-10-17).
