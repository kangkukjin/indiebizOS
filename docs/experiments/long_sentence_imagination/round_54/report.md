## 발견과 원인

- **L54-1 (구현)**: eng_law 상세의 원천 Law.InfSection/JoSection/ArSection이
  정규화되지 않는다. success=true·count=1이지만 items는 제목·본문·출처 없는 행이다.
  실제 응답에는 영문 조문 42개가 있다. 기본/변형/독립 AI에서 재현했다.
- **L54-2 (구현·발견)**: law_term 검색의 법령용어상세검색은 공개 링크인데 매핑하지
  않고, API용 상세링크를 제외하여 url이 빈 값이 된다. 사전구분코드도 정규화에서
  소실되어 한영사전/정의사전 구분을 찾으려면 원천 JSON을 열어야 한다. 상세에도
  공개 링크가 없다. 공식 반환 링크를 직접 열어 대항력/counterforce를 확인했다.
- **작성 결함**: 보충자료 함수가 본문만 있으면 retrieved로 판정해 링크 없는 번역어를
  확보로 셌다. v3에서 사전 종류·본문·공개 링크를 함께 보고 translation_only와
  missing_source를 구별한다. 국문 정의를 만들어내지 않는다.

최소 재현은 `[sense:legal]{id:"001248",target:"eng_law"}` 및
`[sense:legal]{query:"대항력",target:"law_term"}` → id 상세다.
원천 증거는 evidence/source_8~11.json. API 사용자 식별값은 기존 수리대로 제거되어 있다.
