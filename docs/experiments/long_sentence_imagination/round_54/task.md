정확한 법령명을 찾아 조문 원문·시행일·공개 링크와 대조하고, 없는 법/없는 조는
확인되지 않았다고 남겨 주세요. 같은 법은 한 번 조사해서 여러 접수에 함께 써 주세요.
계약서·차임 내역·통지 증거 중 접수에 빠진 자료를 건별로 정리하고, 미확인 인용이나
자료 누락이 있는 건을 먼저 배치해 주세요. 과거 사건에는 현재 조문이 당시 적용된다고
단정하지 말고 과거 판본 확인 필요를 표시해 주세요. 승소 가능성이나 확정 법률 판단은

원문과 출처를 보존하고, 본문 없는 성공 응답을 완성된 자료로 세지 마세요.

## 완료 조건 (사전 고정)

1. 입력 id 전건·순서 보존, 중복 산출 없음.
2. 법령명 정확 일치, 없는 법은 unverified_law, 없는 조는 unverified_article.
3. 확인된 조문 text와 번호·시행일·출처 보존(원천 독립 비교).
4. 누락자료는 required_documents - documents 전건 일치.
5. 사건일이 취득한 법령 시행일보다 이르면 historical_review=true; 시각 부재는 확인 필요.
6. 미확인/누락 우선 목록은 입력 순서를 보존한 정확한 부분집합.
7. 보충자료는 비어 있지 않은 원문과 공개 출처를 갖거나 실패/미확인 표시.
8. JSON·Markdown 모두 생성·재독. API 식별값(OC)은 저장되지 않음.

훈련자는 가이드·공개 계약으로 단일 IBL 작성(핵심 Python 우회 없음).
동일 요청을 자연어로 시스템 AI에 별도 입력/출력 경로만 전달한다.
