# 56회차 — 부동산 현재 매물 검색

평택 비전동과 동삭동에서 전세 빌라를 찾고 있어. 네이버부동산과 직방에서 지역별로 최대 10개씩 현재 광고를 확인하고, 보증금 2억원 이하·전용면적 50㎡ 이상인 후보를 비교해 줘. 금액은 만원으로 맞추고 출처·매물 링크·면적·보증금을 남겨 줘. 같은 출처에서 같은 링크가 나온 것은 한 번만 보여주되 어느 검색 지역에서 나왔는지 보존해. 조건을 알 수 없는 매물은 미확인으로 분리하고, 한 검색이 실패하면 성공한 결과는 남기고 실패 이유를 써 줘. 표본 검색이므로 전국 또는 해당 지역의 매물이 전혀 없다고 단정하지 마. 원응답과 비교 결과를 JSON으로 저장하고 요약 Markdown도 만들어 줘. 중개사 연락·예약·발송은 하지 마.

- 시작: 2026-10-11 22:44 KST 전후. 자료 준비부터 진단까지 상한 60분. 후속 수리·검증 별도.
- 실서비스 읽기 전용, 출력은 `outputs/long_sentence_imagination/2026-10-11_56회차/{trainer,ai}`.
- 변형: 자신의 저장한 원응답으로 보증금 상한만 1억5천만원으로 변경, 재검색 없이 별도 JSON/Markdown. 원자료 불변.
- 기대: 4개 검색 각각 성공/실패 구분, 원응답 보존, 후보 전건 조건 일치, 누락값 0 치환 금지, 출처별 URL 중복 제거·검색 지역 합집합, 표본 한계 표기, 저장 후 재독.

- 분해: 지역/소스별 수집(실패 보존) → 단위·결측 정규화 → 출처/URL별 통합 → 조건 분류 → 저장·재독. 저장 원응답 입력 모드를 두어 변형에서 수집 재실행 방지.
