## 자연어 과제

시험용 공개창고를 정리해줘. warehouse의 파일 전부를 실제로 조사하고 policy.json의 관리 여부,
목표 공개 등급, 버전 정보를 대조해줘. 내용이 같은 파일, 등급별 같은 이름의 다른 내용,
버전 미상, 끊어진 링크를 보고해줘. 수동 배치 파일은 내용과 위치를 보존하고,
자동 관리 파일 중 버전이 확인되는 것만 목표 등급으로 이동하되 상대 경로는 유지해줘.
목표 경로가 다른 파일로 차 있으면 덮어쓰거나 이름을 바꾸지 말고 보류해줘.
중복 파일도 공개 등급과 링크 의미가 다를 수 있으므로 목록만 보고해줘.
HTML의 상대 href를 확인하고 .url의 외부 주소는 연락하지 않고 목록에만 남겨줘.
등급 0~4 방문자에게 보이는 목록을 각각 만들어줘. 같은 상대경로는 접근 가능한 최고 등급이 이긴다.
각 방문자 목록을 기준으로 내부 링크의 연결 여부를 검사해줘.
최종 inventory.json, result.json(파일별 결정·근거·변경/보류·중복·등급별 목록·링크 검사),
사람이 읽는 report.md를 저장하고 재독해서 실제 산출물을 확인해줘.
중간 실패 시 완료한 작업을 다시 하지 않고 남은 작업을 이어갈 수 있는 기록을 남겨줘.
