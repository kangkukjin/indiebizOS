# 긴문장 상상훈련 6회차 — task (실행 전 기록, 2026-09-30 13:00 KST)

## 자연어 요구 원문
"2025년 가계부 연간 결산해 줘. ledger 폴더에 월별 카드 내역 CSV 12개가 있고, rules.json 에 가게→분류 규칙, fixed.json 에 매달 나가야 하는 고정지출 목록이 있어.
규칙으로 분류하고 규칙에 없는 가게는 AI 로 분류하되 AI 가 붙인 분류는 표시해 줘. 월별·분류별 지출 표, 같은 날 같은 가게 같은 금액이 두 번 찍힌 중복 결제 의심,
고정지출이 빠진 달이나 금액이 평소와 다른 달, 분류별로 평소보다 지출이 크게 튄 달(다른 달 평균의 2배 이상), 구독 중에 서로 겹치는 서비스(음악 둘, 영상 둘 같은 것)를 찾아 줘.
환불(음수)은 지출에서 빼고 따로 합쳐 줘. 못 읽은 파일이나 금액을 못 읽은 줄은 따로 알려 줘. 사람이 볼 보고서(md)와 후속 처리용 이상 목록(json)으로 저장해 줘."

## 선정 이유 (5회차 원장 "다음" 후보 + 재평가 권고)
새 연결 = ① 파일 12개 병렬 읽기·부분 실패 합류(`each parallel + on_error:collect`, `&`), ② 수천 행(≈3,000) 규모의 정규화·집계·대조 — 공유 예산(10만 단계·1만 반복 행)이
실제 개인 과제 규모에서 어떻게 닿는지, ③ 규칙 분류 + 잔여만 모델(table:ai) — 모델 입력을 행이 아닌 **가게 단위**로 줄이는 작성 선택, ④ table:judge 를 쌍(pair) 판정에 쓰고
threshold 미결정(null) 가지를 결과에 노출, ⑤ effects:unknown 인 변환자(groupby·dedup)가 낀 프로그램의 reuse(L3-1·L5-3 부류 재확인).
4·5회차 교훈대로 수집·분류(P1)와 분석·판정·렌더(P2)를 `$ref` 로 분리.
(5회차 L5 갭은 다른 세션이 작업 트리에서 수리 중 — describe 에 PDF 표지 제거·corrupt·judge effects:model 이 이미 보임 → 라이브 백엔드는 그 미커밋 변경 포함. 상태 ACTIVE 확인.)

## 입력 (합성, 비민감) — input/ (gen.py, seed 6)
- ledger/tx_2025-01..12.csv: 일자,설명,금액,결제수단 (월 ~250행, 합 ~3,000행). 심은 것: 중복 결제 3건(03-14 스타벅스 6,100 / 08-02 이마트 84,300 / 11-20 CGV 15,000; 자연 발생 중복은 expected.json 이 데이터에서 계산),
  넷플릭스 06월 없음·관리비 09월 없음·통신비 04월 89,000(평소 55,000), 12월 식비 ×2.6, 02월 병원 350,000, 환불 3건(음수).
- rules.json: 키워드→분류 30개(환불 규칙 첫 번째). 규칙에 없는 가게 18종(PAYPAL *STEAMGAMES, HAIRSHOP BLUE, KTX 코레일 …) ~300행 → AI 분류 대상.
- fixed.json: 고정지출 9개(구독 7 + 주거 2) 이름·키워드·금액·결제일.
- expected.json: gen 기준 기대값(행수·총지출·중복·빠진 달·튄 달·분류별 연간).

## 프로그램
- P1 수집·분류: self:list → 12 CSV 병렬 읽기(실패 보존) → 한 번의 each 로 정규화(number·월·환불 표시·금액 오류 보존) → 가게(설명) 단위 dedup → 규칙 분류 → 미분류 가게만 table:ai 한 번 → join 으로 행에 분류 부여 → 반환(행·파일상태·금액오류행·AI분류·가게수).
- P2 분석·판정·렌더: inputs.자료={$ref P1}, fixed.json 읽기 → 월×분류 집계(groupby) → 중복 결제(groupby [일자,설명,금액] count>1) → 고정지출 빠진 달·금액 다름 → 튄 달(다른 달 평균 2배) →
  구독 가게 쌍 table:judge(겹치는 서비스?, boolean, null 노출) → md·json 쓰기·재읽기.

## 완료 조건과 기대값 (expected.json)
1. 파일 12개 전부 읽음, 행수 = expected.행수, 금액 오류 행 0.
2. 분류: 규칙 분류 + AI 분류(출처 표시), 미분류 0. AI 분류 대상 가게 18종·행수 = expected. (AI 가 붙인 분류의 정확성은 기대 분류와 비교해 기록하되 합격 조건은 "표시됨"·"가게 전부 분류됨".)
3. 월별·분류별 표: 총지출(환불 제외) = expected.총지출, 환불 합 = -82,000 별도.
4. 중복 결제 의심 = expected.중복결제 전부(심은 3건 포함), 누락·추가 없음.
5. 고정지출: 넷플릭스 06·관리비 09 빠짐, 통신비 04 금액 다름(89,000 vs 55,000). 그 외 없음.
6. 튄 달: 식비 12월, 의료 02월(expected.튄달). 다른 분류 오검출 없음(AI 분류 가게가 새 분류를 만들면 그 분류 안에서 판정 — 기대값과 대조해 기록).
7. 구독 겹침: (스포티파이,멜론)·(넷플릭스,왓챠) true. 그 외 쌍은 false 또는 null(미결정) — null 은 "확인 필요"로 보고서에 노출, false 로 숨기지 않음.
8. md·json 저장 후 재읽기 일치. json 은 이상마다 종류·근거(일자/가게/금액/월).
