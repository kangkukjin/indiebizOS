## 자연어 요청

로컬 자료실의 세 페이지에 있는 자료 18건을 내장 브라우저로 확인하고 각 상세의 전체 제목,
자료 ID, 금액, 상태, 마지막 확인문을 모아 JSON과 한국어 Markdown 보고서로 저장해줘.
목록은 축약 제목이고 JavaScript로 늦게 나타나므로 상세에서 실제 내용을 확인해줘.
일부 상세는 폼 안에 본문이 있고 긴 본문도 있다. 숨겨진 값과 입력칸 값은 보고서에 넣지 말아줘.
모든 항목의 출처를 남기고 읽지 못한 것은 미확인으로, 읽은 금액만 합산해줘.
자료 없는 목록과 읽기 실패를 혼동하지 말고 저장한 결과도 다시 읽어 확인해줘.
목록·상세 자료는 브라우저 화면에서 확보하고 원본 서버 코드·다른 실행자의 결과·정답은 읽지 마.

변형: 같은 프로그램으로 flaky 경로를 처리한다. D07 상세는 읽을 수 없고 다른 17건은 보존한다.
독립 AI는 자기 직전 결과만 재사용 가능하며 다른 실행자의 trainer/harness/drafts는 참조하지 않는다.
