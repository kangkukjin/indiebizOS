## 과제와 작성 조건

실제 종료된 54~61회차 보고서8개에서 관측·수리 근거·미검증을 구분해 후보3개를 만들고, 완료 판정·근거 보존 과제를 선택했다. 선택한 과제는 합성12훈련·24실행·72조건·2,400이벤트의 검사/실행/달성·근거·과금 중복을 대조한다. 실제 기록의 수치와 합성 수치는 합치지 않았다.

변형은 누락된3실행의 자료6파일 추가 + R00의 같은 경로 산출물/검수2파일을 v2로 교체했다. 기대는 미검증3→달성, 기존 달성1→부분 달성, 다른20실행·비용 불변이다. 추가 순서 탐침은 JSON 필드 순서만 바꿨다.

훈련자 IBL은 원문 읽기/의미 정리/후보 선택·기준 저장 → 결정론적 대조·비용·보고/재독 → 같은 프로그램의 변경 입력 실행으로 나눴다. 최초 `prepare_v0.ibl`, `audit_v0.ibl`을 보존했다. 기존 공개 교재·describe와 HTTP 전송 방식만으로 작성했다. 순서 탐침 뒤 공유 교재 회귀 연결을 위해 `backend/test_ibl_composition_teaching.py`를 읽었다(진단 단계). 내부 구현으로 최초 작성의 빈칸을 채우지 않았다.

시스템 AI는 자연어 요구·공개 계약·자료 위치만 받았다. 훈련자 초안·결과·oracle·생성기는 제공하지 않았다. 두 실행은 별도 입력·출력 폴더를 썼고 후속은 자기 결과 재사용을 허용했다. 다만 훈련자가 자료 생성·oracle을 함께 맡았으므로 시스템 AI와 같은 눈가림 조건은 아니다. 독립성은 허용 경로 지시와 관측 궤적으로 관리했으며 OS 수준 읽기 격리는 하지 않았다.

### 수리 후 고정한 조건 진리표

1. 같은 판본에서 실제 값과 검수가 둘 다 Bool이며 다르면 모순 → 미검증.
2. 그 외 실제 값 false → 미충족. 검수 부재/오래된 판본이 실제 실패 증거를 지우지는 않는다.
3. 실제 true + 같은 판본 검수 true → 충족.
4. 나머지 → 미검증. 요구0건인 실행도 미검증이다.

이것은 이번 업무의 명시적 판정 계약이지 IBL 언어의 보편 규칙이 아니다. 공유 교재의 기록 비교도 평면 스칼라 레코드에 한정하며 중첩 JSON 정규화로 홍보하지 않는다.

## 비용·낭비·잔여

실제 원장 `model.usage(accounting=billable_usage)`의 입력/출력을 합산하고 cache는 별도 성분으로 보존했다. 원시 이벤트와 `cost.summary`를 중복 합산하지 않았다. 내부 판단·평가·분류·관측된 배경 호출을 포함하며 작성자인 외부 Codex 비용은 미측정이다.

| 시스템 AI | 입력 | 출력 | cache_read | cache_create | 관측 모델 호출 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 ep4647 | 3,383,510 | 36,479 | 3,085,488 | 292,873 | 4 |
| 변형 ep4648 | 1,759,938 | 19,030 | 1,639,548 | 109,442 | 6 |

입력은 원장이 제공한 값이며 캐시 성분을 다시 더하지 않는다. `origin:training`이라 실사용 증류 비용을 유발한 비교가 아니다. [역할별 원장](evidence/agent_runs.json), [IBL 실행 계측](evidence/trainer_runs.json).

필요했던 비용은 원문8건의 의미 판단, 독립 원자료/최종 표 대조, 변경 파일의 재확인이었다. 줄인 일은 전문 재복사·그룹별 전체 재탐색·같은 행의 자기 비교다. 기본 엔진 시간15.542→3.552초는 같은 합성 과제의 각1회 측정이며 작성 시간·운영·모델 전체를 포함한 절감률이 아니다. 본문 축소 때 모델 재호출을 피한 것은 실제 재사용1회로 확인했다.

독립 AI는 정상 자작/셸 관문 거절과 순수 식·null 표시·contains 타입 작성 오류를 거쳤다. 관문 자체는 올바른 거절이므로 약화하지 않았다. 수리한 교재가 다음 독립 AI의 선택·토큰을 개선하는지는 이번에 재호출하지 않아 미검증이다. 두 실행자 모두 변경 뒤 결정론 계산 전체는 다시 했으며, 읽기/스크립트/기준 재사용을 부분 계산 재사용이라고 부르지 않는다.

훈련 약15분, 이후 수리·검증·증거 정리는 별도다. 시험 입력/출력은 회차 폴더에 증거로 보존했고 외부 발송·예약·관용구 등록·사용자 자료 수정·상주 시험 자원은 없다. 다음 과제는 **실제 훈련 보고서의 주장과 판본이 다른 실행 증거를 연결하고, 부분 계산 재사용과 전량 계산의 비용을 같은 조건에서 비교**하는 것으로 갱신했다. 다음 회차는 시작하지 않았다.
