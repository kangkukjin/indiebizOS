## 자연어 요청 원문
KHJoffice에서 제공한 작은 작업 앱을 별도 시험 폴더에 설정해 줘. 기존 IndieBiz 설치와 다른 작업은 건드리지 말고, Python 환경을 확인해 전용 가상환경을 준비하고, 입력 파일과 기존 사용자 설정(user_note)을 보존하면서 12개 한글·일본어·이모지 입력을 처리해 결과를 만들어 줘. 제품 어휘 로더 사본이 Windows 기본 인코딩에서도 동작하는지 먼저 확인하고, 실패하면 원인을 기록한 뒤 이번 실행에만 적용하는 우회로 나머지를 검증해 줘. 로컬 HTTP 서비스는 18765가 차 있으면 빈 포트를 사용하고, 응답의 PID·폴더를 실제 실행과 대조해 줘. 작업 접수와 종료 코드, 산출물 검증을 구분하고, 시험 서비스는 종료해 줘. 패키지가 존재한다는 사실만으로 모델이나 Electron 기능까지 작동한다고 보고하지 마.

## 변형
출력 폴더를 out2로 바꾸되 user_note와 기존 out 결과를 보존한다. 처리 접수 뒤 응답을 놓쳤다고 가정하고 같은 요청ID나 영수증으로 회수하여 중복 처리를 방지한다. 환경 재설치 없이 12개 결과와 실제 실행 횟수(기본 1 + 변형 1)를 확인한다.
