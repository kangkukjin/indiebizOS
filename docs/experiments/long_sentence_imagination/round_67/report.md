## 재현

`harness/prepare.py`로 합성 자료를 만든 뒤, `base_v0.ibl` 또는 `base_v2.ibl`을
`POST /ibl/execute`에 edition=2, origin=training, project_id=수동모드와 함께 전달한다.
inputs는 `input`(생성한 inputs 절대 경로), `context_file`(context.json 또는 context_variant.json), `out`(별도 출력 절대 경로)이다.
먼저 check=true로 검사한 후 같은 인자를 실행한다. `harness/verify.py <출력폴더> --context <입력명>`으로 비교한다.
`harness/new_variant.py`는 추가 변형 자료를 만들며 `--inputs <inputs_new>`로 검증한다.
