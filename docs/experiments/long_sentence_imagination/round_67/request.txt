부모님 병원 방문부터 귀가까지 챙기는 과정을 8개 가상 사례로 실행해 줘. 각 사례에서 받은 시각이 가장 늦은 예약 문자를 고르고, 그 문자가 취소라면 과거 예약으로 되돌아가지 말고 취소로 표시해 줘. 시각의 시간대가 달라도 실제 받은 순서로 비교해 줘. 지난 기록의 질문을 보존하고, 내가 바쁘면 누나가 yes라고 응답했을 때만 동행 확정, 답이 없으면 대기로 남겨 줘. 보행 한도와 예산을 만족하는 이동편 중 요금, 이동시간, ID 순으로 하나를 골라 줘. 출발은 예약 분에서 도착 여유, 이동시간, 비 오는 경우 추가시간을 빼서 계산하되 자정을 넘으면 날짜까지 보정해 줘. 전날 안내 날짜도 계산해 줘. 처방전과 진료 메모의 안내가 다르면 두 원문과 출처를 남기고 확인 대기, 엄마 확인 전에도 가족 공유 대기로 표시해 줘. 안내 일치와 엄마 확인을 모두 만족해야 가족 공유 초안이 준비된 것으로 표시해 줘. 귀가 미확인이면 마무리 대기, 확인됐을 때만 비용 합계와 다음 예약을 포함해 완료로 표시해 줘. 취소 사례는 이동·안내·공유·마무리를 모두 취소하고 비용을 정산하지 마. 사례마다 선택한 문자 ID, 날짜/분, 동행, 이동편, 출발 날짜/분, 전날 안내 날짜, 질문, 두 진료 원문/출처, 공유 상태, 귀가/정산 상태, 비용, 다음 예약을 plan.json에 남기고 사람이 읽는 한국어 report.md에도 8개 사례를 빠짐없이 적어 줘. 동행과 이동편이 확정된 경우만 reminder 초안, 공유가 준비된 경우만 share 초안을 outbox.json에 만들어 줘. 초안 key는 사례ID:종류:예약날짜:예약분이며 이미 succeeded인 영수증만 중복 억제하고 failed는 재시도 후보로 남겨 줘. 외부 행동을 실행하는 과제가 아니라 로컬 파일만 만드는 리허설이므로 모든 메시지는 초안으로만 저장해 줘. 실제 계정·폰·캘린더·스케줄러를 조회하거나 발송/예약하지 마. 원자료를 수정하지 말고 세 결과 파일을 생성한 뒤 실제 내용까지 확인해 줘.
