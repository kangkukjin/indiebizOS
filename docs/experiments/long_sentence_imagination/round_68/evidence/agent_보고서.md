# 사진·음성 메모 정리 보고서

정렬 규칙: "사전순으로 앞선 이름"은 파이썬 `sorted`의 유니코드 코드포인트 비교로 판정했다. 공백(0x20)이 "."(0x2E)보다 앞서므로 `IMG_0002 복사본.jpg`가 `IMG_0002.jpg`보다 앞선다.
내용 지문 = 파일 바이트 전체의 SHA-256. 완전 중복 = 지문 동일. 유사 중복 후보 = EXIF 촬영 일시·가로×세로가 같고 지문이 다른 사진(옮기지 않고 앨범에 두되 분류를 유사중복후보로 표기).
음성 판정 기준: ① 디코드는 되지만 말이 없거나 받아쓰기가 실패하면 `음성/미분류/`로 옮기고 이유를 적는다. ② 파일 자체를 열거나 디코드할 수 없으면 읽기실패로 보고 제자리에 둔다. 음성 날짜는 파일 수정 시각(m4a 의 creation_time 태그는 변환 시각이라 쓰지 않음).

## 미확인·한계

- 사진 묘사·핵심어는 이미지 읽기 모델(engines:image_read)의 판단이며, 그림 속 글자에 크게 기댄다.
- 음성 전사는 sense:listen 결과이며 모델 호출 0회(이 파일의 기존 캐시 재사용)였다.
- 새 파일이 추가된 상태의 재실행은 시험하지 않았다. 새 파일 없는 재실행에서 새로 처리 0건·앨범 이름 불변만 확인했다.
- Screenshot_2026-10-01.png 는 EXIF 가 없어 파일 수정 시각을 날짜로 썼다(파일 이름의 날짜는 쓰지 않음).
