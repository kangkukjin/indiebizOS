폰에서 PC로 옮겨 둔 사진·음성 메모 묶음 폴더를 정리해 줘. 폴더 안의 사진(jpg/png)과 음성(m4a)을 전부 다루고, 다른 종류의 파일은 손대지 말고 목록에만 적어 줘.
사진마다 촬영 일시는 사진 안의 촬영 정보를 우선하고, 촬영 정보가 없으면 파일 시각을 쓰되 그 사실을 표시해 줘. 각 사진의 내용을 한 줄로 묘사하고 핵심어를 3개 뽑아 줘. 읽을 수 없는 파일은 작업을 멈추지 말고 이유와 함께 보고에 남기고 제자리에 둬.
내용이 완전히 같은 사진은 하나만 남기고 나머지는 정리/중복/ 폴더로 옮겨 줘(남길 것은 이름이 사전순으로 앞선 것). 촬영 일시와 가로세로 크기가 같은데 내용이 다른 사진 쌍은 옮기지 말고 '유사 중복 후보'로 보고에만 적어 줘.
남은 사진은 촬영 날짜별로 정리/앨범/YYYY-MM-DD_주제/ 폴더로 옮기고, 주제는 그날 사진들의 묘사에서 2~6글자 한국어로 정해 줘. 옮길 때 파일 이름은 YYYYMMDD_HHMMSS_원래이름 으로 바꿔 줘.
음성 메모는 받아써서 말이 있으면 정리/음성/YYYY-MM-DD/ 폴더로 옮기고 같은 이름의 .txt 에 전사문을 저장해 줘. 말이 없거나 받아쓰기가 안 되면 정리/음성/미분류/ 로 옮기고 이유를 적어 줘. 전사문에 날짜나 행사가 나오면 같은 날짜의 앨범과 연결해 줘.
정리/목록.csv 에 파일마다 원래 이름, 새 경로, 날짜, 날짜 출처, 내용 지문, 분류(앨범/중복/유사중복후보/음성/미분류/읽기실패/기타), 핵심어를 적고, 정리/보고서.md 에 건수 요약·앨범별 표·중복 쌍·유사 중복 후보·음성 전사 요약·읽기 실패 목록을 한국어로 적어 줘.
다 옮긴 뒤 실제로 폴더를 다시 읽어서 앨범·음성 폴더의 파일 수가 목록과 맞는지, 원래 폴더에 읽기 실패 파일과 다른 종류의 파일만 남았는지 확인해 줘. 같은 폴더에 새 파일이 더 들어와 다시 실행해도 이미 정리한 파일은 다시 다루지 말고 새 파일만 처리해 목록에 보태 줘. 이미 있는 날짜 앨범의 주제 이름은 바꾸지 마.
