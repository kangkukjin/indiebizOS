## 작성과 최초 관측

공개 조합 교재·문법·`describe`만 사용했다. 기존 회차 HTTP 전송 예제는 참고했지만 구현 소스·내부 시험은 작성에 사용하지 않았다. `후보만들기`(순수)·`토론정리`(AI)·`저장검수`(파일)를 지역 함수로 분리하고 후보 계산과 토론 분석을 병렬로 합류했다. 핵심 계산을 Python에 숨기지 않았다. 검증기는 별도 Python 구현으로 최종 파일의 전건을 대조한다.

## 비용·낭비·잔여
