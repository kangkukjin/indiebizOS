소규모 독서 모임을 기획하고, 취소가 생겼을 때 갱신할 수 있는 계획과 모임 뒤 후속 질문을 정리해 줘. 제공된 JSON의 참가자 관심사·가능 시간·독서 이력, 책·공간 후보만 이용해 모든 날짜×책×공간 조합을 비교해 줘. 취소된 참가자는 빼고 그 시간에 가능한 참가자는 모두 참석한다고 가정해. slots가 null인 사람은 가능 여부 미확인으로 따로 보고하고 참석으로 추정하지 마. 최소 인원, 책 분량 상한, 장소 수용 인원, 이용 가능 시간, 총예산을 모두 지켜. 휠체어 이용자가 참석하면 접근 가능한 장소만 가능해. 장소 비용 미확인은 0원으로 간주하지 마. 총비용은 장소비+참석자 수×간식비이며 책은 각자 준비해. 후보 우선순위는 참석 인원이 많은 순, 참석자들의 관심 태그와 책 태그의 공통 개수 총합이 큰 순, 해당 책을 안 읽은 참석자가 많은 순, 총비용이 작은 순, 날짜가 이른 순, 책 ID와 장소 ID 오름차순이야. 독서 이력이 여러 건이어도 읽은 사람은 한 번만 세어 줘. 모든 조합의 인원·관심점수·미독자수·총비용·탈락 사유를 보존하고, 가능한 최상위 안을 선택해. 가능한 안이 없으면 무리하게 정하지 말고 보류해. 예약 요청과 참가자 안내는 JSON 파일에 초안으로만 남겨 줘. 실제 예약·발송·캘린더 등록은 이 과제에 포함하지 않아. 선택한 안의 날짜·책·장소·참석자·비용을 기록해. 첨부된 가상 토론 기록은 별도의 완료된 모임 기록이야. 주제별로 논의를 종합해 이미 확정된 진행 규칙과 아직 해결되지 않은 질문을 구분하고, 열린 질문마다 원문 기록 ID와 다음에 확인할 방법을 제안해. 결과는 plan.json(모든 조합 candidates, 선택 selected, 미확인 unknown_members, 열린 질문 questions, 초안 drafts)과 사람이 읽을 report.md로 저장해. 질문 내용은 말뜻을 종합하되 원문에 없는 합의나 결론을 만들지 마. 두 파일 저장 후 재독 확인해. input 외 다른 실행자의 trainer/harness/drafts·정답·보고서는 참고하지 마. 너 자신의 앞선 결과·중간 참조는 재사용해도 돼.
