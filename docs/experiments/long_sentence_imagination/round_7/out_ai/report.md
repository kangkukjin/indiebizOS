# 가을 팀 워크숍(당일) 견적 비교 보고서

작성일: 2026-09-30 · 원자료: `docs/experiments/long_sentence_imagination/round_1/input/` (requirements.json, vendor_A.csv, vendor_B.json, vendor_C.csv)

## 1. 요구사항과 수량 산정

- 인원 30명, 예산 2,400,000원
- 버스 대수: 45인승 기준 올림 → ⌈30 ÷ 45⌉ = **1대**

| 항목 | 필수 | 수량 규칙 | 산정 수량 |
|---|---|---|---|
| 대관 | 필수 | 고정 | 1회 |
| 점심 | 필수 | 인원당 | 30인 |
| 간식 | 선택 | 인원당 | 30인 |
| 버스 | 필수 | 45인당 1대 | 1대 |
| 음향 | 필수 | 고정 | 1식 |

## 2. 업체별 금액 (단가 × 수량)

| 항목 | A | B | C |
|---|---|---|---|
| 대관 (1회) | 600,000 (빔프로젝터 포함) | 450,000 | 800,000 (음향 포함) |
| 점심 (30인) | 540,000 (18,000×30, 한식 도시락) | 660,000 (22,000×30, 뷔페) | 450,000 (15,000×30) |
| 버스 (1대) | 450,000 (45인승) | 500,000 | 420,000 |
| 음향 (1식) | 150,000 | **가격 없음** (“현장 협의”) | 0 (견적서에 “대관에 포함”으로 명시) |
| 간식 (30인, 선택) | 150,000 (5,000×30) | **견적 없음** | 120,000 (4,000×30) |
| **필수 항목 합계** | **1,740,000** | **산정 불가** (확인된 금액 1,610,000 + 음향 미정) | **1,670,000** |
| 간식 포함 합계 | 1,890,000 | 산정 불가 | 1,790,000 |
| 예산(2,400,000) 대비 | 안 (잔여 660,000) | 판정 불가 | 안 (잔여 730,000) |
| 필수 항목 가격 완비 | 예 | **아니오** (음향) | 예 |

- B의 음향은 null(현장 협의)이라 0원으로 계산하지 않았습니다. 간식은 B 견적서에 항목 자체가 없습니다.
- C의 음향 0원은 누락이 아니라 견적서에 “대관에 포함”으로 명시된 값이어서 가격이 있는 항목으로 보았습니다.

## 3. 추천

**추천: C업체** — 필수 항목 가격이 모두 있고 예산 안인 업체는 A·C 두 곳이며, 이 중 C가 가장 쌉니다.

- 필수 항목 기준 C 1,670,000원 vs A 1,740,000원 (C가 70,000원 저렴)
- 선택 항목 간식을 넣어도 C 1,790,000원 vs A 1,890,000원으로 순위는 같습니다.
- B는 확인된 금액(1,610,000원)만 보면 가장 싸 보이지만 필수 항목인 음향 가격이 없어 추천 조건을 충족하지 못합니다. 음향이 790,000원 이하로 확정되면 예산 안이고, 60,000원 미만이면 필수 합계가 C보다 싸지므로 확정 견적을 받아 다시 비교할 가치가 있습니다.

## 4. 업체별 확인 질문

**공통**
- 금액에 부가세가 포함되어 있습니까?
- 견적 유효기간은 언제까지입니까? (B만 2026-10-31로 명시, A·C는 미기재)
- 인원이 늘거나 줄 때 점심·간식 단가와 최소 주문 인원, 취소·변경 수수료는 어떻게 됩니까?
- 버스 금액에 유류비·통행료·기사 식비·대기 시간이 포함되어 있습니까? 당일 왕복 기준입니까?

**A업체**
- 대관 시간(몇 시간)과 초과 시 추가 요금이 있습니까?
- 음향(150,000원)에 마이크 개수·스피커·운영 인력이 포함됩니까?

**B업체**
- 음향 비용의 확정 금액은 얼마입니까? (현장 협의가 아닌 사전 확정 견적 요청)
- 간식 제공이 가능하다면 1인 단가는 얼마입니까?
- 버스는 몇 인승이며 30명이 1대로 탈 수 있습니까?
- 뷔페 점심의 최소 인원과 메뉴 구성은 어떻게 됩니까?

**C업체**
- 대관에 포함된 음향의 구성(마이크 수, 스피커, 기사 동반 여부)은 무엇입니까? 별도 음향 수준이 필요하면 추가 비용이 있습니까?
- 버스는 몇 인승이며 30명이 1대로 탈 수 있습니까?
- 점심(15,000원)의 메뉴 형태(도시락/뷔페 등)는 무엇입니까?
- 대관에 빔프로젝터 등 발표 장비가 포함됩니까? (A는 포함 명시)
