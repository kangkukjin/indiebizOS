# 가을 팀 워크숍(당일) 견적 비교 보고서 — 변경 조건

작성일: 2026-09-30 · 원자료: `docs/experiments/long_sentence_imagination/round_1/input_variant/` (requirements.json, vendor_A.csv, vendor_B.json — 3개 파일)

## 0. 이전 비교(report.md)와 달라진 점

- 인원: 30명 → **50명** (예산은 2,400,000원 그대로)
- 버스: 1대 → **2대** (⌈50 ÷ 45⌉ = 2)
- **C업체 견적서가 새 폴더에 없습니다.** 그래서 이번 비교 대상은 A·B 두 곳입니다. A·B 견적서 내용은 이전과 같습니다.

## 1. 요구사항과 수량

| 항목 | 필수 | 수량 규칙 | 산정 수량 |
|---|---|---|---|
| 대관 | 필수 | 고정 | 1회 |
| 점심 | 필수 | 인원당 | 50인 |
| 간식 | 선택 | 인원당 | 50인 |
| 버스 | 필수 | 45인당 1대 | 2대 |
| 음향 | 필수 | 고정 | 1식 |

## 2. 업체별 금액 (단가 × 수량)

| 항목 | A | B |
|---|---|---|
| 대관 (1회) | 600,000 (빔프로젝터 포함) | 450,000 |
| 점심 (50인) | 900,000 (18,000×50, 한식 도시락) | 1,100,000 (22,000×50, 뷔페) |
| 버스 (2대) | 900,000 (450,000×2, 45인승) | 1,000,000 (500,000×2) |
| 음향 (1식) | 150,000 | **가격 없음** (“현장 협의”) |
| 간식 (50인, 선택) | 250,000 (5,000×50) | **견적 없음** |
| **필수 항목 합계** | **2,550,000** | **산정 불가** (확인된 금액만 2,550,000 + 음향 미정) |
| 간식 포함 합계 | 2,800,000 | 산정 불가 |
| 예산(2,400,000) 대비 | **초과 150,000** | **초과** (확인된 금액만으로 이미 150,000 초과) |
| 필수 항목 가격 완비 | 예 | 아니오 (음향) |

- B의 음향은 null(현장 협의)이라 0원으로 계산하지 않았습니다. 음향이 0원이어도 B는 예산을 넘습니다.

## 3. 추천

**추천 조건(필수 항목 가격 완비 + 예산 안)을 만족하는 업체가 없습니다.**

- A: 가격은 완비됐지만 필수 합계 2,550,000원으로 예산을 150,000원 초과합니다.
- B: 음향 가격이 없고, 확인된 금액만으로도 예산을 150,000원 초과합니다.

선택지(결정은 사용자 몫):
1. 예산을 최소 2,550,000원(간식 포함 시 2,800,000원)으로 올리면 A가 조건을 만족하는 유일한 업체가 됩니다.
2. A와 150,000원 이상 할인(예: 버스 2대 묶음 할인, 대관 할인)을 협상합니다.
3. C업체를 다시 비교 대상에 넣을지 확인합니다. **참고로만**: 이전 폴더(input)의 C 단가가 그대로 유효하다고 가정하면 50명·버스 2대 기준 필수 합계는 2,390,000원(대관 800,000 + 점심 750,000 + 버스 840,000 + 음향 0)으로 예산 안입니다. 하지만 새 자료에 C가 없어서 이번 비교에는 넣지 않았고, C가 빠진 이유(견적 철회·일정 불가 등)도 확인되지 않았습니다.

## 4. 업체에 물어볼 질문

**공통**
- 금액에 부가세가 포함되어 있습니까?
- 50명 기준 단체 할인이 가능합니까?
- 버스 2대 금액에 유류비·통행료·기사 식비·대기 시간이 포함되어 있습니까? 2대를 함께 계약하면 할인이 됩니까?
- 최소 주문 인원, 인원 변동 시 단가, 취소·변경 수수료는 어떻게 됩니까?

**A업체**
- 예산 2,400,000원에 맞추려면 어떤 항목을 얼마나 조정할 수 있습니까? (150,000원 차이)
- 대관 공간이 50명을 수용할 수 있습니까? 대관 시간과 초과 요금은 어떻게 됩니까?
- 견적 유효기간은 언제까지입니까? (미기재)
- 음향(150,000원)에 마이크 개수·스피커·운영 인력이 포함됩니까?

**B업체**
- 음향 비용의 확정 금액은 얼마입니까? (현장 협의가 아닌 사전 확정 견적 요청)
- 간식 제공이 가능하다면 1인 단가는 얼마입니까?
- 버스는 몇 인승입니까? 50명에 2대가 필요합니까?
- 대관 공간이 50명을 수용할 수 있습니까?

**C업체(비교에 다시 넣을 경우)**
- 50명 기준 견적이 여전히 유효합니까? 대관 공간과 음향이 50명 규모를 감당합니까?
