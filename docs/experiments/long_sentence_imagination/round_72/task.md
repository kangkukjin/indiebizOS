JSON은 rows(각 sku,ordered,shipped,shortage,status), total_ordered, total_shipped, missing_files 필드를 사용해 줘. 정상 자료에서 부족하면 shortage, 충분하면 fulfilled로 표시하고, 일부 출하 자료를 읽지 못하면 확인된 출하량은 남기되 모든 품목의 shortage를 null, status를 unknown으로 표시해 줘. 누락 파일 이름을 빠짐없이 남기고 요약에도 총 주문량·확인된 출하량·미확인 파일 수를 적어 줘. 기존 보고서가 있으면 먼저 읽고 갱신하고 두 결과 파일을 다시 읽어 확인해 줘. 이 폴더의 자료만 사용하고 외부 발송은 하지 마.
