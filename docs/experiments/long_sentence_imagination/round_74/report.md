## 과제·작성과 환경

[사전 계약](task.md)의 자연어 요구는 교육 절차서 12개에서 명세가 허용한 줄만 발췌하여
excerpts.json과 handbook.txt를 만들고, 기존 결과를 읽어 갱신한 뒤 재독하는 것이다.
LF/CRLF/CR, 한글·이모지·탭·후행 공백을 보존한다. 파일 누락은 unavailable/null과
명시한 파일명으로 남긴다. A/B 회원의 같은 상대경로에는 다른 본문이 있다.

합성 자료를 사용한 이유는 실제 회원의 비공개 문서를 훈련에 사용할 필요가 없기 때문이다.
실제 IBL 판본2 → 회원 관문 → 서명 HTTP → Go 실행부 → 로컬 SQLite/파일 IO를 사용했다.
중앙 저장소·등록 키·기기·자료는 회차 폴더에 격리했다. 두 Go 프로세스는 같은 Mac에 있으므로
두 물리 PC·Electron·Windows 설치·외부 HTTPS의 인수로 해석하지 않는다. 자동 승인 대역은
회차 폴더의 요청만 처리했으며 취소 진단에서는 첫 쓰기를 승인하지 않았다.

공개 조합 교재·회원 계약·system_essentials 어휘 선언과 71/72회차 보고서를 참고했다.
실행 기반 구축을 위해 72회차 harness를 읽었으므로 내부 지식 없는 독립 작성이라고 하지 않는다.
업무 가공은 [최초 전체 프로그램](draft_v0.ibl)에 있고 Python harness는 자료·전송·승인·대조만 한다.
분해는 발췌(항목→범위 본문/실패), 저장(기존 판본 읽기→조건부 쓰기), 순서대로 모으기→두 파일 재독이다.
초안은 별도 검사 `ok:true, issues:[], status:incomplete`(도구 결과는 실행 시 검사)를 거쳐 수정0회로 실행했다.
