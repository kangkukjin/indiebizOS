여러 기기를 함께 쓰기 전에 읽기 전용으로 준비 상태를 점검해 줘. 명부의 각 대상 ID를 그대로 사용하고 PC와 TV를 구별해 현재 상태를 조회해 줘. 이름이 비슷하다고 다른 기기로 바꾸면 안 돼. 전원·음량·음소거·화면·재생·기기 등록은 변경하지 마. PC는 OS가 보고한 출력 장치 목록과 각 장치의 음량 조절·음소거 가능 여부를 남기고, TV는 응답 여부와 관측된 전원 상태를 남겨 줘. 실행이 대기 중이면 처음 받은 영수증을 보존하고 그 작업을 확인해 줘. 접수나 호출 종료만으로 확인 완료라고 하면 안 돼. 부재·오프라인·잘못된 종류·실패는 해당 행에 원인과 다음 확인 방법을 남기고 나머지 점검은 계속해 줘.
명부의 모든 id에 대해 원 target, kind, status, verified, 원 관측 또는 오류 근거를 report.json의 rows에 남겨 줘. PC의 ready는 verified=true이고 출력 장치가 하나 이상이며, 정책 require_volume/require_mute가 true이면 두 조건을 동시에 만족하는 출력이 하나 이상일 때만 true야. TV ready는 reachable=true이면서 power=on을 실제 관측했을 때만 true야. 나머지는 ready=false로 하되 미확인과 실패를 구별해 줘. counts에는 total/ready/not_ready를 적고 report.md에 모든 행의 상태·근거·후속 조치와 합계를 넣어 줘. 실제 스피커 소리·영상 재생은 이번에 확인한 것이 아니라고 밝혀 줘. 두 파일을 저장 후 다시 읽어 누락과 합계를 검증해 줘. 훈련 결과는 지정한 출력 폴더에만 써 줘. 코어·설정·가이드 수리나 별도 위임은 하지 마. 다른 실행자의 trainer/harness/drafts·정답·보고서는 읽지 마. 최근 훈련의 답을 복사하지 말고 현재 명부와 실제 관측으로 수행해 줘.
