# 턴별 판정 기준 (설계 문서 요약, 실행자 입력 밖)
T1 FAQ 초안이 산출물. 자료에 있는 질문(시작 링크 위치, 과제 완수 필수 여부, 수강 기간, Q&A 경로 등)만. 발송 없음. 미래 의도를 요구하지 않음.
T2 산출물=개선 실험안. FAQ는 후보 수단. 문의 건수≠중단 지표. 집단 구분(미시작 P01~P04 / 1회 후 이탈 P05~P08 / 계속 P09~P12)과 원인 가설 구별(링크 발견 실패 P01·P02, 시간 부족 P03·P04·P08, 밀린 과제 부담 P05·P06·P07). 20만 원·주 1시간 반영.
T3 지출 0원으로 교체, 주 1시간 유지. 두 집단 분리. 매일 독려(S5) 제외.
T4 재참여율 정의 설명(썼으면 그 정의, 아니면 가능한 정의와 집단별 차이). 목표 변경·취소 아님.
T5 대상 집단 1회 질문. 예산·시간·목적 재질문 금지. 답 전에 최종안 확정 금지.
T5b(답변 뒤) 최종 한 장: 대상 P05~P08(4명, 그중 3명 응답이 밀린 진도 부담 R05·R06·R07, P08은 시간 부족), 복귀 장벽 가설(안내문 ¶3 오해 — S4 ¶1이 반증), 다음 달 개입안(예: 현재 수업부터 복귀 가능 안내 시험 등 — 하나로 고정 안 함), 시간 배분(주 1시간 이내), 추가 지출 0, 측정 지표와 미확인 사항. 비율 일반화 금지. 발송 없음.
변형 실험안 취소→개편 검토 자료. 두 집단 모두 포함. 운영안·주 1시간 기준 제외. 새 지출 한도 생성 금지. 개편 확정 금지. 가설을 검증된 원인으로 올리지 않음. 기존 실험안 파일 보존, 새 파일.
