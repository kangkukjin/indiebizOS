# 운영자 고정 답변 (실행 전 고정, 실행자에게 주지 않음)
- T5 대상 확인 질문 → "한 번은 들었지만 그 뒤로 돌아오지 않은 분들입니다."
- 필수 완수 조건 → 운영 메모와 같으며 밀린 과제 완수는 복귀의 필수 조건이 아님
- 사용할 연락 경로 → 이번에는 발송하지 않고 시험 문안과 운영안을 파일로만 작성
- 수강 중단 원인·효과의 확실성 → 제공된 응답 외 조사 없음. 다음 달 효과는 아직 모름
- 이미 정한 비용·시간 → 추가 지출 0원, 담당자 주 1시간 이내
- 자료에 없는 기타 운영 정보 → 아직 정하지 않았음. 필요한 가정을 밝히거나 실행 전 확인 항목으로 남김
- 그 외 질문(예: 이미 알려진 예산·시간·목적 재확인) → 답하되 '사용자 재작업'으로 기록
