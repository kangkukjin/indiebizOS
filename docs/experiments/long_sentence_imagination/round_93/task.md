- 합성 CSV: 서비스·기밀 자료 없이 따옴표/CRLF/빈 자료/잘못된 숫자의 경계를 통제한다.
- Python 부품: stdin 객체의 CSV를 파싱하여 items 반환, stdout은 진단.
- IBL 지역 함수: 코드 작성 → 묶음별 실행/실패 격리 → 합류·합계 → JSON 저장·재독.
