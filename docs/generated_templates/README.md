# 문서 파생 구간의 편집 원문

`scripts/iblbuild_docs.py`의 `DOC_TARGETS`가 이곳의 템플릿과 레지스트리 실측을 합쳐 문서 마커 안을 통째로 생성한다. 수정은 이곳에서 하고 `python3 scripts/build_ibl_nodes.py`로 반영한다. `--check`와 커밋 관문은 같은 생성 결과를 대조한다. 마커 밖 산문은 해당 문서에서 편집한다.

- Markdown 템플릿의 `{{이름}}`은 명시적인 실측·표시 슬롯이다. 없는 슬롯과 템플릿, 손상된 마커는 실패로 보고하며 해당 문서를 쓰지 않는다.
- `descriptions.json`은 노드와 패키지의 사람이 편집한 설명이다. 패키지 표의 행 집합은 설치 레지스트리가 결정한다. 새 패키지는 메타데이터 설명을 사용하고, 제거된 패키지는 설명이 남아 있어도 표에 나오지 않는다.
- `ibl_grammar.json`은 연산자의 의미·짧은 설명·검증 예제를 소유한다. 전체 명세, 전체 교재, 짧은 교재는 각 독자에게 필요한 열을 선택한다. 그 밖의 문법·권한·도메인 교재는 기존 정본을 유지한다. 언어 개정은 파서와 행동 시험, 이 의미 계약을 함께 갱신한다.

기존 파생 문장의 숫자나 표현에 맞추는 정규식은 쓰지 않는다. 새 노드·라우터·패키지를 추가했을 때 행과 합계가 함께 변하는 것이 생성 계약이다.
