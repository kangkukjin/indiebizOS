kospi-board — 코딩 목표

무엇을 만드나

코스피 상위 50 종목의 현재가·등락률을 한 화면에 보여 주는 현황판. 브라우저에서 연다.

꼭 되어야 하는 것

  • 등락은 한국식 색 — 상승 빨강, 하락 파랑.
  • 매일 아침 8시에 자동으로 데이터를 갱신한다.
  • 종목을 누르면 최근 30일 차트가 열린다.
  • 폰에서도 깨지지 않게.

안 해도 되는 것

로그인, 알림, 매수·매도 기능.

실행 방법

python app.py → http://localhost:5000
