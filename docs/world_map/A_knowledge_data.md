# A. 지식·데이터·공공 연결 (조사 2026-09-06)

## 요약 (가장 강력한 5개와 이유)
1. **공공데이터포털 data.go.kr 카탈로그·범용 호출** — 한국 공공 API 의 단일 관문(개발계정 일 1,000건). 지금은 `DATA_GO_KR_API_KEY` 로 특정 데이터셋 5~6개만 코드에 박혀 있고 "데이터셋 검색→호출" 이라는 관문 자체가 어휘가 아니다. 이걸 열면 수천 개 공공 API 가 데이터로 들어온다.
2. **Wayback Machine (Availability/CDX API)** — 사라진 페이지·과거 판본을 보는 유일한 표준. 키 없음. `sense:crawl` 이 404 를 만나면 자연스럽게 잇는 짝.
3. **OpenStreetMap Overpass + Nominatim + OSRM** — 카카오 기반 장소·경로 어휘는 한국 한정. 해외 지리(지오코딩·POI 질의·경로)는 OSM 생태계가 사실상 유일한 무료 표준.
4. **FRED + 한국은행 ECOS** — 미국·글로벌 거시(80만 시계열)와 한국 거시(금리·환율·통화량)의 양대 정본. `sense:world_bank` 는 연 단위 개발지표라 분기·월·일 거시를 못 준다.
5. **GDELT DOC 2.0** — 전 세계 뉴스를 사건·톤·언어별로 시계열 질의(키 없음). 뉴스 API 들이 유료화된 2025~26 에 남은 무료 글로벌 뉴스 관측소.

주의(기존 어휘 영향): **OpenAlex 가 2026-02-13 부터 API 키 필수**(무료 일 $1) — `sense:paper` 기본 소스가 무키 호출이면 지금 깨져 있을 가능성. **네이버 검색 API 는 2026-07-31 NAVER API HUB 로 이관**(도메인·헤더 변경, 책·쇼핑·전문자료 검색 종료) — `sense:search{source:naver}`·`sense:restaurant` 의 호출 경로 확인 필요.

## 겹침 메모 (기존 어휘와 겹쳐 뺀 것)
- **OpenAlex / arXiv / PubMed / Semantic Scholar** — `sense:paper` 의 source 로 이미 있음. 차이=없음. 단 **OpenAlex 는 2026-02-13 부터 API 키 필수**(무료 계정 일 $1 예산, 아래 참조) — 기존 호출이 무키면 수리 대상.
- **Europe PMC** — `sense:paper{source:"pubmed"}` 와 겹침. 차이=키 없음·전문(full text XML)·유럽 특허까지 색인. `source:"europepmc"` 한 줄 추가로 흡수 가능.
- **CORE** — `sense:paper` 와 겹침. 차이=오픈액세스 전문 PDF 4천만 건 집계(무료 키, 10초당 5건). 전문이 필요할 때만.
- **Wikidata (SPARQL)** — `sense:entity` 가 이미 Wikidata. **DBpedia** 도 같은 층(Wikipedia 인포박스 추출, SPARQL, 100 req/s) — 차이=영문 중심·갱신 느림, Wikidata 가 상위 표준이므로 제외.
- **World Bank** — `sense:world_bank` 있음. 차이=연간 개발지표만 → 월·일 거시는 FRED/ECOS(표).
- **Google Books / 도서관정보나루 / 국립중앙도서관** — `sense:book`. **Open Library** 는 겹침(ISBN·서지·표지 이미지·무키). 차이=표지 URL·판본 계보·스캔본 전문검색. `source:"openlibrary"` 추가로 흡수.
- **Project Gutenberg** — `sense:classic{western}`. **한국고전종합DB** — `sense:classic{korean}`.
- **KOSIS** — `sense:kosis`. **법제처 law.go.kr** — `sense:legal`. **국토부 실거래가** — `sense:realty{source:"molit"}`. **DART 전자공시** — `sense:company{disclosures}` (한국 DART/미국 SEC 자동 판별). **K-Startup·상권정보·문화정보·관광정보** — 각각 `sense:startup`·`sense:commercial`·`sense:exhibit` 이 data.go.kr 경유로 이미 호출.
- **The Guardian Open Platform** — `sense:search{source:"guardian"}` 로 2026-08-05 흡수됨. 차이=없음.
- **Open-Meteo** — `sense:weather`. 기상청 API허브는 관측·특보·지진이라 표에 남김.
- **네이버/카카오 개발자 API** — `sense:search{naver}`·`sense:restaurant`·`sense:place`·`sense:reverse_geocode`·`sense:navigate_route` 가 사용 중. 아래 '변경' 항목 참조.
- **Kaggle** — `sense:contest`. Kaggle arXiv 메타데이터 덤프(1.1TB 전문)는 `sense:paper` 의 벌크 대체이나 개인용 아님.
