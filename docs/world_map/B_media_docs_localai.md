# B. 미디어·문서·로컬 AI 도구 (조사 2026-09-06)

> 범위: 로컬에서 도는 것. 몸(indiebizOS)이 내부적으로 이미 부르지만 **어휘로는 없는** 도구(ffmpeg·soffice·PyMuPDF 등)는 "내부 사용" 표기 후 어휘 후보로 남겼고, 이미 어휘·프로바이더 층에 있는 것(Ollama·sentence-transformers·yt-dlp·Playwright·edge-tts·moviepy·typst·Pillow·ripgrep)은 겹침 메모로 뺐다. 모든 근거 URL 은 2026-09-06 웹 검색으로 확인.

## 요약 (가장 강력한 5개)
1. **ffmpeg 9.0.1** — 영상·음성의 유일 표준. 몸이 8개 파일에서 내부 호출하면서도 "변환·자르기·추출·probe" 어휘가 없다 — 가장 큰 공백.
2. **pandoc 3.10.1 + LibreOffice 26.8 headless** — 문서 형식 변환의 두 기둥. `table:document` 는 렌더(생성)만 하고 *any→any 변환*(docx→md, epub, odt, hwpx…)은 없다.
3. **whisper.cpp(맥) / faster-whisper(윈·NVIDIA)** — 로컬 STT 표준. `sense:listen` 은 마이크+Gemini(클라우드)라 *파일 전사·오프라인·한국어 대량*이 비어 있다.
4. **rclone 1.75.1 · restic 0.19.1 · Syncthing 2.1.3** — 클라우드 동기화·백업·기기 간 P2P 동기화 표준 3종. 백업 규약(`data/_backups/`)은 있으나 어휘가 없다.
5. **Hugging Face Hub(`hf` CLI) · ComfyUI · MLX** — 로컬 AI 자산의 공급망(모델 내려받기)·이미지 생성(로컬)·애플 실리콘 런타임. `engines:image_gemini` 는 클라우드뿐.

## 겹침 메모 (기존 어휘·몸과 겹쳐 뺀 것)
- **Ollama** — 이미 `backend/providers/ollama.py` 프로바이더 층(`self:ask` 경량 기어). 남는 공백은 모델 관리(`ollama pull/list/rm`) 뿐 → 위 `[self:model]` 후보에 흡수.
- **sentence-transformers** — 이미 해마(`ibl_embedding_trainer.py`·`ibl_usage_db.py`)가 사용. v6.0(MultiVectorEncoder·ColBERT식)·v5.4(멀티모달) 갱신만 참고.
- **yt-dlp** — `api_ytrelay.py`·`nas_music.py` 내부 사용, 어휘는 `sense:video`·`limbs:music{download}`. 차이 없음.
- **Playwright** — `limbs:browser` 가 정본. **edge-tts / moviepy / typst** — `requirements-tools.txt`·deck 렌더에 이미 있음(`engines:tts`·`self:deck`).
- **Pillow** — 6파일 내부 사용. ImageMagick/libvips 행은 HEIC/AVIF·대량·합성이 차이.
- **PyMuPDF(fitz) / pdfplumber / pypdf** — `document_converter.py`·`ingest_engine.py` 가 이미 사용(`self:read`). `pymupdf4llm.to_markdown()` 만 옵션 추가 검토.
- **ripgrep / fd** — `self:grep`(grep/ripgrep)·`self:file_find` 가 정본. **fzf** 는 대화식이라 프로그램 통로 아님.
- **jq / yq** (1.8.2 / 4.53.4) — IBL 의 `table:*`(filter·select·compute·groupby)와 `self:ledger` 가 언어 안 등가. 셸 그림자 관문 대상.
- **sqlite-utils** — `sense:sqlite`·`self:ledger` 와 겹침(Simon Willison 이 2026-08 `alchemy-utils` 로 범용화 중).
- **Kokoro-82M / Piper** — `engines:tts`(Gemini)·edge-tts·Qwen3-TTS 와 겹침. 차이=오프라인·Apache 2.0, 단 **둘 다 한국어 없음**(Kokoro 8개 언어, Piper 47개에 ko 부재) → 표 제외. 한국어 오프라인 TTS 는 몸이 이미 Qwen3-TTS 로 감.
- **EasyOCR** — Tesseract/PaddleOCR 의 중간(설치 쉬움) — 2026 표에서 위 둘에 밀려 B 도 아님.
- **Marker(Datalab)** — Docling 과 정확도 동급이나 GPL-3 + RAIL-M 가중치 라이선스·GPU 의존 → Docling 을 대표로.
- **vLLM** — Linux/NVIDIA 서버용, 맥 비대상. **borg** — 유닉스 전용·2.0 베타(b22) → restic 대표. **Kopia** — 3위, GUI 겸비.
- **Logseq** — DB 판 장기 베타·점유율 하락, 파일 규약(md/org)은 `self:read/write` 로 충분 → 제외.
- **HandBrake / SoX** — ffmpeg 가 덮음(아래 후계 항목 참조).
- **poppler(pdftotext)** — PyMuPDF 가 덮음.
