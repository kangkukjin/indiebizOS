# 세계 지도 대규모 확장 — 편집 원천과 분야별 목록

편집일: 2026-09-17. 이 문서는 새 어휘의 **편집 출처**다.
AI의 일반 지식에서 통용 방법·개념·도구를 수집하고 중복·명칭·분류를 검토했다.
아래 모든 어휘를 외부 문헌으로 하나씩 검증했다는 뜻은 아니다.
정확한 기능·최신 계약·의료 및 법률 적용은 실제 사용 시 원출처로 확인한다.
검색 힌트는 독자적으로 쓴 짧은 구별 설명이며 인용문이 아니다. 모델 주입에는 설명을 넣지 않는다.

## 확인한 참조 체계

분야 공백 점검과 갱신 통로로 다음 공식 목록을 확인했다. 각 목록 전체를 복제하지 않았다.
- [UNESCO 어휘 서비스](https://vocabularies.unesco.org/en/): 인문·사회·문화 분류의 대조 입구.
- [FAO AGROVOC](https://www.fao.org/agrovoc/): 농업·식품·환경의 다언어 어휘와 관계.
- [NLM MeSH](https://www.nlm.nih.gov/mesh/meshhome.html): 생명·건강 연구 용어의 계층과 다른 이름.
- [NIST 탐색적 자료분석](https://www.itl.nist.gov/div898/handbook/eda/eda.htm): 통계적 탐색과 가정 점검.
- [scikit-learn 사용자 가이드](https://scikit-learn.org/stable/user_guide.html): 통계학습 방법의 분류.
- [SciPy 참조](https://docs.scipy.org/doc/scipy/reference/): 수치계산·신호·통계 모듈의 입구.
- [IDEO Design Kit](https://www.designkit.org/methods.html): 설계 조사·시제품·학습 방법의 분류.
- [W3C SKOS](https://www.w3.org/TR/skos-reference/): 표제·별칭·상하위·연관 관계의 구별.

IUPAC Gold Book 본문은 이번 접근에서 403 응답이어서 검증 근거로 세지 않았다.
도구 확인 범위: [Stan](https://mc-stan.org/), [GNU Octave](https://octave.org/),
[OpenRefine](https://openrefine.org/), [ImageJ](https://imagej.net/software/imagej/).
여기서 확인하지 않은 도구는 통용 이름의 편집 초안이며 최신 버전이나 설치 가능성을 보증하지 않는다.

## 편집과 갱신

정본은 `data/knowledge_catalog/atlas/*.yaml`이다. 아래 목록은 이번 편집의 검토 기록이다.
새 어휘는 기존 한국어 표제와 영어 표제를 먼저 찾고, 같은 개념이면 별칭을 추가한다.
이름 없는 질문에서 검색이 실패하면 어휘 부재와 표현 불일치를 구별한다.
분야 경로는 탐색 분류이며 모든 항목 사이의 의미적 상하위 관계를 주장하지 않는다.
관계 추가는 방향·종류·근거를 따로 검토한다. 단순히 같은 분야라는 이유로 완전연결하지 않는다.
수정 뒤 색인·검색 회귀·전체 분야 탐색·폰 번들을 확인한다. 자동 외부 수집이나 예약 갱신은 이번 범위가 아니다.
