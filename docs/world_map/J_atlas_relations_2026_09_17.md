# 확장 어휘의 관계 검토

2026-09-17. 아래 관계는 AI 편집자가 두 어휘의 통용 의미를 대조하여 검토한 **편집상 연관**이다.
`verified`는 이 표와 방향·종류·참조를 검토했다는 로컬 상태이며 외부 실험의 검증을 뜻하지 않는다.
동의어·대체 가능성·필수 순서·사용자에게 맞는 추천을 주장하지 않는다.
동일 분야 전체를 묶지 않고 의미를 구별하는 연결만 골랐다. 이 표 변경 시 관계를 재검토한다.

## stan

[Stan 공식 소개](https://mc-stan.org/)를 확인했다. 공식 소개의 Bayesian inference와 확률 모형 기능. 베이지안 추론 구현 도구로 연결한다.

## openrefine

[OpenRefine 공식 소개](https://openrefine.org/)를 확인했다. 공식 소개의 reconciliation과 값 군집화 기능. 개체 식별 통합 구현 도구로 연결한다.

## gephi

[Gephi 공식 소개](https://gephi.org/)를 확인했다. 공식 소개의 network analysis와 중심성·군집 기능. 네트워크 분석 구현 도구로 연결한다.

## audacity

[Audacity 공식 소개](https://www.audacityteam.org/)를 확인했다. 공식 소개의 spectrogram과 오디오 분석 기능. 스펙트럼 분석 구현 도구로 연결한다.
