# 세계 전반의 분류 골격과 기본 개념 보강

2026-09-22 편집 원천. `data/knowledge_catalog/outline.yaml`에 분야와 하위 가지를
먼저 선언한 뒤 기존 항목을 배치하고 빈 가지의 기본 개념을 채웠다.
특정 인물·기관의 조사 절차나 평가 결론을 항목으로 넣지 않는다.

이 원천은 모델의 일반 지식에 기초한 편집 초안이다. 이름과 한 줄 구별, 일상 한국어
입구를 담으며, 각 항목을 외부 문헌으로 개별 검증했다고 주장하지 않는다.
건강 개념은 인체·보건 지식으로 가는 입구이며 진단·치료 지침이 아니다.
새 관계의 외부 검증 근거로 이 편집 문서를 쓰지 않는다.

`foundation/*.yaml`의 source.section은 분야명이다. 기존 atlas 항목의 출처와 ID,
검토된 의미 관계는 유지한다. 분류 경로의 이동은 의미 관계의 추가가 아니다.

골격은 하나의 편집 관점이며 완전성이나 유일성을 주장하지 않는다. 주요 분야별 기본
이해의 입구를 먼저 확보하고 이후 같은 골격 안에서 깊이를 더한다. 항목 수를 같게
맞추거나 이미 많은 도구를 삭제하여 균형을 가장하지 않는다. 가지를 채우며 발견한
구분의 문제는 골격을 수정할 근거로 남긴다.

검색 힌트·별칭은 이름과 개념의 뜻에 근거해 작성했다. 이번 작업자가 만든 진단 질문은
독립 눈가림 평가가 아니며 개발 진단으로만 사용한다. 검색 성공과 실제 응답 품질은
별개다. 자세한 적용·검증 결과는 `docs/WORLD_MAP_TOPDOWN_2026_09_22.md`를 따른다.
