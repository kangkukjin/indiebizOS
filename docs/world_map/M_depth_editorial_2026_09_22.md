# 분야 골격 아래의 기본 대상·현상·원리 — 편집 원천

이 문서는 `data/knowledge_catalog/concepts/*.yaml`의 편집 출처다. AI 일반 지식으로
작성한 짧은 개념 표제·구별·일상 표현이며, 각 항목을 외부 문헌과 개별 대조한 자료가 아니다.
정의는 검색 입구이며 전문적 판단의 근거 문헌을 대신하지 않는다.

항목을 작성하기 전에 기존 14개 큰 영역 아래에 119개 세부 주제를 선언했다.
수와 연산부터 물질·지구·생명·건강·마음·사회·경제·인문·예술·컴퓨팅·공학·생활·탐구까지
같은 방식으로 기본 대상을 채웠다. 인물 조사나 특정 사건은 골격의 기준으로 쓰지 않았다.
기존의 상세 경로 18개도 보존한다. 분류와 검색을 위한 편집이며, 검토된 관계를 새로 주장하지 않는다.

중복은 기존 ID를 재사용했다. 도구의 검색 별칭에 들어 있다는 이유만으로 기본 개념을
도구와 합치지 않았다. 예를 들어 방정식과 SymPy는 서로 다른 입구다. 전제·유화·앙상블·
교정·매개변수처럼 뜻이 다른 경우 표제를 한정한다. 공명처럼 여러 분야에서 쓰는 같은
원리는 하나의 항목을 유지한다. 기존 ID·설명·별칭·출처는 보존하며, 기존 표제 중
전제·일관성·발효·유화·앙상블·브레이징·교정은 분야를 괄호로 명시해 다른 뜻과 구별한다.

이번 항목의 일상 표현은 개념별로 짧고 구별 가능한 한 개부터 작성했다. 네 개를 채우기
위한 변형 문장을 만들지 않았다. 다만 기존 눈가림 별칭 실험의 성과를 이번 묶음의 성과로
옮겨 주장할 수 없다. 작성자는 기존 개발 질문을 알고 있으며, 고정 질문 재실행은 회귀
진단이다. 독립 평가와 실제 답변 행동의 개선 여부는 별도 검증할 일이다.
