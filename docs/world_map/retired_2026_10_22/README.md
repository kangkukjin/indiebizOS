# 세계의 지도 — 2026-10-22 은퇴 기록

사용자 결정에 따라 자동 검색·주입, 수동 조회, 색인·감사 도구와 지도 기반 자작 관문을 제거했다.
의식의 **세상의 방식·탐색·전문가의 선택**은 유지한다. 라이브러리 설치 승인도 기존 계약을 유지한다.

이 폴더의 `data/`는 수집된 카탈로그·평가 자료·가이드의 원문을 이전 경로 구조 그대로 보존한다.
`SHA256SUMS`는 이전 당시의 원문 바이트 지문이다. 문서 안의 경로·명령·성능 수치는 당시 기록이며
현재 사용 지침이 아니다. 자동 회상·가이드 목차·배포 번들에서 읽지 않는다. 상위 폴더의 조사 원천과
기존 WORLD_MAP 설계 문서도 역사 기록으로만 보존한다. 삭제된 구현은 Git 이력에서 확인할 수 있다.
